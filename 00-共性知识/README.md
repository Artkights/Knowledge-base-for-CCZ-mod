# 共性知识

本目录描述所有版本共同的阅读规则、证据等级、术语和迁移边界。它不替代 6.5、6.5pl 或 6.6 的版本入口。

## 证据等级

- `verified`：当前样本、工具源码、复读、烟测或实机已确认。
- `external`：可复核的外部文档或论坛资料，但尚未完成当前版本验证。
- `unverified`：线索、推断或样本不足，只能进入待验证队列。
- `deprecated`：被新证据替代的旧结论。

## 使用规则

1. 先选版本，再读主题。
2. 未验证地址、偏移和字段语义不得直接写回游戏文件。
3. 跨版本迁移必须查看版本差异和来源证据。
4. 归档资料用于追溯，不用于默认实现。
5. 涉及地址解析、内存补丁、文件写回、代理 DLL 或安装器时，先读[源码级制作与安全写回规则](07-源码级制作与安全写回规则.md)。
