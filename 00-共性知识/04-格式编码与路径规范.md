# 格式编码与路径规范

## 结论速览

- Markdown 和普通文本使用 UTF-8 BOM。
- JSON 使用标准 UTF-8，CSV 使用 UTF-8 BOM。
- 文档只使用仓库相对路径。

## 适用版本

- 所有版本。

## 已确认事实

- 发布校验器会检查编码、盘符路径和本地链接。

## 实现/使用方法

- 使用 `tools/validate_kb.py` 检查发布内容。

## 风险与边界

- 不要把个人电脑路径、真实密钥或调试临时目录提交到仓库。

## 证据来源

- 当前知识库格式规范。

## 待验证项

- 继续检查新增外部来源中的路径和编码。
