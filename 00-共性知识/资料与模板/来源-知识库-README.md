# data 管理器知识库

## 结论速览

本知识库只描述 `data 管理器` 的纯数据能力。工具向用户公开 `曹操传加强版 6.5` 和 `曹操传加强版 6.6` 两个 Profile；6.6 内部根据样本证据选择标准、兼容或旧山贼布局。表定义的运行时权威来源是 `config/profiles/ccz-6.5.json` 与 `ccz-6.6.json`。

## 证据等级

| 等级 | 含义 |
| --- | --- |
| `BaselineVerified` | 已用 6.5 默认基底确认结构和读写 |
| `VariantVerified` | 已用相应 6.6 本地变体确认 |
| `SourceReviewed` | 已从旧工具的纯数据实现复核，但本工具样本覆盖有限 |
| `InheritedUnverified` | 从共性布局继承，当前样本没有足够的非空语义证据 |

验证等级只用于说明证据，不用于禁止写入。只有文件不存在或长度不足以容纳某张表时，该表本身无法加载。
