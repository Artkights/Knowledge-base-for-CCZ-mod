# 曹操传 MOD 引擎与制作知识库

本仓库面向引擎修改、制作工具开发、剧本制作和自动化测试。版本目录中的结构化 JSON 是机器事实源；`reference/` 是由 JSON 自动生成的人类阅读页，禁止手工维护两份互相漂移的结论。

## 有用知识的定义

能够直接回答“在哪里、是什么、怎样解析、怎样调用、怎样修改、怎样验证”的资料属于有用知识：

- 引擎画像、VA/RVA/文件偏移、函数 ABI、寄存器和返回值、调用链与关键全局量；
- 表基址、记录步长、字段偏移、索引公式、编码、空值和二进制文件格式；
- 特效桩、调度函数、注入站点、替换字节、参数点、代码洞、回跳和冲突关系；
- 剧本 opcode、子命令、参数槽、语义、风险和版本差异；
- 可复用的制作工作流，包含输入、顺序步骤、门禁、产物和回滚；
- 自动化测试契约，包含命令、变更范围、断言、产物和失败含义；
- 已实施制作案例，包含目标、输入、过程、结果和可复用结论。

仅介绍源码文件作用、工具界面、构建过程、发布历史、治理口号或重复摘要的内容不进入事实树。没有版本画像、上下文和含义的裸地址也不是可执行知识；它只能进入研究队列，等待补证。

## 三种知识状态

| 状态 | 含义 | AI 可如何使用 |
|---|---|---|
| `canonical` | 已绑定画像并具有可复核证据的正式事实 | 可用于工具实现；涉及写回时仍须满足条目的全部前置条件 |
| `candidate` | 已从历史资料提取成结构化技术记录，但仍缺少样本、原字节、ABI 或实机闭环中的一项或多项 | 默认可搜索，可用于方案设计、解析器开发和定位复核；不得据此自动写回 |
| `legacy-reference` | 旧版本地址参照物 | 只用于迁移和差异分析，不能套用到 6.5/6.6 |

`research/` 保存尚未形成结构化实体的线索，不进入默认索引。

## 读取与查询

1. 先选择 `6.5`、`6.5pl`、`6.6` 或 `legacy`，读取相应 `README.md`。
2. 人工浏览 `reference/`；机器先读 `index.json`，再按 `structuredDataPath` 打开完整实体。
3. 地址检索示例：`python tools/query_kb.py "0x004210D0" --version 6.5`。
4. 剧本检索示例：`python tools/query_kb.py "0x14" --version 6.5 --entity-type script-command`。
5. 只接受已验证事实时增加 `--canonical-only`；研究线索需显式增加 `--include-research`。

当前数据域包括引擎画像、函数、全局量、数据结构、文件格式、补丁、机制、特效桩、剧本指令、工作流、测试契约和制作案例。`index.json` 提供统一 ID、版本、状态、证据、地址、搜索词、来源和数据路径。

## 地址与写回规则

每个地址必须声明 `va`、`rva`、`fileOffset`、`pointerSlot` 或 `resolvedRuntimeAddress`，并绑定独立 `profile`。同名函数在不同版本中不得合并。

历史候选补丁保留精确替换字节是为了逆向和迁移，不表示可直接应用。自动写回至少还需要目标样本身份、`expectedBytes`、覆盖长度、完整指令边界、ABI、桩入口/回跳、重定位和冲突检查；缺少任一项时保持只读。

## 提交格式

新增知识先写入对应版本的 `data/` JSON，不直接编辑生成页。所有实体至少包含：

```json
{
  "id": "type.version.unique-name",
  "title": "可检索的中文标题",
  "versions": ["6.5"],
  "profile": "profile.ccz65.example",
  "status": "candidate",
  "evidence": "source-reviewed",
  "sourceRefs": ["src.unique-id"]
}
```

不同实体还必须提供足以复用的核心字段：

| 类型 | 必需技术内容 |
|---|---|
| 地址/全局量 | 地址种类、值、画像、宽度、含义 |
| 函数 | 地址、调用约定、寄存器/栈输入、返回值、语义 |
| 数据结构/文件格式 | 步长或头部、索引公式、字段偏移、宽度、类型、编码 |
| 特效桩 | 桩风格、寄存器契约、压栈顺序、特效 ID、调度器和核心函数 |
| 补丁/Hook | 站点、原字节、目标字节、长度、指令边界、桩、回跳、重定位、冲突 |
| 剧本指令 | opcode、子命令、参数槽、参数类型、语义和写回风险 |
| 工作流 | 输入、连续编号步骤、门禁、产物和回滚 |
| 测试契约 | 可复现命令、目标、变更范围、断言、产物和失败含义 |
| 制作案例 | 目标、输入、过程、结果和可复用结论 |

完整命名、证据升级、来源登记和验收规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 生成与验收

```text
python tools/build_reference.py
python tools/build_index.py
python tools/validate_kb.py
```

校验器检查实体关系、画像绑定、补丁字节长度、剧本键唯一性、工作流顺序、来源引用、索引哈希、本机路径、敏感信息和生成物是否最新。干净克隆执行上述命令后必须产生零差异。
