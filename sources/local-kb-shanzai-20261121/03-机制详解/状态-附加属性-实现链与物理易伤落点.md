# 状态 → 附加属性：实现链、调用点与「物理易伤」落点（2026-10-16）

> 来源：用户口径 2026-10-16 14:2x「他们附加了相关属性，调用了，或者跳转到了哪些地址。有没有可能我们没有这个物理易伤的地址呢。
> 毕竟是附带状态，比如中毒后加血减半这个。正向和逆向都深挖一下。」
> 证据样本 SHA256：`6322C185072ECFFCA12E9557CE40D3470F4D8D40B0C7FCB3CAAC2506594AA612`（含 v6 中毒易伤补丁；未打补丁处字节与 `2A555B0B…` 同）

## 结论速览

1. **「状态 → 附加属性」在本引擎有三种落地形态**，其中**形态 A 是唯一"带数值参数"的原生形态**：
   - **A. 状态专用小函数**（`push 选择子 → call 0x423FE8 → 改 [ebp+8] → mov eax,[ebp+8] → ret 4`）——**中毒有且只有一个**：
     **`0x423FA1`**（`push 0x10 → call 0x423FE8 → shr dword [ebp+8],1`）= 「**中毒后加血减半**」。
   - **B. 价值判断/标志改写**：调用点自己读 `0x423FE8` 返回值，决定命中/伤害/仇恨/优先度（`0x43B64A`、`0x43B7B0`、`0x438A74`、`0x439955`、`0x43F93E` …）。
   - **C. 每回合结算**：`0x44DFFC`（选择子 `0x10`）→ `push 1 / push 0xF / call 0x44E024` = 中毒每回合扣 HPMax。
2. **`0x423FE8` 全文件共 34 个调用点**（本次线性扫描实测；含 `0x4240E2` 位测试助手与显示循环 `0x478A10`）。**没有任何一个落在物理伤害路径上**。
3. **物理伤害路径与状态增强完全"解耦"**：
   - 物理伤害主控 `0x405DE1`（**唯一调用者 `0x452802`**）；
   - 物理伤害公式 `0x43BC5A`（**5 个调用者**：`0x405E6D`(主控) / `0x419AED`(AI 预估) / `0x438A2A` / `0x438CCA` / `0x440668`）；
   - 这 5 个调用者**一个都没有** `call 0x423FE8`，也没有 `call 0x423FA1`。
   ⇒ **结论：「中毒 ⇒ 物理易伤」在本样本中不存在原生实现。**
4. **但「物理易伤」本身是有的**：特技 **`0xF6`（246「※物理易伤」）**，实现挂在**特技链第 8 槽**
   `0x43F277 → call 0x441D87`（`0x43F1E8~0x43F290`，预览/实战共用嫌疑链）。
5. **中毒的"原生落点"只有两处**：
   - 治疗/回复量减半：`0x423FA1`（被 `0x43C6A1`、`0x43CE4E` 两处调用，分别是回复量与策略形态的量）；
   - 每回合扣血：`0x44DFFC` → `0x44E024`。
   ⇒ **要「中毒 ⇒ 物理易伤」，只有"新增一个消费者"这一条路**（形态 A 的样板照抄，挂点必须选在物理伤害收口处）。

## 已确认事实

### 1. 状态测试函数 `0x423FE8`（选择子语义，与 `0x478A10` 一致）

```asm
00423FE8  push ebp / mov ebp,esp / push 0
00423FED  movzx edx, byte ptr [ecx+0x1E]   ; ECX = 战术单位
00423FF1  push edx
00423FF2  ... 循环 4 次：shr [ebp+8],1 → test al,1 ...
00424016  xor eax,eax                       ; 不命中
0042401B  ret 4                             ; 命中返回非 0
```

* **`unit+0x1E` = 4 组 2-bit 窗口**（2026-10-24 定案：窗口0 麻痹 / 窗口1 禁咒(封锁) / 窗口2 混乱 / 窗口3 中毒，窗口值 1~3 = 剩余回合数；本行原「单 bit 标志」表述作废，现行口径见 `03-机制详解\异常状态-现行结论.md`（L1）。现读依据（样本 `0F6220E4…`，快照 2026-10-24 23:45）：清除函数 `0x423FB9` 为 AND 语义（`0x423FDF = 20 51 1E`），置位函数 `0x4240D6` 为 OR（`0x4240FC = 08 51 1E`），施加初值表 `0x4240CE = 02 04 20 C0`、窗口掩码表 `0x4240D2 = 03 0C 30 C0`——两表口径均按窗口拆分，与单 bit 权重不可换算）。
  选择子（窗口口径，值 = `2<<i`）→ 状态：`0x02`=麻痹 / `0x04`=封锁 / `0x08`=混乱 / **`0x10`=中毒**——**是窗口选择子、不是 bit 位**；`0x423FE8` 只返回布尔、`0x01` 永不命中。
  第二处独立证据：显示循环 `0x478A10` 用 `mov eax,1 / inc ecx / shl eax,cl` 生成 `0x02/0x04/0x08/0x10`，
  名字表 stride 5：`0x486D06` 麻痹 / `0x486D0B` 封锁 / `0x486D10` 混乱 / **`0x486D15` 中毒**。

### 2. 形态 A 样板：`0x423FA1`（中毒 → 入参减半）

```asm
00423FA1  push ebp / mov ebp,esp
00423FA4  push 0x10            ; 中毒选择子
00423FA6  call 0x423FE8        ; ECX = 单位
00423FAB  test eax,eax / je 0x423FB2
00423FAF  shr dword ptr [ebp+8],1      ; ★ 中毒 ⇒ 入参减半
00423FB2  mov eax, dword ptr [ebp+8]   ; 返回改后的值
00423FB5  pop ebp / ret 4
```

**调用者只有 2 个**（本次全文件扫描）：

| 调用点 | 上下文 | 结论 |
|---|---|---|
| `0x43C6A1` | `callee` 返回后 `add eax,[ecx+0x10]`、与 `[ecx+0x14]` 比较、`0x43C6B8 call 0x41A6B9` | 回复/治疗量一类 |
| `0x43CE4E` | 前面 `0x43CE20 call 0x428a25`、`0x425AD9` 取百分比累加、`0x4210F4` | 策略形态的量 |

⇒ **这个函数就是"状态改数值"的官方样子**：一个入参、一个选择子、一个数值运算、`ret 4`。
**要加"中毒 ⇒ 物理易伤"，本质就是再造一个同形函数 + 在物理伤害收口处调用它。**

### 4. 物理伤害收口（要挂"物理易伤"只能挂这里）

```
0x405DE1 物理伤害主控（唯一调用者 0x452802；伤害落地 0x42E4FD）
  ├─ 0x405E6D call 0x43BC5A   ; 伤害公式（参数 push [ebp-0x20]=目标单位）
  ├─ 写槽：ctx(0x4927F0)+0x84+4*index
  └─ 0x405F0B call 0x42E4FD   ; 主目标伤害落地
0x43BC5A 的 5 个调用者：0x405E6D / 0x419AED / 0x438A2A / 0x438CCA / 0x440668
  ⇒ 全部**不查状态**（无 0x423FE8 / 0x423FA1 调用）
```

## 实现·使用方法

* 要"某单位打人更疼/挨打更疼"且**不依赖状态**：给装备/兵种挂特技 **`0xF6`（※物理易伤）**，特效值填百分比 ⇒ 零代码。
  （名表行 `0x4CC600 + 0xF6×16`，flag `02` = `+%d%%`）
* 要"**中毒状态**成为物理易伤来源"：只能新增消费者，两条路：
  1. **特技链第 8 槽**（`0x43F277 → 0x441D87`）：v3/v4/v5 实测**推进回合即进程终止**，**已判定不可用**（除非先拿到崩溃现场定因）。
  2. **攻击函数侧**（物理伤害收口）：v6 补丁已按此实现（挂点 `0x405E72` / `0x405E8D` → 洞 `0x4E4211`/`0x4E4271`），
     **判据用 `unit+0x1E` 的 `0x10` 位**，与引擎原生位序一致。
* 查状态一律用 `0x423FE8`（`push 选择子` + `ECX=单位`，`ret 4`）或等价的 inline `test byte [unit+0x1E], 位`。

## 风险与边界

1. **`0x423FA1` 的语义是"入参减半"**，与伤害无关；不要因为它"带中毒判定"就以为它参与伤害。
2. `0x439955` 已被改过（`nop` 填充 + `add [ebp-4],0`）⇒ 旧注释与样本不符是常态，**引用前复读**。
3. 表里"选择子 ≠ 注释状态名"的位置（`0x43B7AB`/`0x438A6F`）说明**同一段代码被不同 MOD 反复改过**，
   跨版本直接套用会踩坑。
