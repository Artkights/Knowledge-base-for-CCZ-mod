# 伤害数字显示链（飘字）

## 结论速览

- **伤害飘字的唯一绘制入口是 `0x44FB73`**（全 exe 只有 **3 个调用者**）：
  签名 `0x44FB73(单位编号, 数值, 颜色参数A, 颜色参数B)`。
- **物理攻击**的调用点是 `0x404A77`（在 `0x403240` 准备贴图之后）。
- **策略伤害**的调用点是 `0x421CAA`（对数值取负后显示，即策略显示为负数）。
- 该调用点正上方 `0x404A3C~0x404A56` 会读 `ctx+0x84`(物理伤害槽) 与
  `ctx+0x604`(暴击标志) 来**选颜色**：暴击用 `0x12/0x28`，普通用 `0x18/0x12`。
- ⇒ **任何写进伤害槽的值都会自动体现在飘字上**，不需要另做"显示补丁"。
  防御暴击 0x24 的减伤值（v5 补丁写入 `[ebp-0x28]`）因此天然会被正确显示；
  这正是 2026-10-13 那条待办「伤害预览显示减伤后的实际伤害」的答案。

## 已确认事实

### 1. 绘制入口 `0x44FB73`

```
0044FB73  push ebp / mov ebp,esp
0044FB76  mov  ecx,[ebp+8]        ; 参数1 = 单位编号(slot)
0044FB79  call 0x4061F9           ; -> 单位指针
0044FB7E  push dword [ecx+6]      ; 取单位数据
0044FB81  sub  esp,0x1c
0044FB84  push esp
0044FB85  call 0x47FC5A           ; 取显示字符串/坐标
0044FB8D  cmp  dword [ebp+0xc],0  ; 参数2 = 数值；为 0 直接跳走(不显示)
0044FB91  je   0x44FC3E
0044FB97  mov  ecx,0x4B4250       ; 全局显示上下文
0044FB9C  call 0x451A93 / 0x451AA4  ; 取坐标基准（用于数字对齐）
```

- `[ebp+0xc]` = 要显示的数值（血量伤害 / 策略伤害），**0 就不画**。
- `[ebp+0x10]`、`[ebp+0x14]` = 颜色/字号参数，由调用方按"暴击/普通"选择。

### 2. 物理攻击调用点 `0x404A3C`（★减伤显示的关键）

```
00404A34  call 0x403240           ; 准备该单位的贴图/位置（参数=坐标）
00404A39  mov  ecx,[ebp-4]
00404A3C  cmp  dword [ecx+0x84],0 ; ctx+0x84 = 物理伤害槽[0]
00404A43  je   0x404A60           ; 为 0 -> 看策略伤害槽
00404A45  cmp  dword [ecx+0x604],0; ctx+0x604 = 暴击标志
00404A4C  je   0x404A54
00404A4E  push 0x12 / push 0x28   ; 暴击配色
00404A52  jmp  0x404A58
00404A54  push 0x18 / push 0x12   ; 普通配色
00404A58  push dword [ecx+0x84]   ; ★ 数值 = 伤害槽（v5 写入的减伤值就是它）
00404A5E  jmp  0x404A73
00404A60  cmp  dword [ecx+0x254],0; 策略伤害槽
00404A67  je   0x404A7C
00404A69  push 0x18 / push 0x45   ; 策略配色
00404A6D  push dword [ecx+0x254]
00404A73  mov  cl,[ecx+1]          ; ctx+1 = 目标 slot
00404A76  push ecx
00404A77  call 0x44FB73           ; ★ 画飘字
00404A7C  call 0x41E5F6           ; 显示刷新
```

### 3. 其他相关函数

| 地址 | 调用者数 | 作用 |
|---|---|---|
| `0x44FB73` | 3 | **伤害/数值飘字绘制**（唯一入口） |
| `0x403240` | 10 | 单位贴图/位置准备（飘字前调用；参数为坐标） |
| `0x41E5F6` | 160 | 界面刷新（通用，飘字后调用） |
| `0x42F699` | 64 | 通用消息显示（对白/提示） |
| `0x4061F9` | 大量 | 单位 slot -> 单位指针 |

### 4. 与防御暴击 0x24 的关系

- 用户 2026-10-13 的待办是「**伤害预览显示减伤后的实际伤害**」。
- 结论：**飘字读的就是 `ctx+0x84` 伤害槽本身**，而 v5 补丁在写回伤害槽时
  已经把值改成了 `未暴击伤害 × (100−V)/100` ⇒ 飘字显示的**天然就是减伤后的值**，
  无需额外的显示补丁。
- 唯一例外：`0x405F24` 分支在 `+608`(连击) > 0 且目标有特效 `0x30/0x44` 时会把
  伤害槽清 0 —— 此时飘字**不显示**（`0x44FB8D` 的 `je` 直接跳过），符合"完全免伤"。

## 风险与边界

- `0x44FB73` 的 `mode` 分支多（暴击/普通/策略/负数），**改绘制会同时影响所有伤害类型**；
  要做"只改防御暴击显示"的补丁，应改**调用点**（`0x404A3C` 附近）而不是绘制函数本体。
- 颜色参数（`0x12/0x28/0x18/0x45`）语义未逐一确认，改动前应先实机截图对照。
- 本页结论来自**离线反汇编**；飘字是否真的按此路径显示，仍建议实机截图核对一次。
