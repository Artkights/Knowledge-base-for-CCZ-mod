## 四条路线（按风险从低到高）

### 路线 A｜只改立即数（**首选**）
| 项 | 内容 |
|---|---|
| 做法 | 把现成桩/现成立即数里的**特技号**换掉（如 `6A 16`→`6A 10`、`68 F6 00 00 00`→`68 FD 00 00 00`）|
| 代码量 | **1~5 字节，指令等长** |
| 依据 | `AGENTS.md` §3.6「只改立即数/操作数 ⇒ 安全」；库内 **3 个已实机落地实例**（`0xFC`/`0xF7`/`0xFD`）|
| 风险 | **最低** ✓ 不动指令边界、不动寄存器/栈契约 |
| 注意 | 若号从 `imm8` 变 `imm32`（或反之）会**改变指令长度** ⇒ 那就**不是**路线 A 了 |

### 路线 B｜空位搬移（把初版有、现版无的槽位搬回）
| 项 | 内容 |
|---|---|
| 做法 | 从**初版** `Ekd5.exe` 抄回一段桩代码到现版**同一地址**（指令等长时相对跳转/调用无需重算）|
| 代码量 | 约 21~66 字节（库内实例：`0x42E589` 55 字节；3 段 66/55/47 字节）|
| 依据 | `特技定义表与空位搬移.md`：**初版有查询、当前没有的 37 个槽位 = 被删掉的处理，可作搬回候选** |
| 风险 | 中（要确认目标地址在现版**是空洞**且指令等长）|
| 注意 | **⚠ 只有被引擎查询过的特技号才生效** —— 名称表空位 `0xF4`/`0xF9` **不在**查询列表 ⇒ 放上去**不生效** |

### 路线 C｜内联桩新增（**真·创造**）
| 项 | 内容 |
|---|---|
| 做法 | 在功能代码里内联一个桩：`mov ecx,<单位>` + push 参数（**允许动态**）+ `call 0x4101D9` + `test eax,eax` + `jz <skip>` |
| 代码量 | 约 21 字节 |
| 依据 | `桩函数.md` 第 9 条：「**模组新增特技用内联桩**」（跳过 `600XXX` 调度与 `9BBFE4` 查表）|
| **★ 模板实例** | **本会话扫描的 225 个调用点**（`大鲸鱼产生专用\_内联桩扫描.md`）；三型：**型A** `mov ecx` + 无 imm push；**型B** `mov ecx` + 2 imm push；**型C** 无 `mov ecx` + 1 imm push |
| **★ 契约（必读）** | `0x4101D9`：**stdcall，被调者清 16 字节栈**；参1（栈顶 push、`[ebp+8]`）= **特技号**；返回可能 `0xFF`；**⚠ 每次调用前必须重设 `ECX` = 单位指针** —— **两个桩连查不重建 `ECX` ⇒ 点击敌人（伤害预览走该链）闪退** |
| 风险 | **中低（风险取决于挂点，不取决于洞）**——5 件已验收实例全在函数体内点 |

### 路线 D｜借洞塞函数 + `JMP`（**条件放行**，2026-10-26 用户修正）

⚠ **后果不止闪退**：也可能是静默算错（v6 把单位指针当伤害值 ⇒ 156 万伤害），**后者更危险**。

## ★ 五步操作流程

```
① 定语义    写「行为契约六项」（触发条件/对象/输入/输出/必须保留的原生分支/边界场景）
② 选挂载点  在【资源①】里找"这一类作用"的域 ⇒ 决定挂在哪
③ 选路线    A(改立即数) > B(空位搬移) > C(内联桩) —— D 禁止
④ 写桩      照【资源②】的模板；⚠ 每次调用前重设 ECX；用【资源③】里"引擎查询过"的号
⑤ 落盘验收  §3.5 走 _dsh写锁.safe_write_exe（SHA→锁→备份→写→复读→审计）
            §3.6 只改立即数优先；动指令边界必须按【资源④】三步核洞
            五级证据：静态 → 文件读回 → 运行时读回 → 受控启动 → 游戏内验收（不可越级）
            判崩必须【无调试器】跑
```

## 风险与边界

1. **"新增特技"的真正约束不是"没地方写代码"，而是"引擎**只查询它认识的号**"** ——
   当前 exe 共查询 **105 个**；**名称表空位 `0xF4`/`0xF9` 不在查询列表 ⇒ 放上去不生效**。
2. **`ECX` 契约是最容易踩的坑**（库内明确记：两个桩连查不重建 `ECX` ⇒ 伤害预览闪退）。
3. **说明栏（flag）分派只收 flag + 特效值、不收特技号 ⇒ 同 flag 的技能无法区分**；
   分派母函数入口是 **`0x452C81`**（`0x42834D` **不是**入口）。
4. **判崩必须无调试器** —— 附加/暂停态 `debug_stop` 会让进程消失，污染判定。
5. **`.text3` 的零区不都是洞**（`0x512DC0` 就是活跃表）⇒ 落洞前**必过判洞三步**。

## 7. ★★ 资源索引补遗（2026-10-17，DSH）：**攻击范围 / 形状类特技的入口**

> 来源：`大鲸鱼产生专用\_注入地址占用登记.py` 之外的静态勘察（详见
> `03-机制详解\特技0x17-奋战攻击次数改造.md` §86 / §88 / §92 / §94）
> 样本：`Ekd5.exe` SHA `2AC91CB8…`（= v1 + 用户口径 8 字节）

### 7.1 若要做「改攻击范围 / 形状」类特技，这里是入口
| 地址 | 作用 | 证据 |
|---|---|---|
| **`0x4D1400`** | **形状表**：`[动作码] → 坐标偏移对数组`（每对 2 字节，`FF FF` 终止）| §94.1 现读：`[2]→0x4D2228` = `01 00 FF FF`（`(1,0)`）；`[4]→0x4D2232` = 5 个点 |
| **`0x436511`** | **动作码分派器**（参 3 = 4 字节"动作码包"，**按字节索引**）| §92.1 现读：`0x436567 mov al, byte [eax + ebp + 0xC]`；`0x43659C mov edx,[eax*4+0x4D1400]` |
| **`0x4366F0`** | **动作码 `0x0A` = 遍历全图**（双层循环 `0x4B422D` 高 × `0x4B422C` 宽）| §94.2 现读 |
| **`0x50`（哨兵）** | 传给 `0x436511` 的参 3 写 `0x50` ⇒ **交给 `0x43F8C0` 算出动作码包**（常见返回 `0xFFFFFF0B` = `0B FF FF FF` = 全跳过）| §92.2 现读 |
| **`0x43F8C0`** | 算"动作码包"的**通用辅助**（**22 个调用者**，**不是特技桩**）| §91 三条判据 |
| **`0x42466D`** | 扫单位表找匹配槽位（`[记录]==参数` + `al==2` + `0x41B500()>0`）| §94.3 现读 |
| **`0x4B422C` / `0x4B422D`** | **地图宽 / 高**（运行时写入；现读 `00 00`）| §94.2 用作循环边界 |
| **`0x436499`** | 取周边目标列表 ⇒ 返回固定 `0x500EA5` | §86 |
| **`0x419A67`** | `0x4AC748`（原始候选）→ **去重** → `0x500EA5` | §86.2 |
| **`0x437AFF`** | 范围标记器（坐标 → 三张并行标记数组 `+0` / `+0xC80` / `+0x12C0`）| §90.3 现读 |

### 7.2 动作码语义（现读）
| 值 | 处理 |
|---|---|
| **`0xFF`** | 跳过（空/结束）|
| **`0`** | 特例（还需 `[ebp-8]==0`）|
| **`0x0A`** | **走 `0x4366F0`（全图）** |
| **`0x0B`** | 跳过（**安全的空动作**）|
| **`1` ~ `0x25`** | **查 `0x4D1400 + v*4` 取"坐标偏移对数组"** ⭐ |

### 7.3 ⚠ 使用这条链的**风险提示**
1. **`0x4AC748` 是"引擎通用候选缓冲区"（13 处引用）** ⇒ 改它**影响面大** ⚠
2. **`0x43F8C0` 有 22 个调用者** ⇒ 改它**影响 22 处** ⚠
3. **`0x436511` 是 `0x4091F4` 的核心**，而 `0x4091F4` 又被 `0x436499`（奋战 + 引导**共用**）调用 ⇒
   **改这里会同时影响奋战与引导** ⚠
4. **`0x4D1400` 表项 `[11]` 指向 `.code`（`0x452958`）是混杂项** ⇒ 表**可能不是单一用途** ⇒ 改表要逐项核对

### 7.4 ⇒ 建议路线（若要新增"范围/形状"类特技）
* **改形状** ⇒ **改 `0x4D1400[n]` 指向的坐标对数组**（**纯数据**，风险最低；但要注意共享）
* **改触发条件** ⇒ 在 `0x436511` 的 `cmp`/`jae` 处**改立即数**（§3.6 的低风险路线）
* **不要**改 `0x43F8C0` / `0x4AC748`（共享面太大）
* ⚠ **落点前必做**：`_注入地址占用登记.py --check` + **四条硬判据**（`01-核心引擎\注入落点判定-四条硬判据.md`）
