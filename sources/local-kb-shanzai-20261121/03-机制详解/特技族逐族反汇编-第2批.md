```bat
python 大鲸鱼产生专用\_族分析器.py --family "<族名>" <域…>   :: 生成/重生成族报告

python 大鲸鱼产生专用\_批量跑族.py 0 26                          :: 一次性重跑全部 26 族
```

**★ 本批确立的第二条模式（除"1 桩 + N 域"外）**：
**"参数可能内嵌在代码字节里"** —— 例 `0x40CED4` 用 `movzx eax, byte [0x406b8a]` 取参数。
⇒ 用"桩扫描器"找桩时会**漏掉这一类**；检漏办法：搜 `movzx reg, byte [0x40xxxx]` 形态。

## 风险与边界

* 全批**未实机验证**；"定名"基于静态反汇编 + 调用者反查，**不排除引擎里另有分支**。
* `0x40CF5C`（反弹异常攻击·逐槽位）里的 `[edx+0x18]` 与第 1 批 `0x43C940` 的 `[unit+edx+0x18]`
  **是同一处 6 槽位数组**（跨族复用）⇒ 该数组语义值得单独定位。

## ★ 2026-10-21 20:xx 现读补齐：`0x492E04` 与 `0x423971`

- 样本 SHA256：`2A853B0189248761F7FC327419DE3CE9489592AD329289ABCED804258220AB21`。
- `0x492E04` 不是独立的未知全局：结构页已确认它是战斗上下文基址 `0x4927F0 + 0x614` 的别名，对应 `COUNTER_ATTACK_FLAG`，用于反击及反击后反击标志。`0x417941` 对它显式清零，属于反击链状态复位。
- `0x423971(arg)` 先调用 `0x42C632(arg)`：`0x42C632` 以 `0x47EB97()` 的返回值为基础加上参数，并把结果写入全局 `0x4B1B18`。`0x47EB97` 读取一个外部计数并除以 `0x32`，因此这是按 50 为单位的累计值更新。
- 随后 `0x423971` 调 `0x42C4E5`；后者循环调用 `0x4750E0`，直到返回非零。`0x4750E0` 读取 `0x500AD8` 的阶段字、`0x4B3D18` 的场景/回合值和 `0x4750DC` 表，递增 `0x4750DF`，在达到 `0x32` 时折返，并继续调用 `0x411195`、`0x40C19D`。这是一条阶段计数/事件刷新链。
- `0x47EAC4` 则是该刷新链使用的事件轮询包装：构造 `0x1C` 字节局部结构，经 `[0x4862AC]` 获取事件，再由 `[0x486310]`、`[0x486314]` 处理。
- 因而 `0x423971` 的静态语义不是“单纯按厚实表皮次数循环施加”，而是“更新 `0x4B1B18` 累计量并等待阶段/事件刷新完成”；厚实表皮域只是以次数调用它的一个上层入口。具体 `0x4B1B18` 的业务名称仍待运行时或更多调用者语境确认。

证据：`02-数据结构\\战斗数据结构.md:8,69,100`；`03-机制详解\\特技族逐族反汇编-第2批.md:31,38,73`；`_族核心.py 0x423971 0x42C632 0x42C4E5 0x47EB97 0x4750E0 0x47EAC4`。未实机验证，未写 EXE/剧本/存档。
