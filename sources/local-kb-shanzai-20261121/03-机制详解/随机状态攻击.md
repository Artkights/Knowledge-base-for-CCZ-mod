# 随机状态攻击 (随机状态攻击) 机制分析

## 结论速览

- 个人特效号 `0B` (11)、装备特效号 `5E` (94)；能力检测点位于 `405A59` 附近，桩函数内联在 `472C41`，调用者为后伤害效果调度器 `405966`（同一调度器内 `472D48` 是属性下降）。
- 四种异常状态写在战术单位的 `unit[1E]` 状态字节：中毒 `C0`（位 6-7，每回合损失 HP）/ 麻痹 `30`（位 4-5，无法行动）/ 禁咒 `0C`（位 2-3，无法使用策略）/ 混乱 `03`（位 0-1，行动不受控制）。
- 随机选择状态索引调用 `47FB13`，参数 `04`（4 种异常状态）→ 索引 0-3。
- 与属性下降攻击的分工不可混用：`472C41`（个人特效号 `0B`）写状态字节 `1E`、判定点 `405A59`；`472D48`（个人特效号 `0C`）改属性数组 `21-26`、判定点 `472D63`。
- ⚠️ 页内 `472C41` 的汇编只给出「预期汇编结构（类比属性下降）」，调度调用写作 `600XXX` 占位，前置条件检查与状态应用段落均未确证（待验证）。

## 详细记录

#### 概述

曹操传中存在一种"攻击命中后使目标随机获得异常状态"的能力，其个人特效号为 `0B` (11)，装备特效号为 `5E` (94)。该能力的检测点位于 `405A59` 附近，桩函数内联在 `472C41` 中。

**四种异常状态**：中毒、麻痹、禁咒、混乱。

**关键特征**：与属性下降攻击（472D48）类似，该能力同样使用内联桩函数架构，位于后伤害效果处理流程中。

---

#### 完整调用链

```
后伤害效果调度器 405966 (attacker, target)
    │
    ├── 40399B: 伤害效果执行
    ├── 472C41: ★ 随机状态攻击（本文档所述）← 判定点 405A59
    ├── 472D48: 属性下降效果
    ├── 4039F4: 伤害动画/音效
    ├── 436392: 前置条件检查
    └── ...
```

##### 预期汇编结构（类比属性下降）

```asm
; 472C41: 后伤害随机状态攻击入口
; 参数: [ebp+08] = attacker_ptr (攻击者)
;       [ebp+0C] = target_ptr  (被攻击者)
472C41: push ebp
472C42: mov ebp, esp
          ...
          ; 前置条件检查
          ...
          
; ===== 内联桩函数: 检测 5E/0B 特技 =====
          mov ecx, [ebp-08]     ; ecx = attacker
          push 01               ; 效果值标志 = 1 (无效果值)
          push 01               ; 叠加标志 = 1 (不可叠加)
          push 5E               ; ★ 装备特效号 = 5E (94)
          push 0B               ; ★ 个人特效号 = 0B (11)
          call 600XXX           ; → 调度函数
          test eax, eax
          jz 472CXX             ; 无特技 → 退出
          
; ===== 随机状态应用 =====
          push 04               ; 参数 = 04 (4种异常状态)
          call 47FB13           ; ★ 随机选择状态索引 (0-3)
          ...
          ; 应用异常状态到目标
          ...
          
472CXX: mov esp, ebp
472CXX: pop ebp
472CXX: ret 08
```

#### 四种异常状态详解

##### 状态位编码

异常状态存储在战术单位的 `1E` 偏移处（状态标志字节）：

```
unit[1E] = 状态标志字节
```

###### 位结构

| 位 | 含义 |
|----|------|
| 位 0-1 | 状态类型 |
| 位 2-3 | 状态等级/强度 |
| 位 4-5 | 麻痹/禁咒状态 |
| 位 6-7 | 中毒状态 |

###### 四种状态对应

| 状态 | 位掩码 | 效果 |
|------|--------|------|
| 中毒 | `C0` (位 6-7) | 每回合损失HP |
| 麻痹 | `30` (位 4-5) | 无法行动 |
| 禁咒 | `0C` (位 2-3) | 无法使用策略 |
| 混乱 | `03` (位 0-1) | 行动不受控制 |

#### 设计注意事项

若要在模组中修改此机制：

1. **修改状态类型**：调整随机选择的状态范围
2. **添加新状态**：扩展 `1E` 字节的位定义
3. **修改命中概率**：调整随机判定逻辑
4. **状态持续回合**：修改状态持续时间相关代码
