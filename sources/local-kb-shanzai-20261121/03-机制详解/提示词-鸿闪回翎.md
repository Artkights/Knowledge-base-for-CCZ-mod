## 结论速览

1. **语义**：我方**持技持有者 A 自己**被敌军物理攻击时，若 **A 未处于麻痹**、且 **A 的正后方一格可站**
   （格内无单位 + 地形可走），则 A **完全闪避这次攻击**、**立刻后退一格**、并**反打原攻击者一次**。
   **任一条件不成立 ⇒ 本特技完全不生效**，A 按正常流程受伤。
2. **触发者 = 持有者自己**（用户 2026-10-28 确认；不是"持有者在场给全队"）。
3. **麻痹检查用现成函数**：`push 0x02` + `ECX=单位` + `call 0x423FE8`，**返回非 0 = 处于麻痹 ⇒ 不触发**
   （`0x423FE8` 自带 2-bit 窗口循环，掩码实测 `0x02/0x04/0x08/0x10`）。**禁止自己读 `unit+0x1E` 判位**。
4. **「正后方」= A 自己朝向（`unit+0x0F`，`0..3`）的 +2 取模**。参考样本的方向偏移表在
   `0x48DF68`（ΔX = `0,+1,0,-1`）/ `0x48DF6C`（ΔY = `-1,0,+1,0`）——
   **⚠ 本样本现读 `0x48DF68` 起 40 字节全 `90`：该表在本样本不存在**，必须重新定位或改用引擎同型算式（§六.3）。
5. **移动走引擎现成链**（用户给的"先制攻击那一套"= 斗将域）：`0x437E23`（移动路径评估）
   → `0x437D59`（候选点探测）→ 包装器 `0x428B7A(…, 0/1, 4)` **`0`=预判 / `1`=实际执行**。
   现读全部在位：`0x428B7A` 3 参 `ret 0xC` → 内部 `call 0x428A53`（斗将域，71 条指令，**只处理第 3 参 `== 4`**）
   → 第 2 参 `== 1` 时再调 `0x4749B5`（全映像唯一调用者就是 `0x428B7A`）。
   ⚠ **`0x428A53` 内部有 `[record+0x22]` 次数门**（`0x428ABE cmp byte [ecx+0x22],al` / `jae`，命中后 `inc`）；
   该槽已闭合为**斗将专用**（`0x45D390 → 0x4101D9(0x52,0x51,0,0)`）⇒ **本特技不复用 `0x428A53`**，
   改为洞内自建候选遍历 + 直接调 `0x4749B5`（§六.4）。计数另起新字段，**绝不共用 `+0x22`**（用户 2026-10-28）。
6. **必定闪避，不是概率**；与 `4018` 集气闪避是两条独立路径，测试结论要分别标注。
7. **触发面只限「敌军 → 我方」的物理攻击**；策略、反击、连击后续段都不触发。
8. **号位 = `0x88`**（用户 2026-10-28 定）。现读名表 `0x4CCE80` = 「空置」/ flag `0x0B`；
   三个桩入口共 **221** 个调用点（`0x4101D9`×150 / `0x42518F`×64 / `0x413009`×7 现读）**无一 `push 0x88`**
   ⇒ 空闲可占。全 `.code` 内 `0x88` 立即数仅 1 处（`0x412DA6`：`push 0x88` 送 `0x43E6AA` 的**位标志值**，
   最终进 `0x40DDAF` 的 `test al,0x80` 分支）⇒ **不是特技号查询**。

## 一、核心语义

> 持有者 A 被敌军物理攻击 → A 未麻痹 → A 的正后方一格可站 → A 闪避 + 后退一格 + 反打原攻击者。

| 参数 | 取值 | 做歪长什么样 |
|---|---|---|
| **谁对谁** | A（被攻击的持有者）→ 后撤 → 反打**原攻击者** | 反打别人 ⇒ 变成"换目标"；后撤到攻击者背后 ⇒ 不是"正后方" |
| **什么时候** | 攻击已确认、**伤害结算之前** | 伤害已扣完再位移 ⇒ 变成"挨打后撤退"，不是闪避 |
| **做到什么程度** | **本次攻击整段作废**（含连击后续段）+ 位移 1 格 + 一次攻击 | 只免第一段、连击第二段照打 ⇒ 假闪避 |

**判定顺序（全部成立才动手；任一不成立就"什么都不做、不扣次数"）**

```
① 桩查询特效值 v（号位走参数字节）；v == 0 → 退（视为未持有）
② 本次是「敌军 → 我方」的物理攻击
③ A 未麻痹            → push 0x02 / ECX=A / call 0x423FE8 ；非 0 即退
④ 本回合次数未满       → count[slot] < v
⑤ 后方格在战场边界内   → 朝向 +2 & 3 → ΔX/ΔY → (x+ΔX, y+ΔY)
⑥ 后方格无单位         → Data 号 == 0xFFFF 为空（刘备 Data 号就是 0，不能用 ==0 判空）
⑦ 后方格地形可通行     → 用引擎现成判定函数，不许自己读地形表
  ↓ 全过
⑧ 闪避本次攻击 → ⑨ 位移一格 → ⑩ 反打攻击者一次 → ⑪ count[slot]++
```

**扣次数口径**：只有 **⑤~⑦ 全过并进入 ⑧** 才 `count[slot]++`；①②③④⑤⑥⑦ 任一不过 ⇒ **不扣**。
`++` 放在三个动作**发起之后**（`⑪`），不放最前 —— 否则"判定成立但位移被引擎拒绝"会白扣。调试期发现"没动却扣了"就是 `++` 位置写错。

**三组推论（落实要点，不是并列需求）**

1. **「闪避」必须是原生路径或整段取消**：只把伤害清零会留受击动画 + 连击后续段照打。
   优先让命中判定判失败（原生闪避），退路是在攻击入口整段取消（与执天之行同型）。见 §六.2。
2. **「可站」= 无单位 + 地形可走，两条都要**；只看其一 ⇒ 会挪到河里或叠人。
3. **「反打」是一次独立攻击动作**（走完整命中/伤害链），不是追加伤害；它自己也可能被对方特技改写，
   这是正常的，不要额外拦。**但反打不得再次触发本特技**（否则无限递归）。

## 二、与现有特技的关系（会撞车的先对齐）

| 特技 | 关系 | 处理 |
|---|---|---|
| **执天之行 `0x96/0x97`** | 同在"敌军攻击我方 → 伤害结算前"拦截（`0x410F37`）；它做先手策略 | **执天之行优先**：它可能直接击杀攻击者，攻击者死了就没有反打对象；攻击者仍活着才轮到本特技 |
| **回马攻击 `0xA9`** | 用 `+0x0F` 朝向判侧背加成 | 不冲突，但**共用朝向字段** ⇒ 位移改朝向后它的方位会变，测试要单独标注 |
| **劲透攻击 `0xDF`** | 单目标穿透加成 | 不冲突 |
| **物理免疫（距离判定）** | 相邻格免疫 | 叠加时"免疫"先成立 ⇒ 本特技不触发（本来就没伤害）|
| **借力打力 `0x57`** | 把伤害转给最弱单位 | 不冲突：本特技是**取消**伤害，取消了就没有可转的量 |
| **与子同袍 `0x99`** | 分摊伤害给持技者 | **冲突**：分摊发生在伤害写入阶段 ⇒ **本特技优先**（先闪避，分摊不再执行）|

## 三、号位与换号（用户 2026-10-28 定 `0x88`）

| 项 | 值 |
|---|---|
| 特技名 | **鸿闪回翎** |
| 特技号 | **`0x88`**（现读名表 = 「空置」/ flag `0x0B`；151 个桩调用点零 `push 0x88` ⇒ 空闲）|
| 名表 VA | `0x4CC600 + 0x88×0x10` = **`0x4CCE80`** |
| 名表写入 16 B | **现读行布局 = 名字 12B(GBK，尾 0) + 3×`00` + flag 1B（byte[15]）**；<br>`鸿闪回翎` = GBK 8 B，写 `BA E8 C9 C1 BB D8 F4 E1 00 00 00 00`（**翎 = `F4 E1`**，以 Python `encode('gbk')` 为准）；<br>flag 建议 **`0x06`（显示「%d次」）** —— 与「特效值 = 每回合次数上限」语义一致（`0x87` 移星易宿次数同族）|
| **号位载体** | **参数字节**（与 `0x6F` v34+ 同型：新增 1 B 参数，换号只改 1 字节）；值域 **`00~FF`**（单字节，写死）|
| 已知不可选 | `0x6F`（转移策略在装）、`0x99`（与子同袍）、`0x96/0x97`（执天之行）、`0x9C/0x9D`（撞宝物表）、`0x98/0x9B`（有功能）|
| 候选（2026-10-26 全表口径）| `0x9A`、`0xED`、`0xF4`~`0xF9`、`0xFC`、`0xFD`、`0xFF` —— **实现时必须现读复核**，不许照本页直接写 |

**换号 SOP**：同通用模板 §2 三处同步（号位载体 + 新名表行 + 旧行清「预留」），**同一次写完**。

**两格制**：格1 = **持有**（桩查询命中即启用）；格2 = **每回合次数上限**（`count[slot]` 记"本回合已用"，每回合刷新）。

- **次数上限 = 特效值**（用户 2026-10-28 定 **A**）：桩查询返回 `v`；`v == 0` ⇒ 不触发（视为未持有）；
  `v > 0` ⇒ 本回合可触发 `v` 次。值域按桩返回写死 **`00~FF`**（单字节）。
- **不许复用 `record+0x22`**（斗将次数格，`0x45D390 → 0x4101D9(0x52,0x51,0,0)`），
  也不许用 `+0x23`（执行器 `0x41058D` 自增）、`+0x24`（0x40 死亡结算计数/bit7）；
  **计数一律放补丁自带的 `count[slot]` 数组**（§6.4，用户 2026-10-28 定"每单位各自一份、每回合刷新"）。

| 计数字段候选 | 结论 |
|---|---|
| `U+0x22` | ❌ 斗将次数格 |
| `U+0x23` | ❌ 执行器自增链 |
| `U+0x24` | ❌ 0x40 死亡结算计数 + bit7 待处理位 |
| `U+0x20/+0x21` | ❌ 限制区域/第二目标坐标（来源冲突，不可写）|
| `U+0x24..+0x2F` 全段 | ❌ **无常住空位**：被三组 dword 打包访问整体覆盖 —— `[reg+0x24]` 7 处（盖 0x24-0x27）、`[reg+0x28]` 9 处（盖 0x28-0x2B）、`[reg+0x2C]` 2 处（盖 0x2C-0x2F）；2026-10-28 capstone 全 `.text` 扫描 |
| **补丁自带 `count[slot]` 数组** | ✅ **选定**：250 B，按槽号索引，随补丁装/卸，零冲突 |

## 四、实现要点

1. **桩查询**：`push 0 / push 1 / push <桩内号> / movzx eax, byte [<参数>] / push eax / call 0x42518F`，
   `test eax,eax / je 退`。**每次调用前 `ECX` 必须是单位指针**（两个桩连查不重设 ⇒ 预览闪退）。
   ⚠ 读 1 字节必须 `movzx`：`0x6F` v28 的 `0x458400` dword 读窗口坑。
2. **麻痹**：`push 0x02 / ECX=A / call 0x423FE8` ⇒ `eax != 0` 直接退出。
   **不许**自己解 `unit+0x1E` 的位（库内三处口径互斥，见 §六.7）。
3. **后方格**：`idx = (byte[A+0x0F] + 2) & 3`；`(x,y) = (byte[A+0x06], byte[A+0x07])`；
   增量取**本样本引擎表** `0x435A3E`（ΔX，步长 2）/ `0x435A3F`（ΔY，步长 2）；**边界必须先判**
   （`新X < byte[0x4B422C]`、`新Y < byte[0x4B422D]`）。
4. **可站判定（三查都要）**：`0x435884(&格)` 得槽号（`0xFF` = 空）→ `0x412557(格)` 得地形
   → `byte [0x4A3517 + 兵种系×0x3C + 0x1E + 地形] != 0xFF`。兵种系走 `0x4061E4 → 0x40BF0C`。
5. **位移**：**调引擎原生后撤 `0x4594EA(0x404+槽, X', Y', 4)`**（§6.5；`0x500AD3` 置 1/清 0），
   **返回 `-1` ⇒ 整技不生效**。**不调 `0x428B7A` / `0x428A53`**（会 `inc` 斗将次数格 `U+0x22`）；
   **`0x4749B5` 是攻击执行器，不是移动器**（§6.4/⑥）。**写后必须复读**：`+0x06/+0x07` 已变 **且** 原格 `0x435884` 返回 `0xFF`、新格返回 A 的槽号。
   回退方案（若原生后撤有副作用）：`0x40D84B` 清格 → 写坐标 → `0x41BD67` 登记（24 B，钩点与判定段不动）。
6. **免伤**：**走 B（整段取消）** —— 钩点处直接返回 `AL=0xFF`（执天之行 v32 已验收同型）。**禁止**伤害落地后清零。
7. **反打**：`0x43DB23(参1=A 单位指针, 参2=0, 参3=攻击者槽, 参4=1)`（物理攻击执行体，`ret 0x10`）。
   **不许**手写 `ctx+0x84` 造伤害；**不许**用 `0x4749B5`（它要候选记录、且是另一条攻击链）。
8. **一次性**：同一次被攻击最多触发一次；反打本身不再触发本特技。

## 五、禁止项（本特技专属）

1. **不许把「正后方」理解成"相对攻击者的反方向"** —— 是**被攻击者自己的正后方**（用户确认）。
2. **不许裸写 `unit+0x06/+0x07` 当位移** —— 走 §6.5 的引擎原生后撤 `0x4594EA`（占位/渲染/动画由引擎自己同步），并复读两格 `0x435884`。
   <br>（历史备注：旧句"必须走 `0x428B7A` 链"已作废——该链执行体 `0x4749B5` 实为**攻击**执行器。）
3. **不许用 `0x406710` 的返回值直接当阵营** —— 库内两处口径冲突（一处"势力判定 1=我方/友军、0=敌军"，
   另一处记为"命中/格挡"）。用前必须现读定案，否则会"闪避友军攻击"。
4. **不许自己解 `unit+0x1E` 判麻痹** —— 库内三处位定义互斥（位 0-1 / 位 4-5 / 单 bit `0x02`）；
   `0x423FE8` 已封装窗口循环，直接用。
5. **不许照抄 `0x48DF68` / `0x48DF6C`** —— 本样本该址全 `90`，表不存在（§六.3）。
6. **不许伤害落地后再清零** —— 会留受击动画 + 连击后续段照打。
7. **不许把反打写成追加伤害** —— 必须是独立攻击动作。
8. **不许改 `0x441EE7`**（攻击前朝向临时储存）—— 那是回马攻击 `0xA9` 的字段。

**洞内判定顺序（与 §一 的 11 步一致）**：返回地址门 → 槽→A → 阵营(2/0) → 特效值 v → **相位清零** → `count[slot] < v`
→ 麻痹(`push 2`) → 后方格(方向表) → 边界 → 写入自带格变量 → 格内无单位(`0x435884`) → 地形(`0x412557`)+移动消耗
→ **原生后撤 `0x4594EA(0x404+槽, X', Y', 4)`（返回 `-1` ⇒ 整技不生效）** → `count++` → 反打(`0x43DB23`) → `popad; AL=0xFF; jmp 0x410F98`。

**⚠ 已知坑（v1 崩栈根因，v1b 已修）**：`0x412557` 的出口是 **`ret 4`**（`0x412597 pop eax / 0x41259B ret 4`），
调用方**不得**再 `add esp,4`；v1 多写了一条 ⇒ 栈多退 4 字节 ⇒ `popad` 取错 EBP ⇒ `jmp 0x410F98` 后
`mov esp,ebp` 用垃圾值 ⇒ 跳进 `.text3` 零区（用户 debug 文件报 **`0x4FDD88`**）。v1b 已删该条，
并在生成器里加了 **`SIG = (压入字节数, 自身 ret N 清参数)` 双值断言**（含 `popad` 前栈净差必须为 0）。
现读 ret 口径：`0x4101D9/0x4594EA/0x43DB23 = ret 0x10`、`0x423FE8/0x412557/0x4061E4 = ret 4`、
`0x42DC72 = ret 8`、`0x435884/0x410F0A/0x4061F9/0x40BF0C = 平 ret（调用方清）`。

**待实机验证（写盘后第一次 1 回合就要盯的三条）**：
1. 反打 `0x43DB23` 在 `0x410F1C` 帧内递归调用，会写全局 `0x500E9A/B` 与 `0x4927F0` ctx；外层随后仍会走 `0x42C144` / `0x4223A9` ⇒ 看**攻击者与旁观单位行动状态是否正常**（异常就改成"延迟到外层返回后再反打"或用 `0x4749B5` 候选链）。
2. 连击的第二段是否会被本特技再吃一次（同一被攻击最多触发一次）；`count[slot]` 每回合清零用 `0x4B3D0A`+`0x4B3D18` 双值（v32 惯用法）。
3. 位移后 `0x435884` 复读：旧格 `0xFF`、新格 = A 槽号，且渲染位置跟上（`0x41BD67 → 0x43FCC9 → 0x418C90/0x42A5B5`）。
