## 结论速览

1. **触发点必须在 `0x410F37`（`0x410F1C` 结算前）**，不是 `0x435829`（通用伤害结算，16 调用点，已晚于敌人出手）。
2. **保留 v22 的全槽扫描**：持有者不必正好是被攻击的单位；但**排除被攻击者本人**（候选槽 == `[ebp+8]` 低字节 ⇒ 跳过）。
3. **施法必须走原生 `0x41CECC` 三参**（目标, 施法, 策略号）；**不要裸调 `0x412B30`** —— 它依赖 `0x401DFF` 预置，裸调会把所有候选判成“不在范围”（v30 实测不触发）。
4. **击杀 ⇒ `AL=0xFF` 跳 `0x410F98`**；4 个调用点全部 `cmp al,0xFF; je`，直接跳过 `0x4064F1` 结算 ⇒ 敌人这一击打不出来。
5. **洞内不写 HP、不写 view**；死亡退场由 `0x40502B → 0x441744` 原生执行。
6. `0x5E` 未被禁用：洞未命中时 `call 0x41932B` 走原生 0x5E；只有“同时带 0x96 且条件命中”时 0x96 优先。
7. 与 `0x86/0x87` **无计数冲突**：0x86 用 `[unit+0x23]`，本功能用私有表 `0x430C00`；`0x430980` 旧洞为死代码（全 EXE 0 条 call/jmp 引用）。

## 机制

- `0x410F1C` 参数：`[ebp+8]` = 本次**被攻击目标槽**；`[ebp+0xC]` = 行动单位（攻方）；`[ebp-8]` = 先手资格单位（`0x41AABC` 返回，可能是护卫者）。
- `0x41AABC`：遍历 `0x4AC748`（0xFF 终止）选人；无候选时返回 `[ebp-0xC]` 初值 = 参数 1 槽的单位，**永远不是 0 / 代码地址**。
- `0x41CECC` = `ret 0xC`，三参；内部 `0x401DFF` 预置 → `0x412B30` 范围门 → `0x4179B4` → `0x425627`。
- 策略伤害应用点 `0x422999`：`cmp 伤害, 当前HP; jle; mov 伤害, 当前HP` ⇒ `HP − 伤害 ∈ [0, HP]` ⇒ `0x43F6DB` 可写 0、**不会写负值**（“保底 1 血”说法不成立）。
- 退场唯一执行器 `0x441744`（门 `[unit+0xC]==2`）；`view=3` 只由 `0x443120` 设置（全库 3 调用点，其中 `0x44181F` 在 `0x441744` 内）。
- 整表扫描 `0x40502B`：唯一直接调用者 `0x42BC1C`（`0x42BC14` 首步）；`0x4065D9 = 0x44C601 + 0x42BC14`；原生范例 `0x439413`：`0x439466 call 0x43DB23` → `0x439470 push 0x4B3D08; call 0x4065D9`。

## 实现（v32）

| 段 | 内容 |
|---|---|
| `0x435829` | `55 8B EC 6A 00`（恢复原序言，撤销 v22） |
| `0x410F37` | `E9 44 FE 01 00` → `0x430D80` |
| `0x430D80` | 洞 409B（0x200 段），数据区 `0x430F60` |

洞流程：

1. `0x4B3D0A` / `0x4B3D18` 变化 ⇒ 清 `0x430C00..0x430CF9`（250B）；
2. 目标 `[ebp+0xC]` 非空、`0x406710 == 0`（敌方）、HP>0；
3. 记录 `DEFSLOT = [ebp+8]` 低字节（被攻击者槽）；
4. 槽 `0..0xFA`：跳过 `槽 == DEFSLOT`、`[unit+0xC] != 2`、HP<=0、阵营 `== 0`；
5. `0x4101D9` 查 `0x96`（值=策略号+1）与 `0x97`（次数，0 视作 1），按槽查 `0x430C00`；
6. `0x41CECC(目标, 持有者, 0x96值-1)`；成功 ⇒ 计数 +1；
7. 目标 `0x41B500 == 0` ⇒ `popad; AL=0xFF; jmp 0x410F98`；否则 `popad; jmp 0x410F61`；
8. 未命中 ⇒ `popad; call 0x41932B; jmp 0x410F3C`。

数据：`0x430B06/07` 相位；`0x430C00` 次数；`0x430F60/64/68/6C/70` = 目标/持有者/槽/策略号/被攻击者槽。

## 判据

- 敌军攻击**其他友军**且持有者在场 ⇒ 先手施法；击杀 ⇒ 敌方该击不出伤害。
- 敌军攻击**持有者本人** ⇒ 不触发（v32 排除）。
- 无持有者 / 次数用完 ⇒ 走原生 0x5E（`0x41932B`）。
- 死亡退场：无残尸、悬停预览不显示 0 号（原生 `0x441744`）。

## 已知取舍

- 施法成功即扣 1 次（目标未死也扣）；射程门失败不扣。
- `0x96` 与 `0x5E` 同时存在时 0x96 优先。
- 洞内用 `pushad/popad` 保寄存器；`0x41CECC` 会破坏 EBX/EDI，已在设计上规避（工作变量放在洞内数据区）。

## 版本沿革

- v22：钩 `0x435829`，手写 HP/view ⇒ 敌人仍能攻击、残尸、预览 0 号（结构性错误）。
