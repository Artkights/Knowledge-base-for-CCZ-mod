# 能力辅助特效值编码

## 结论速览

- **HP辅助（2026-10-12 重构后）**：拆成 2 个特技，特效值 = **子掩码(低3位) + 百分比×8**，支持任意子组合，1% 粒度。
- **MP辅助**：保持原编码，特效值 = **能力掩码(低5位) + 倍率(高位)**，比例 = 倍率×10%（高位为0 → 100%）。
- 本页口径来自对当前 `Ekd5.exe` 的实机反汇编与注入验证，证据等级：本地样本字节 + 复读校验。

## 已确认事实

### 特技槽分配

| 技能 | 特技号 | 覆盖能力 | 编码 |
|---|---|---|---|
| HP辅助·攻防 | `0x8F` | 攻 / 防 | 子掩码 + 百分比×8 |
| HP辅助·精敏士 | `0x90` | 精 / 敏 / 士 | 子掩码 + 百分比×8 |
| （空出）| `0x91` | — | — |
| MP辅助 | `0x92`/`0x93`/`0x94` | 全部五维 | 掩码 + 倍率×10% |

- 名称表现状：`0x8F~0x91` 显示为「命若洪炉」，`0x92~0x94` 显示为「气贯长虹」（初版名为「HP辅助 / MP辅助」）。
- 三槽同类叠加：同一技能的 3 个槽可累加。

### HP辅助（新）编码

```
特效值 = 子掩码(低3位) + 百分比 × 8
百分比 = 特效值 >> 3      （1~31，建议 1~30）
```

| 技能 | 子掩码取值 |
|---|---|
| `0x8F` 攻防 | `1`=攻、`2`=防、`3`=攻+防 |
| `0x90` 精敏士 | `1`=精、`2`=敏、`4`=士、`3`=精敏、`5`=精士、`6`=敏士、`7`=精敏士 |

速查：只辅助攻15% = `1+15×8` = **121**；攻防都辅助15% = **123**；精敏士全20% = **167**；攻防30% = **243**（上限 247）。

### MP辅助（原）编码

```
特效值 = 能力掩码(低5位) + 倍率 × 32
能力掩码：攻=1 防=2 精=4 敏=8 士=16（可相加）
倍率 = 特效值 >> 5；比例 = 倍率 × 10%（倍率=0 → 100%）
```

速查：MP辅助攻防30% = `1+2+32×3` = **99**。

### 说明文字机制（关键，务必记住）

**母函数入口是 `0x452C81`**（不是 `0x42834D`！），`ret 0xC`，3 个参数：

| 参数 | 含义 |
|---|---|
| `[ebp+8]` | 输出缓冲 |
| `[ebp+0xC]` | 特效值（同时放在 ECX）|
| `[ebp+0x10]` | **flag 原始值**（不是 flag-1！）|

原入口 `0x452C8B` 为 `cmp al,0x10 / jne 0x452CC2`：**只有 `flag==0x10`** 走专用分支（`0x452C8F`，原本是「特效值当1~4档查表」）；其余跳 `0x452CC2 → 0x428350`（那里才 `dec eax`）进入原线性分支链。

原分支链按 `AL = flag - 1` 分派：

| AL | flag | 行为 |
|---|---|---|
| 0~5 | `0x01`~`0x06` | `0x4283D3` → `sprintf(缓冲, 格式串表[AL], 特效值)`（见下表，**工具里的「显示效果 00~06」就是这一组**）|
| 6 | `0x07` | `dec ecx` → `call 0x483002` |
| 7 | `0x08` | `cmp cl,6`：`cl≥6` 或 `cl==0` → 空串；否则 `0x486ADB + cl*5` 查表 |
| 8 | `0x09` 能力辅助 | `0x423D45` → `"%s→%s"`（如「精→攻精」）|
| 0xA | `0x0B` | `0x4283F4` → `0x423D96` 列能力名（如「攻精」）|
| `0x0B`~`0x0E` | `0x0C`~`0x0F` | 各自查 `0x40620A` / `0x48C470` / `0x41AEB0` / `0x41AFCB` 表 |
| ≥0x0F | ≥`0x10` | `0x4283E7` 写空串（各补丁改成跳自己的代码洞）|

**flag（=「显示效果」）↔ 实际显示文本**——flag 存在**名称表每行第 16 字节**（`0x9D800` 宝物特效名表 / `0x9E800` 个人特技名表，均为 `基址 + id*16 + 15`；见 `07-数据表与资源/宝物物品设定.md` 的「两个特效号名称表」节）：

| flag | 格式串（表 `0x462274[flag-1]`）| 显示效果（工具口径）|
|---:|---|---|
| `0x00` | 空串 | 00 不显示特殊效果值 |
| `0x01` | `"+%d"` | 01 显示为 + 效果值 |
| `0x02` | `"+%d%%"` | 02 显示为 + 效果值 % |
| `0x03` | `"-%d%%"` | 03 显示为 − 效果值 % |
| `0x04` | `"%d%%"` | 04 显示为 效果值 % |
| `0x05` | `"%d"` | **05 显示为 效果值** |
| `0x06` | `"%d次"` | 06 显示为 N 次 |

> 实测样本（本工程 `Ekd5.exe`，2026-10-13）：`0x0D 麻痹攻击`/`0x0E 封锁攻击`/`0x0F 混乱攻击`/`0x10 中毒攻击` = `0x04`（显示为概率 %）；`0x8F 命若洪炉` = `0x14`、`0x90 命若洪炉` = `0x11`、`0x91 命若洪炉` = `0x0B`、`0x92~0x94 气贯长虹` = `0x13`（这些 ≥0x10 的值走本页补丁自建的代码洞说明）；`0xB3 破坏MP攻击` 原为 `0x00`，已改为 `0x05`（见 `破坏MP攻击-特效值化.md`）。

本补丁把入口整条换成 `jmp 0x4322D3`，于是**所有 flag 都在代码洞里分流**，不必为了分流去改 flag 值。代码洞分流：

- `flag==0x10` → `TBL8F[特效值&7]` + `+` + `(特效值>>3)` + `%`
- `flag==0x11` → `TBL90[特效值&7]` + 同上
- `flag==0x13` → 先调原函数 `0x4283F4` 写能力名，扫到串尾再追加 `+((特效值>>5)×10)%`（倍率0 → 100%）
- 其他 flag → `jmp 0x452CC2` 走原分支链（显示完全不变）

### 容易走弯路的坑（血泪）

- **`0x42834D` 不是函数入口**，只是分支链中间的一段，且被 `0x452CC2 → 0x428350` 跳过；改它无效。
- **`flag==0x10` 才是游戏原生专用分支**；曾误以为是 `0x11`，结果落到 `AL>=0x0F` 的空串分支，说明一片空白。
- **`AMSG.E5`（表 `0x4AE4BC`，2049×200字节）服务的不是「兵种技能」说明**，而是 `0x466E30` 渲染的名称列；往 `0x4AE4BC + (特技号+0x1AE)*200` 写文字对「兵种技能」说明无效。
- 说明分派**只收 flag + 特效值，不收特技号**，所以同 flag 的技能无法区分——只能靠 flag 区分。

- 结算调用链：`0x43C51C → 0x4C0300 → 0x428430`（参数：单位 / 累加值 / 能力索引）。
- HP 特效值查询 `0x414D98`（内部按组号映射到 `0x8F+g`）；MP 为 `0x414DAB`（`0x92+g`）。
- HP 基值 `0x41B500`；MP 基值 `0x472840`；百分比 `0x425AD9`；比例换算 `0x4321FE`。

## 风险与边界

- 说明文字**由 flag 驱动**；特技**效果由特技号驱动**（`0x414D98`/`0x414DAB` 查询），不经 flag，因此改 flag 不影响战斗数值。
- `0x13` / `0x11` 在本样本名称表中原本无人使用，可安全征用；`0x10` 原属「48不会输的英雄」，本补丁保留了它的 1~4 档查表行为（该技能 `特效值` 走 1~4 档，不受影响）。
- 重构后 `0x91` 槽不再被 HP 段使用，其原有效果（若数据里有）会失效。
- 配套工具：`【6.6山贼】特技特效值计算器.xlsx`（勾选能力 + 填百分比 → 得出填进游戏的数值；含反查表）。

- ⇒ **"辅助五维"的效果位置仍未实机定性**；本页第 1 节（只由物品授予）与本节（能写入、能还原）为已确证部分。

### 4. ★ 两条方法学教训（本次踩到，防后人重踩）

## 2026-10-16 ★ 游戏内「特技说明框」排版规则（每行 17 字符、按字符数折行）

### 一、结论速览

### 三、参考实现（已落地到 `_特技叠加面板.py`）

```python
def _cw(ch):
    """字符显示宽度：半角 0.5、全角 1.0。"""
    return 0.5 if ord(ch) < 0x7F else 1.0

def _game_wrap(s, n=17):          # n = 每行全角单位数
    out = []
    for para in s.split("\r\n"):
        if not para:
            out.append(""); continue
        cur, w = "", 0.0
        for ch in para:
            c = _cw(ch)
            if w + c > float(n) + 1e-9:
                out.append(cur); cur, w = ch, c
            else:
                cur += ch; w += c
        out.append(cur)
    return "\n".join(out)
```
