> 本页所有引擎地址均在**当前** `Ekd5.exe`（SHA256 `D5A2F54C726E784AC248D5B3E81C392EFBCD12131AD2253AF7C19B7463686419`，1148928 B，备份 353 / 补丁 47）上现读。

## 结论速览

1. **CMF V7 静态提取不到任何地址**（不是"没找到"，是"地址不以任何可搜形态存在"）：候选地址 `0x43C65B / 0x48C093 / 0x8AA93 / 0x4CC7A0 / 0x43C5DF / 0x423FA1 / 0x401000 / 0x4BE000` 的 **dword 小端 / 低 3 字节 / ASCII 6-8 位 / UTF-16 6-8 位** 四种形态**全部 0 命中**；功能性关键词（`先手攻击`/`地址`/`Ekd5`/`兵种`/`策略`/`Address`/`Offset`/`ComboBox`/`CheckBox`…）在 UTF-16LE 与 GBK 下**全部 0 命中**。⇒ 该工程是**加密/混淆**的 CheatMaker 工程，必须「CheatMaker 打开导出 / UI 枚举 / 人工抄录」才能拿到地址（与库内 `CheatMaker-CMF证据索引.md:7` 一致）。
2. **教程对象是复刻版 6.5，不是本样本**：图 5、图 7 窗口标题均为 `文件 [本地盘]\Users\Mr.Wang\Desktop\复刻版6.5\Ekd5.exe`。教程地址**不可跨样本照抄**（§3 版本护栏）。
3. **换算规律（教程核心，本样本实测成立）**：UE 里记的是**文件偏移**，OB「复制到可执行文件 → 选择 → Ctrl+G」里输入同一偏移，切「在 CPU 数据窗口中查看镜像」后得**虚拟地址 VA**；本样本 `.text2` 节 `VA = 文件偏移 + 0x401600` ⇒ `0x8AA93 → 0x48C093`，与教程数字**逐位一致**。
4. **本样本 `0x8AA93`（VA `0x48C093`）不是「先手攻击」，而是「恢复HP」**：该处是**策略效果名表**（步长 8 字节），内容 `恢复HP / 恢复MP / 恢复状态 / 再次行动 / 气候变化 / 谜 / 四神 / … / 攻击(火)(水)(地)(风) / 吸收HP / 吸收MP / 能力上升下降 / 混乱 / 中毒 / 麻痹 / 封锁`。
5. **本样本「先手攻击」在 VA `0x4CC7A0`（文件偏移 `0x9E9A0`，`.api` 节）**，表项**步长 16 字节**，同表含 `辅助策略中心 / 辅助策略格挡 / 辅助策略命中 / 敌人？无法？ / 辅助攻击命中`。
6. 锚点核对（用户口径「小补给公式地址 `43C65B`」）：**真实存在**，属函数 `0x43C5DF..0x43C717`（`ret 0xC`，3 个栈参数）= 策略效果量（补给/伤害共用）计算。附近与"回血量"相关的可改点见下节表格。
7. 教程「**要反着写**」= GBK 字节**倒序**：`BA F3 CA D6` 解码为「后手」（图 6 红框内即此 4 字节），倒序 `D6 CA F3 BA` 就是教程让你在 OB 输入框里敲的 `x D6 CA F3 BA`。⚠ 倒序后的 `D6CA`/`F3BA` 本身也是合法 GBK 字（实测解出「质蠛」一类的怪字），所以**不能靠眼看校验**，必须按倒序规则核对。

## 已确认事实

### 1. CMF 为加密工程的证据（只读探测）

| 探测项 | 方法 | 结果 |
|---|---|---|
| 头部 | 前 64 字节 | `FF FE`（UTF-16LE BOM）+ `63 00 6D 00 66 00 30 00 61 00` = `cmf0a`，其后即混淆流 |
| 签名统计 | 正则 `cmf[0-9a-f]{2}` | 仅头部 1 处（`cmf0a`）；无其他可见分段标记 |
| UTF-16LE 可读串 | 宽松正则 | 64698 条，但绝大多数是**混淆字节被误判**（`'搀怀紀礀'`、`'#$DID%'`、`'1t2SVW'`） |
| 关键词 | 18 个功能词 × UTF-16LE/GBK | **全 0** |
| 候选地址 | 8 个地址 × 4 形态 | **全 0** |
| 全文件 dword 落在 `0x400000..0x530000` | 步长 1 扫描 | 165330 命中，Top 全是 `004A0024 / 00520057 / 004C0073`… ⇒ 均为 UTF-16 字符对（如 `'$','J'` = `24 00 4A 00`）的**假地址**，非真实地址表 |

⇒ 结论：**不解析、不绕过保护**（库规），走人工导出路线。

### 2. 教程流程还原（docx 文本 + 图）

1. 需要两个工具：**UE（UltraEdit）** + **OB（OllyDbg）**。
2. UE 打开 `Ekd5.exe`，搜要改的名字（例：`先手攻击` → `后手攻击`），记录**左侧地址**（十六进制文件偏移），右侧是文字（GBK）。
3. OB：右键 → **复制到可执行文件 → 选择** → 弹出窗口 → `Ctrl+G` → 输入 UE 记录的偏移（图 7 对话框：十六进制 `8AA93` / 有符号 `567955` / 无符号 `567955`）。注意该窗口地址列本身就是**文件偏移视图**（图 7 显示 `0008A93`、`0008A94`…）。
4. 点中对应位置 → **在 CPU 数据窗口中查看镜像** → 下方 hex 跳到该位置并给出 **VA**（教程记 `48C093`）。
5. 用指针写回：`(p)` 输入 `x+48c093`（自动转换），再用 `(*p)` 输入要写的字节，**反着写**（教程例 `x D6 CA F3 BA`）。
6. 读取对应剧本后修改完毕 —— 即"**用剧本在游戏中途改名字**"。

### 4. 锚点：策略效果量函数 `0x43C5DF..0x43C717`（含 `0x43C65B`）

`func 0x43C65B` 推定入口 `0x43C5DF`，共 312 字节，`ret 0xC`（3 栈参）。关键位点：

| 地址 | 字节 | 语义（静态推断） |
|---|---|---|
| `0x43C63C` | `6A 02` | `push 2` |
| `0x43C63C` 后 | `E8 8A 86 FD FF` | `call 0x414CCB`（取值；`push ecx/0/2` 参数形态） |
| `0x43C642` | `6A 1E` | `push 0x1E`(30) |
| `0x43C647` | `E8 6C 31 00 00` | `call 0x43F7B8` ← **特技修正链**（预览与实战共用区，见 §8 页） |
| `0x43C64D` | `6A 64` | `push 0x64`(100) |
| `0x43C650` | `E8 73 01 FD FF` | `call 0x40C7C8` |
| **`0x43C65B`** | `6A 02 / E8 72 F4 FC FF / 83 C0 63` | `push 2; call 0x40BAD4; add eax,0x63` ⇒ **浮动率 99** |
| `0x43C667` | `D1 E8 / 83 C0 64` | `shr eax,1; add eax,0x64` ⇒ **浮动率 100**（另一分支） |
| `0x43C66C` | `89 45 FC` | `mov [ebp-4], eax` ⇒ 浮动率存入结果槽 |
| `0x43C682` | `68 C8 00 00 00` | `push 0xC8`(200) 阈值比较（`call 0x47FB13`） |
| `0x43C691` | `6A 0B` | `push 0xB`(11) 超额附加（`add [ebp-4], eax`） |
| **`0x43C6A1`** | `E8 FB 78 FE FF` | `call 0x423FA1` ⇒ **回复量修正（可减半）** ← "回血量"最贴近的候选 |
| `0x43C6B8` | `E8 FC DF FD FF` | `call 0x41A6B9`（当 `[ebp-0x10]==0xD` 时再修正） |
| `0x43C6CC` | `03 41 14` | `add eax, [ecx+0x14]` 后与上限比较截断 |
| `0x43C6E5` | `03 41 10` | `add eax, [ecx+0x10]` 后与上限比较截断 |

子函数 `0x423FA1`（24 字节，`ret 4`）：

```
00423FA1  55              push ebp
00423FA4  6A 10           push 0x10
00423FA6  E8 3D 00 00 00  call 0x423FE8   ; 特技/标志判定（0x10 = 16 号）
00423FAB  85 C0           test eax,eax
00423FAD  74 03           je  +3
00423FAF  D1 6D 08        shr dword [ebp+8],1   ; ← 回复量减半
00423FB2  8B 45 08        mov eax,[ebp+8]
00423FB6  C2 04 00        ret 4
```

⚠ `0x43C65B` 字节已用 `exe_bytes` 独立复读核对（`6A 02 E8 72 F4 FC FF 83 C0 63 EB 05 D1 E8 83 C0 64 89 45 FC 83 7D 10 00 75 26…`），非仅凭 `da` 输出。

## 风险与边界

- **CMF 不解密、不绕过保护**（库规，`CheatMaker-CMF证据索引.md:7`）；本页只记录"静态拿不到"这一事实与人工导出路径。
- **教程是 6.5 样本**：其 `8AA93/48C093` 在本样本另有内容；任何"教程地址 + 本样本"的直接套用都属跨版本错误。
- **改名会改 EXE**：写 `Ekd5.exe` 必须走 `大鲸鱼产生专用\_dsh写锁.py` 的 `safe_write_exe()`（备份 + 写后复读 + 审计行），禁止直接 `open(...,'wb')`。
- 名表是**定长槽位**：改写必须保持长度（超出会串到下一项）；OB 的"反着写"是为了对齐 OB 输入框的字节序，不是引擎要求的内存序。
- `0x43C5DF` 函数的 `[单位+0x10]` / `[单位+0x14]` 字段语义**未确认**（候选：当前/最大 HP 类上限），改动前必须实测。

**根本性区分（重要）**：CM V7 的地址分两类——
1. **公式/常量类**（如 `43C65B`）：命中**原生引擎代码**，可从引擎侧自主定位（本页已在做）；
2. **注入类**（SP 特效 / buff 回合 / 范围特效 / 众志成城 / 主界面标题…）：地址是**补丁作者选定的代码洞**，原生引擎里**不存在**，只能从 CMF 或作者文档获得。

⇒ 因此"把 CMF 的全部实用地址自己弄出来"在**注入类**上不可能；`43C65B` 这类公式锚点可以。
