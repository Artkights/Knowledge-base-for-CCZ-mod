## 结论速览

1. **伤害公式：有，但属 6.5**。`ccz-LuaSkill` 给出物理 `伤害 = 等级 + 25 ± |攻击-防御| / 2`、

2. **伤害预览：全组织 0 命中**。`ccz-LuaSkill` 里 `预览`/`preview` **一次都没有**；
   可视化剧本编辑器 MKII 自己也写着"**预览…不计算伤害**"。⇒ 普罗源码**帮不上**预览。
3. **集气模式：只在老补丁仓库里**。`Patch-for-CaoCaoZhuan`（6.2~6.4）含完整集气实现；
   `ccz-LuaSkill`（6.5）**`集气/0x505EC8/0x4930C8` 全部 0 命中**。

   本地 6.6 的 11 个已知地址里，只有 `ctx+0x84`（物理伤害槽）完全一致。
5. **唯一"能抄"的是公式本身与数据结构语义**（`ctx+0x84` / 标志 `+0x600/+0x604/+0x608/+0x614` /
   单位数组 `0x4A7B20` 步长 `0x30`），**不是地址**。

1. **要用伤害公式**：抄 `ccz-LuaSkill` 的**算式与结构语义**，地址一律回到本地 6.6 重新复读
   （物理公式仍在 `0x43BC5A`，5 处调用点：`0x405E6D` / `0x419AED` / `0x438A2A` / `0x438CCA` / `0x440668`）。
