# 加速机制与 `0x4B3D20` 口径统一

> **本页是"战斗加速到底怎么看、怎么写、能不能信"的唯一真源。**
> 历史问题：`03-机制详解/自动战斗-识别与驱动.md` 写「**不是**可写控制量」，
> `05-教程指南/战场操作自动化与调试流程.md` 写「**直接写 `=3`** ✓✓」，两页并存 ⇒ 新会话无法判断该信哪句。
> 建立日期：2026-10-14

## 结论速览

`0x4B3D20` **三件事要分开说，合起来才是完整口径**：

| 层次 | 结论 | 证据 |
|---|---|---|
| **能写吗** | **能**。直写 `=3` 后立刻读回 `3`，1 秒后仍是 `3` | 实测（`战场操作自动化与调试流程.md:636`） |
| **写了就等于加速吗** | **不等于**。引擎自己每秒在 `1↔3` 之间刷这个字节 ⇒ 它是**状态指示**，不是控制量 | 实测（`自动战斗-识别与驱动.md:14,33`） |
| **权威判据是什么** | **用户手动按 X**（`0x58`），并经**人眼确认 HUD/画面显示加速** | 用户口径 2026-10-13：「必须按 X」「我必须要看到是加速的」 |

**注入按键完全无效**：`keybd_event` / `SendInput` 发 `X / 空格 / 1 / 2 / 3 / 4 / 0 / Z`
实测**改不动这个字节**（AutoDLL 键盘钩子丢弃注入按键）⇒ 自动化只能用"直写"兜底。

⇒ **自动化里的正确姿势**（照抄）：
```
① 用户手按 X（或至少脚本按 X 做样子，但不要指望它生效）
② 直写 0x4B3D20 = 3                  ← 兜底，不保证真提速
③ 读回，确认字节 ∈ 1..4              ← 门禁，不通过就 exit 3 停下来报错
④ 最终以人眼看到加速为准（用户口径）
```

## 适用版本

- `复刻版6.6山贼\Ekd5.exe`（**SHA 每轮现读**，见 `06-项目与工具链/样本SHA时间线与现行补丁.md`）。
- 发布文稿口径：`0` = 不加速，`1..4` = 加速档。
- 实测：按 X 前 `02` → 按 X 后 `03`（用户机、当时样本）。

## 已确认事实

### 1. 字节语义

| 值 | 含义 |
|---|---|
| `0` | 不加速 |
| `1..4` | 加速档（`3` 是自动化里常用的目标值） |

- 地址：`0x4B3D20`（**字节**，不是结构体）。
- 引擎自刷：**每秒在 `1↔3` 之间跳**（这也是"读到的值会变"的原因，不是脚本写失败）。
- ⚠️ **不可反复重写**：`更新记录.md` 记录过"脚本只能直写，且**不可反复重写**"——
  反复写会与引擎自刷打架，观测到的值不可信。

### 2. 为什么"写 3 ≠ 开加速"（事故原委）

- 旧口径「`0x4B3D20` 是加速状态，写 `3` 就等于开加速」已被用户当场否证（纠错台账 2026-10-13）。
- 用户要求是**在 HUD 上真的看到加速**；字节只证明"状态字是 1..4"，**不能证明画面在加速**。
- 另有实测：注入按键后该字节**全无变化**（`0 → 0`），只有直写才动
  ⇒ 说明它是**被引擎写**的状态字，不是"按键事件"的入口。

### 3. 待办：真正的速度变量还没找到

- **P0**：`0x4B3D20` 不是可写控制量 ⇒ 若要"程序化、可靠地提速"，必须定位**真正的速度变量/函数**
  （线索方向：普罗源码相关入口、`GearNtKe.dll`）。
- **P1**：需要一次**人手对照实验**：按 X 后同时记录（画面/菜单显示 + 字节值），
  把"字节 1..4"与"人眼可见加速"的对应关系钉死。

## 实现·使用方法

**只读检查**（判断当前是否处于加速档，不写内存）：
```bat
大鲸鱼产生专用\_pyrun.cmd 大鲸鱼产生专用\_内存读写.py probe
```

**自动化门禁写法**（改写脚本时照此实现）：
1. （可选）`keybd_event(VK_X)` —— 只为满足"按 X"的形式；
2. `write_u8(0x4B3D20, 3)` —— 兜底；
3. `v = read_u8(0x4B3D20)`；`if v not in (1,2,3,4): exit 3`（**停下来报错，绝不带着未确认状态继续跑**）；
4. 由用户确认"画面确实在加速"。
5. **不要循环反复写**（见"不可反复重写"）。

## 风险与边界

- **不要把"字节 = 3"当作交付验收**：用户口径是要看到加速。
- **不要在标题页就按 X / 写加速**：正确时机是**读档完成、进战场之后**
  （工具已按此实现，见 `战场操作自动化与调试流程.md`）。
- 该字节地址来自 6.6 山贼样本；换样本必须重新核对。
- 若工具默认会写该字节，必须在文档与参数里写明（现有工具支持 `--no-x` 改为只读检查）。
