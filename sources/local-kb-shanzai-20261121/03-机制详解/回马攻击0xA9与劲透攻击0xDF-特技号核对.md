00441EFC  call 0x4101D9                ; 取效果值

00441F06  cmp  [ebp+0x14],0

### 3. ★ 方位语义（可直接用于任何伤害对照）

| 朝向关系 | `当前朝向 XOR 记录朝向` | 回马攻击的处理 | 与用户口径对应 |
|---|---|---|---|
| **正面**（未转身） | `0` | **不加成** | — |
| **侧向** | `1` 或 `3` | **+1× 效果值** | 用户所说"**侧面 5%**"（基础游戏另有 +5%） |
| **反向** | **`2`** | **+2× 效果值（翻倍）** | 用户所说"**背面 10%**"（基础游戏另有 +10%） |

- **方向字段**：**`单位+0x0F`**（byte，0..3，四方向：相邻差 1=侧、差 2=对向）。
- **"攻击前方向"记录**：**`0x441EE7`**（byte，`#临时储存攻击前方向`，由 `0x43583A`(发起) / `0x410F8D`(先手) 处的 `call 0x441F63` 记录）。
- **通用性**：`0x43F249`(槽6) → `call 0x441EE8` ⇒ 回马在**预览与实战共用链**上 ⇒ 其加成**两侧都会算**（与文本自述"伤害预览时均能显示加成后的伤害值"一致）。

### 4. ★ 对"暴击预览"验收的直接影响（判据必须加这条）

**预览值 vs 实际掉血的对照，必须在"同朝向"下比**；否则会归因错误：
```
预期 = 基础预览 × (150 + K/2 + 特效0x70)/100              ← 暴击部分
      × (1 + 侧面5% 或 背面10%)                            ← 基础游戏方向加成（待定位地址）
      + 回马攻击(0xA9)效果值 ×(1 或 2)                     ← 若持有该特技且发生过转身
      + 劲透攻击(0xDF)增伤（穿透目标数×10%，最多100%）      ← 若持有且只打一个目标
```
⇒ **一次干净对照**：**不转身、正面攻击**（`XOR == 0`）时，回马/劲透都不生效 ⇒ 预期严格等于暴击公式值。
