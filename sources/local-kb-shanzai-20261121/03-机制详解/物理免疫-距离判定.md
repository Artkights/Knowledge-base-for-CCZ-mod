# 物理免疫-距离判定（特效值分档 + 周围八格）

## 结论速览

- **「周围八格」在本样本里已有现成实现**：一段 41 字节纯寄存器函数
  （`eax` = 单位A、`edx` = 单位B，读 `unit+06`/`unit+07` 坐标，判定切比雪夫距离 ≤ 1）。
  这是本项目里**最短、最通用**的邻接判定，可直接复用到任何"周围/相邻/距离"类特效。
- **攻击者与目标的取法有两条路径，两条都已确认**：
  - 物理伤害公式 `0x43BC5A`：**`ecx` = 攻击者**（入口 `0x43BC60` 存入 `[ebp-0x2C]`，
    全函数仅此一处写），**`[ebp+8]` = 被攻击目标**；
  - 特效分发入口 `0x43B600`（在伤害公式内部由 `0x43B4B6` 调用）：**`ecx` = 攻击者**，
    **`[ebp+0xC]` = 目标**。
- **档位与距离可以用一行 `xor` 合成**，不需要分支：
  `xor al, cl`（`cl` = 特效值−1）同时实现"值 1 = 相邻才免疫、值 2 = 不相邻才免疫"。
- **判定函数返回值语义是反的**：`eax = 0` = **免疫**（拦截），`eax = 1` = **不免疫**（放行）；
  所以挂钩点一律写成 `test eax,eax / je <直接返回>`。
- ★ **版本护栏**：用户 2026-10-14 提供的《免疫物理攻击-距离判定增强版》文本属
  **star6.6x 血统**，与当前复刻版6.6山贼样本 **8 段里 5 段字节不一致**；
  整份照抄会覆盖 `0x43B617` 处的 `call 0x4E4000` 挂钩，并把入口开关
  `0x500E9B` 换成 `0x500E9A`。在当前样本上启用距离判定**只需写 2 段**（见第四节）。

## 已确认事实

### 一、单位结构的相关偏移（本页用到）

| 偏移 | 含义 | 证据 |
|---|---|---|
| `unit+04` | 阵营/类别字节（`0xFF` = 无效单位） | `0x43BC66` `movzx eax,byte [ecx+4]` + `cmp al,0xFF` 判无效 |
| `unit+06` | **X 坐标（字节）** | `0x43BAD8` `mov cl,[eax+6]` |
| `unit+07` | **Y 坐标（字节）** | `0x43BAE6` `mov cl,[eax+7]` |
| `unit+10` | **当前 HP（dword）** | `0x43BC47` `mov ecx,[ecx+0x10]`，紧接 `cmp eax,ecx / jbe` 做"伤害不超过目标 HP"截断 |

`unit+06/+07` 为坐标与 `6.5特效注入索引.md` 的既有口径一致，本次由机器码直接复读确认。

### 二、「周围八格」判定函数（41 字节，纯寄存器传参）

位置 `0x43BAD5`（写在原判定函数之后的 NOP 区），反汇编（静态复读）：

```asm
43BAD5  55              push ebp
43BAD6  8B EC           mov  ebp, esp
43BAD8  8A 48 06        mov  cl, [eax+6]      ; cl = A.x
43BADB  2A 4A 06        sub  cl, [edx+6]      ; cl = A.x - B.x
43BADE  80 C1 01        add  cl, 1
43BAE1  80 F9 02        cmp  cl, 2
43BAE4  77 12           ja   43BAF8           ; |Δx| > 1 → 不在
43BAE6  8A 48 07        mov  cl, [eax+7]      ; cl = A.y
43BAE9  2A 4A 07        sub  cl, [edx+7]
43BAEC  80 C1 01        add  cl, 1
43BAEF  80 F9 02        cmp  cl, 2
43BAF2  77 04           ja   43BAF8           ; |Δy| > 1 → 不在
43BAF4  B0 01           mov  al, 1            ; 在周围八格内
43BAF6  EB 02           jmp  43BAFA
43BAF8  30 C0           xor  al, al           ; 不在
43BAFA  8B E5           mov  esp, ebp
43BAFC  5D              pop  ebp
43BAFD  C3              ret
```

要点（这是本页最值得复用的部分）：

- **传参约定**：`eax` = 单位A、`edx` = 单位B，**没有栈参数、没有 `ret n`**。
  返回值在 `al`：1 = 在（含自身格），0 = 不在。
- **等价语义**：`|A.x − B.x| ≤ 1 && |A.y − B.y| ≤ 1`，即切比雪夫距离 ≤ 1 =
  九宫格（**含自身格**）。
- **无符号回绕技巧**：`sub cl` 之后 `add cl,1` 再 `cmp cl,2 / ja`，
  利用 8 位减法把 `{-1,0,+1}` 映射到 `{0,1,2}`，一条比较就排除两侧越界。
- **副作用**：只改写 `ecx`/`al`，不动 `edx`、`ebx`、`esi`、`edi`、`ebp`；
  但**不保存 `ecx`** ⇒ 调用者若还要用 `ecx`，必须先 `push ecx`（补丁里正是这么做的）。
- **对称性**：交换 `eax`/`edx` 结果不变。所以"谁当 eax"不影响判定值，
  但 `[ebp-4]`/`[ebp+8]` 的**取特效方向**不能反（见下）。

### 三、两条进入路径：「攻击者」和「目标」分别从哪来

**(a) 物理伤害公式 `0x43BC5A`（主路径，被 `0x405E6D` 调用）**

```
0x405DE1  物理伤害主控（ctx = 0x4927F0 由 ecx 传入，入口存 [ebp-0xC]）
  0x405E25  mov dl,[eax+ecx+0x10]   ; ctx+0x10+i = 第 i 个目标战场编号
  0x405E37  call 0x4061F9           ; 战场编号 → 单位指针（走 cl，返回 ecx）
  0x405E3C  mov [ebp-0x20],ecx      ; ★ [ebp-0x20] = 当前目标单位
  0x405E3F  call 0x40658F           ; 取当前行动单位（攻击者），返回 ecx
  0x405E44  mov [ebp-8],ecx         ; ★ [ebp-8]  = 攻击者单位
  0x405E67  push [ebp-0x20]         ; → 0x43BC5A 的 [ebp+8] = 目标
  0x405E6A  mov ecx,[eax+0xC]       ; ctx+0xC
  0x405E6D  call 0x43BC5A           ; ★ ecx = 攻击者
```

`0x43BC5A` 内部：

```asm
43BC5A  55              push ebp
43BC5B  8B EC           mov  ebp, esp
43BC5D  83 EC 3C        sub  esp, 0x3C
43BC60  89 4D D4        mov  [ebp-0x2C], ecx   ; ★ 全函数唯一写入：攻击者
43BC63  8B 4D 08        mov  ecx, [ebp+8]      ; 目标
43BC66  0F B6 41 04     movzx eax, byte [ecx+4]
43BC6D  3C FF           cmp  al, 0xFF           ; 目标无效 → 直接返回 0
...
43BD2C  8B 4D D4        mov  ecx, [ebp-0x2C]   ; 攻击者 → 取等级
43BD2F  E8 40 69 FD FF  call 0x412674
43BD34  83 C0 19        add  eax, 0x19         ; 伤害基数 25
43BD95  FF 75 D4        push [ebp-0x2C]        ; 攻击者
43BD98  FF 75 08        push [ebp+8]           ; 目标
...     ret 0xC                                ; 3 个栈参数
```

- 机器码证据：`0x43BC60` 是 `[ebp-0x2C]` **唯一**的写点（脚本扫 0x43BC5A~0x43BF27
  共 9 处 `[ebp-0x2C]` 引用，其余 8 处全是读取）⇒ 挂钩点读 `[ebp-0x2C]` 拿到的一定是
  函数入口的 `ecx`，即攻击者，**全程有效**。
- `0x43BF15` 的 `cmp eax,ecx / jbe` + `mov [ebp-4],ecx` 证明此时 `ecx` = 目标当前 HP，
  与被覆盖的 `0x43BF0E` 原指令（取目标 HP）配对。

**(b) 特效分发入口 `0x43B600`（同一伤害流程内，由 `0x43B4B6` 调用）**

```
0x43BD1C  mov ecx,[ebp-0x2C]      ; 攻击者 → ecx
0x43BD1F  call 0x43B4B6           ; 参数：push 0xFF / push 1 / push [ebp+8](目标)
0x43B4B6  push ecx(攻击者) / push 1 / push [ebp+0x10]=0xFF / push [ebp+8]=目标 / push 0
0x43B4CA  call 0x43B600
          ⇒ 0x43B600 看到：ecx = 攻击者、[ebp+8]=0、[ebp+0xC]=目标、
             [ebp+0x10]=0xFF、[ebp+0x14]=1
0x43B61B  push [ebp+0xC]          ; ★ 目标 → 栈参数
0x43B61E  call 0x43BA9D           ; 判定（判定函数用 [ebp+8] 取特效 = 目标持有）
```

⇒ **「免疫」读的是被攻击者（目标）的特效值**，判定"攻击者是否在目标周围八格"，
两条路径语义完全一致。

### 四、判定函数：档位 × 距离的合成（增强版，56 字节）

```asm
43BA9D  55              push ebp
43BA9E  8B EC           mov  ebp, esp
43BAA0  51              push ecx              ; ★ 把"攻击者"(ecx) 落到 [ebp-4]
43BAA1  8B 4D 08        mov  ecx, [ebp+8]     ; 目标 → ecx（4101D9 的入参）
43BAA4  E8 DA FF FF FF  call 0x43BA83         ; 取目标的特效值 → eax
43BAA9  85 C0           test eax, eax
43BAAB  74 1D           je   43BACA           ; 值 0  → 不免疫
43BAAD  83 F8 03        cmp  eax, 3
43BAB0  73 14           jae  43BAC6           ; 值 ≥3 → 无条件免疫
43BAB2  50              push eax              ; 存特效值（1 或 2）
43BAB3  8B 45 FC        mov  eax, [ebp-4]     ; ★ 攻击者 → eax
43BAB6  8B 55 08        mov  edx, [ebp+8]     ; 目标 → edx
43BAB9  E8 17 00 00 00  call 0x43BAD5         ; 周围八格判定 → al
43BABE  59              pop  ecx              ; 取回特效值
43BABF  49              dec  ecx              ; 1→0，2→1
43BAC0  30 C8           xor  al, cl           ; ★ 值1 取正、值2 取反
43BAC2  84 C0           test al, al
43BAC4  74 04           je   43BACA           ; 合成结果 0 → 不免疫
43BAC6  33 C0           xor  eax, eax         ; 返回 0 = 免疫
43BAC8  EB 05           jmp  43BACF
43BACA  B8 01 00 00 00  mov  eax, 1           ; 返回 1 = 不免疫
43BACF  8B E5           mov  esp, ebp
43BAD1  5D              pop  ebp
43BAD2  C2 04 00        ret  4
```

语义表（`adj` = 攻击者在目标周围八格内）：

| 特效值 | 行为 | `adj` | `cl=值-1` | `al^cl` | 返回 |
|---|---|---|---|---|---|
| 0 | 不免疫 | — | — | — | 1 |
| 1 | **相邻才免疫** | 1 | 0 | 1 | 0（免疫） |
| 1 | 相邻才免疫 | 0 | 0 | 0 | 1（不免疫） |
| 2 | **不相邻才免疫** | 1 | 1 | 0 | 1（不免疫） |
| 2 | 不相邻才免疫 | 0 | 1 | 1 | 0（免疫） |
| ≥3 | 无条件免疫 | — | — | — | 0 |

### 五、特效值读取与「钩子骨架」

```asm
43BA83  55              push ebp
43BA84  8B EC           mov  ebp, esp
43BA86  6A 01           push 1                ; 效果值标志 = 1（要值，不是"是否拥有"）
43BA88  6A 00           push 0                ; 叠加标志 = 0
43BA8A  68 00 00 00 00  push 0                ; ★ 装备/宝物特效号（参数行 -43BA8B）
43BA8F  68 31 00 00 00  push 0x31             ; ★ 个人特效号（参数行 -43BA90）
43BA94  E8 40 47 FD FF  call 0x4101D9         ; 核心特技引擎，ecx = 单位指针
43BA99  8B E5           mov  esp, ebp
43BA9B  5D              pop  ebp
43BA9C  C3              ret
```

- 参数行 `-43BA8B` / `-43BA90` 就是直接改这两个 `push` 的立即数：
  `00` = 不含宝物，`31` = 个人特效号 0x31（**用户口中的"31"**）。
- `0x4101D9` 的调用约定：`ecx` = 单位指针，4 个栈参数，**返回特效值**或"是否拥有"。
- **骨架三件套**（本项目所有"特效值化"改造通用）：
  1. 在表项 / `call` 目标处把入口改指到新地址（`0x428961[0]`、`0x43B4CA`）；
  2. 新入口必须**自带完整序言**（`push ebp / mov ebp,esp / xor eax,eax /
     push eax / push ecx / sub esp,8`），因为原序言被跳过了；
  3. 在别处（原函数的 NOP 区或 `ret` 之后的空隙）写代码，末尾用
     `jmp` 回原流程 —— 本项目典型样本是 `0x43BF0E` 埋 `jmp 0x43BC2F`，
     `0x43BC2F` 段执行完 `jmp 0x43BF13` 回到 `0x43BF15` 的原指令。

## 实现/使用方法

### 1. 复刻版6.6山贼的**最小适配版**（只写 2 段）

当前样本**已经内置**物理免疫（原版逻辑：特效值≠0 即免疫），入口在
`0x43B600` 函数体内的 `0x43B61B`，**未**改表项、**未**改 `0x43B4CA`。
把判定升级为"距离分档"只需替换两段：

| 段 | 字节数 | 作用 | 覆盖区现状 |
|---|---|---|---|
| `-43BA83` | 123 | 包装函数（不变）+ **增强版判定** + **新增九宫函数** | 覆盖 `0x43BA83`~`0x43BAFD`，其中 `0x43BA9D` 之后当前全是 `90` NOP，安全 |
| `-43BC2F` | 35 | 伤害公式挂钩：`mov ecx,[ebp-0x2C]`（攻击者）+ `push [ebp+8]`（目标）+ 判定 + 回跳 | 32→35 字节，多占 `0x43BC4F`~`0x43BC51` 三个 NOP，安全 |

**不要写**这 4 段（它们是 star6.6x 的入口改造，在当前样本上会冲突）：

| 段 | 当前值 | 照抄的后果 |
|---|---|---|
| `-428961` | `00 B6 43 00`（= `0x43B600`） | 表项改指 `0x43B617`；该表只被 `0x428925` 使用，而 `0x428925` 全文件无引用（死代码）⇒ 实际无害但无必要 |
| `-43B4CA` | `E8 31 01 00 00`（call `0x43B600`） | 改指 `0x43B617` 后必须配套写 `0x43B617`，否则新入口不存在 |
| `-43B617` | 4×`90` + 现有挂钩 | **会覆盖 `0x43B627` 的 `call 0x4E4000` 挂钩**（另一功能，`.text3` 侧），并把入口开关 `0x500E9B` 换成 `0x500E9A` |
| `-43BF0E` | `E9 1C FD FF FF 90 90` | 与补丁一致，写了也不变 |

适配版补丁文本：`大鲸鱼产生专用\【6.6山贼】物理免疫-距离判定增强版-适配版.txt`
（预检脚本 `_补丁段预检.py` 可复核）。

### 2. 移植到别处时的模板

判定"两个单位是否相邻"：

```asm
; 入参 eax = 单位A, edx = 单位B；出参 al = 1 在 / 0 不在；破坏 ecx
push ebp / mov ebp,esp
mov cl,[eax+6] / sub cl,[edx+6] / add cl,1 / cmp cl,2 / ja 不在
mov cl,[eax+7] / sub cl,[edx+7] / add cl,1 / cmp cl,2 / ja 不在
mov al,1 / jmp 出
不在: xor al,al
出:   mov esp,ebp / pop ebp / ret
```

在挂钩点取"攻击者 + 目标"：

```asm
; 物理伤害公式 0x43BC5A 内（[ebp-0x2C] = 攻击者，[ebp+8] = 目标）
mov ecx,[ebp-0x2C]      ; 攻击者 → 判定函数要求的 ecx
push [ebp+8]            ; 目标 → 判定函数的栈参数（也是特效持有者）
call <判定函数>          ; ret 4，返回 0 = 免疫 / 1 = 不免疫
test eax,eax
je  <免疫返回路径>
```

## 风险与边界

- **血统不可混用**：本页的 5 段差异是 star6.6x 与复刻版6.6山贼的**入口改造策略不同**造成的
  （前者改表项+`call` 点并自带序言，后者只在函数体内挂钩）。
  两个版本都正确，但**混写会同时存在两套入口**，导致 `0x500E9A`/`0x500E9B` 两套开关叠加。
- **会连带影响预览与 AI**：`0x43BC5A` 是**公共**伤害公式，全文件 5 处 `call`
  （`0x405E6D` 实战、`0x419AED` 筛可击杀、`0x438A2A`/`0x438CCA` 范围与 AI 评分、`0x440668`）。
  挂钩写在公式内部 ⇒ 免疫判定在预览与 AI 决策时**同样生效**（通常是想要的效果，
  但会让 AI 放弃攻击目标，需实机确认手感）。
- **返回值语义易写反**：0 = 免疫、1 = 不免疫，与直觉相反；改动挂钩时务必保留
  `test eax,eax / je <直接返回>` 的方向。
- **判定函数不保存 `ecx`**：调用前若 `ecx` 有别的用途，必须先保存（补丁用 `push ecx`）。
- **`[ebp-4]` 依赖"进入函数时的 ecx"**：增强版判定函数靠 `push ecx` 后读 `[ebp-4]`
  取攻击者 ⇒ **调用它的每一处都必须先把攻击者放进 `ecx`**；
  只换判定函数而不给 `ecx`（例如漏写 `0x43BC2F` 段的 `mov ecx,[ebp-0x2C]`）
  会读到垃圾指针，症状是崩溃或随机免疫。
- **`0x43B600` 的其余分支未解析**：`[ebp+0x10]`（= `0xFF`）、`[ebp+0x14]`（= 1）
  在该函数内如何被消费尚未逐条确认；本页只用到 `ecx` 与 `[ebp+0xC]`。
