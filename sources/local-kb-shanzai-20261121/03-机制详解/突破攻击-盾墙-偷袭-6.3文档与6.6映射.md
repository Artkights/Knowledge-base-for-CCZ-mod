# 突破攻击 / 盾墙 / 偷袭 —— 6.3 文档与 6.6 样本逐条映射

## 结论速览

- **突破攻击入口**：文档 6.3 = `0x41106D`；**本样本 6.6 = `0x411072`**（整体 +5，因为前面多 5 字节）。
  体内 `call 0x42112A`（加强攻击）与 `call 0x421118`（突破攻击）**与文档同址**。
- **两个桩（本样本现读）**：
  - `0x421118` 突破攻击：`push 1 / 1 / 0 / 0x61 → call 0x42518F`
  - `0x42112A` 加强攻击：`push 0 / 0 / 0 / 0x62 → call 0x42518F`
  - 名表：`0x61 = 突破攻击`、`0x62 = 加强攻击`（`0x4CC600`）。
- **击退判定 `cmp al,0xFF` = `0x41110E`**（与文档同址，`jnz 0x411122`）。
- **击退对话**：文档 `push 0x500CFF; call 0x45965D`（对话字节区 `0x500CFF`，首字节 0 即不弹）。
- **地形免击退**（文档补丁）：从 `0x41110B` 跳洞，`call 0x435991` 取地形，`0x12..0x16` 视为可恢复地形 ⇒ `eax=0`。
  **本样本 `0x43060E/0x430612` 全是 `90` ⇒ 洞可用**（与文档 cave 同址）。
- **偷袭攻击 `0x4D2700` 在本样本同址存在**，`0x4D2765 imul eax,eax,0x19`（25）同址：
  正面 0 / 侧面 25% / 背面 50%；随后 `0x406710` 判阵营组，`al==1` 且 `[0x500E9A]==1` 再 +25%。
- **盾墙（0x77）不在本样本**：名表 `0x77 = 焚世`；盾墙方向函数 `0x4D2955` 在本样本**全 `00`**（未打补丁）。
  要做盾墙需新写方向判定——可直接复用 `0x4D2700` 的方向算法（两者逻辑同构）。
- 另有一个 `imul eax,eax,0x19` 在 **`0x4303B1`**（非偷袭，待查）。

## 6.3 文档要点（突破攻击）

```asm
; 6.3 文档
0x41106D  push ebp / mov ebp,esp / push ecx
0x411071  push 0x4B5DF0
0x411076  mov ecx,[ebp+0x10]
0x411079  call 0x40658F          ; 攻击者 Data
0x41107F  sub esp,0x0C
0x411082  push 0x16
0x411084  push [0x500E9B]
0x41108A  call 0x436334          ; 某种"槽/效果"查询
0x411096  call 0x42112A          ; 加强攻击?
0x4110A2  call 0x421118          ; 突破攻击?
0x4110AB  cmp [0x500E9A],1 / je
0x4110B7  call 0x426B33          ; 状态检查
0x4110BE  je 0x4110D6            ; → 突破分支
```

## 实现·使用方法

- **改突破攻击**：直接按文档地址改（注意入口 +5：本样本 `0x411072`；文档里的 `0x41106D` 在本样本是上一条指令的尾部）。
- **地形不击退**：把 `0x41110B` 改成 `E9 <rel32→0x430612>`，洞内 `add esp,4 / push eax / mov ecx,[ebp+0xC] / call 0x435991 / cmp al,0x12 / jb / cmp al,0x16 / ja / pop eax / mov eax,0 / pop eax / cmp eax,0xFF / jmp 0x411110`。
- **盾墙**：需要新桩 + 方向判定；方向算法照抄 `0x4D2700`（朝向 `+0x0F`、坐标 `+6/+7`，奇数朝向比 X、偶数比 Y），判定"盾墙方向挡住"后把 `eax` 清 0。
- **偷袭**：本样本已存在，改系数就改 `0x4D2765` 的 `6B C0 19`（25）或 `0x4D2790` 的 `push 0x19`。

## 风险与边界

- 文档是 **6.3**；本样本 6.6 只有"这几个函数同址"——**不代表全文件同布局**，其它地址仍须现读。
- `0x4D2955` 全 00 说明"盾墙补丁没打过"，不能假设本样本有盾墙行为。
- 突破攻击入口差 5 字节：直接照抄文档 `0x41106D` 会改到上一条指令尾部 ⇒ **必须用 `0x411072`**。
- 洞 `0x43060E` 是否被其它补丁声明：落点前跑 `_注入地址占用登记.py --check 0x43060E N`。
