## 历史结论（2026-10-15，仅限当时工具与样本）

1. **托管不抢鼠标**：`unit+0x0E ← 1` 是**纯内存写**（`_42托管我军.py`），一个输入事件都不发。
2. **回合推进必须靠输入**，而且**输入被前台门控**：
   实测游戏不在前台时 —— `SetCursorPos`+`mouse_event` 右键**无效**（4 个位置全试）、
   `PostMessage`/`SendMessage` 右键（down/up/dblclk）**全部无效**；
   且游戏内「光标所在格」`[0x4B2C60/64]` 在非前台时**完全不更新**
   ⇒ **不是"消息 vs 物理"的差别，是"非前台不收鼠标"**。
3. **引擎里确实有回合推进函数 `0x44E0D9`，但不能直接调**：
   它是**约 0x700 字节的巨型 UI 函数**（内串动画 `0x47EAC4`/`0x47`系、声音 `0x40BE38`、
   刷新 `0x449DE6`、棋盘绘制 `0x453AFF`、并 `call 0x42F699` 弹确认框），**无可用入口与参数契约**。
4. **阶段变量 `0x4B3D18` 全映像找不到写点**（疑间接寻址）⇒ "直接写阶段跳过回合"也不成立。
5. **最省事的现实做法**：**游戏窗口保持在前台**（你就让它开着），
   然后 `托管` + 本页工具链全自动跑；**你切走去看别的窗口时，自动化会停下**（不是失败，是门控）。

## 一、实测矩阵（本会话）

| 通道 | 游戏在前台 | 游戏不在前台 |
|---|---|---|
| `SetCursorPos` + `mouse_event`（物理） | ✅ 有效（本会话点标题页/读档均成功） | ❌ **无效**（4 个空地位置全试） |
| `PostMessage` 右键 down/up | ❌ 无效 | ❌ 无效 |
| `SendMessage` 右键 | ❌ 无效 | ❌ 无效 |
| `PostMessage` 双击右键 | ❌ 无效 | ❌ 无效 |
| `PostMessage` 键盘（Enter/Space/Down） | ❌ 无效（标题页实测） | ❌ 无效 |
| 只读 `ReadProcessMemory` | ✅ 有效 | ✅ **有效**（唯一不受门控的通道） |
| 写 `WriteProcessMemory`（托管/集气） | ✅ 有效 | ✅ **有效** |

⇒ **读写内存不受前台门控；鼠标/键盘输入受**。这就是"静默"的天花板。

## 二、回合推进主函数 `0x44E0D9`（找到但不可直接调）

**定位手段**（老教材的"从界面文字反查"）：搜字符串 `就这站位？等着sl吧`
→ 文件偏移 `0x8CB20` → VA **`0x48E120`** → 引用点 **`0x44E4FE` / `0x44E603`**（都在 `0x44E0D9` 内）。

```asm
0044E4F8  call 0x45461C           ; 收尾
0044E4FD  68 20 E1 48 00        push 0x48E120      ; ★ "就这站位？等着sl吧"
0044E502  6A 01                 push 1
0044E504  E8 90 11 FE FF        call 0x42F699      ; ★ 弹框（返回用户选择）
0044E509  83 C4 08              add esp,8
0044E50C  89 45 F4              mov [ebp-0xC],eax
```

- 该函数还调用 `0x449DE6`（界面刷新，出现 8 次）、`0x47EAC4`/`0x479795`（动画/绘制）、
  `0x40BE38`（音效）、`0x453AFF`/`0x453AC3`/`0x45461C`/`0x45503F`（棋盘/面板）、
  `0x464A32`（**即调预览薄壳，参数 -1**）等 **70+ 个调用**。
- ⇒ **直接 `call` 它会连带跑动画/音效/绘制**，且入口参数契约未知
  （入口 `[ecx+1]` 被当分支条件、`[ebp-8]`/`[ebp-0xC]` 是内部局部）。
- 与库内既有缺口登记一致：`待验证清单` 的
  **P1「内部 action dispatcher ABI：已有攻击入口和自动阶段调用栈，但不能直接内部调用」**。

## 四、要用静默自动化，正确的运行姿势

1. **让游戏窗口保持前台**（你看着它跑，或把它放主屏）；不要切成全屏其它程序。
2. 我这边跑：`_42托管我军.py --on`（托管）+ `大鲸鱼自动战斗.py --go --rounds N --silent`（推进回合；`_静默战场测试.py`、`_静默结束回合.py` 均已退役）
   + `--watch`（只读采样）。
3. **你切走 → 自动化自动停在中途**（右键不生效）；切回来继续即可，**不会产生错误数据**
   （工具会报告"没生效"，而不是假装成功）。
4. 若要"真·完全后台"，只有一条路：**往游戏进程注入 DLL 并钩输入相关 API**
   （`GetCursorPos` / `GetAsyncKeyState` / `PeekMessage`），由钩子喂假输入。
   但本页实测"非前台不更新光标格"⇒ **该路能否成仍未验证**，
   且工作区目前**没有现成的输入类 DLL**（`ExtendData.dll` 是数据扩展，不是输入钩子）。

## 风险与边界

- **不要**为了"静默"去写 `Ekd5.exe` 加输入钩子：那会把"测试用改动"变成"发布级改动"，
  且与 `Ekd5写入串行化规则.md` 的契约冲突。

- `0x44E0D9` 的**入口参数契约**仍未闭环 ⇒ 不要尝试 `call` 它。
