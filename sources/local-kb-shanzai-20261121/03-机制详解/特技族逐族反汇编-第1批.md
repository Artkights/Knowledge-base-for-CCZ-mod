## 结论速览

1. **★ 命名模式（本批 3 族全部适用）**：**一个"族" = 同一个特技出现在多个域**，
   形态是「**1 个桩函数 + N 个域各调用它**」。
   ⇒ **域的差别不在"算什么"，而在"在哪个流程里被触发"**。
   ⇒ 定名时先看**桩查的是哪个特技号**，再看**域被谁调用**。
2. **`0x02 破妄归真`（3 域）**：桩 = **`0x43C72C`**（`call 0x4101D9(特技 0x02, 0x25, 1, 1)`，按参数选个人/装备；命中 ⇒ `AL=0x64`）。
   域体 `0x43C940`（115 条指令）= **一整套"6 槽位逐槽处理 + 概率判定 + 递减"循环**。
3. **`0x6C 自动使用`（3 域）**：桩 = **`0x43E1A8`**（`call 0x42518F(特技 0x6C, 3, 0, arg+0x4E)`）
   ⇒ **按"类型"取自动使用特技值**（3 个域都用 `cmp al,3 / jae 跳过` 判定）。
4. **`0x40 狂妄`（3 域）**：三域共用 **8 个**函数（含 `0x45D3A2`/`0x47CAE3`/`0x45D3CC` 三域全用），
   域体都很大（98~103 条指令）⇒ **属于"战场/单位列表"一族**（见下）。

## 已确认事实：`0x02 破妄归真` 族

**桩 `0x43C72C`**：
```
call 0x40658F                       ; 取单位记录
cmp dword [ebp+8], 0 / je 走个人分支
  真分支: push 1 / 1 / 0x25 / 0x02 → call 0x4101D9(特技 0x02 破妄归真, 0x25, 1, 1)
          test eax,eax / je … / mov al, 0x64        ← 命中 ⇒ AL=0x64
```

**域 `0x43C940`（115 条，全族唯一"实做"的域）关键结构**：
| 位置 | 指令 | 判读 |
|---|---|---|
| `0x43C94A` | `call 0x418C90` + `cmp al,2 / jne 跳过` | **只在 view==2 时生效** |
| `0x43C95C` / `0x43C969` | `call 0x43C72C(0)` / `call 0x43C72C(1)` | 取「个人特技值」与「装备特技值」两份 |
| `0x43C976~0x43C9DA` | `cmp dl,6 / jae 结束` 的循环，索引 **`[unit+edx+0x18]`** | **遍历 6 个槽位**（`[unit+0x18+i]`）|
| `0x43C989~0x43C9A0` | `cmp al,3 / je 跳过`；`cmp al,5 / jb`；`cmp al,2 / ja` | **按槽位当前值分支**：=3 跳过；≥5 则 `dec`；≤2 走概率 |
| `0x43C9AE` | `push 1 / push byte[ebp-4] / call 0x43786B` | **概率/集气判定**（库内记 `0x43786B` 与集气模式相关）|
| `0x43C9C8` | `push … / call 0x45AA37`（9 处调用者） | 施加效果 |
| `0x43C9DC~0x43CA18` | `call 0x42545F` ⇒ `test al,al` / `cmp al,1` ⇒ `dec byte [edx]` | **回合递减**（`al==1` 时改为置 `0x64`）|
| `0x43CA1B` | `cmp cl,0x3C / jb 跳过` | 另一分支的阈值（0x3C=60）|
| `0x43CA21` | `call 0x4841F3`（**全映像仅此 1 处调用**） | 该域**专属**的判定 |
| `0x43CA0D` / `0x43CA53` | `call 0x427CBC(0x2F)` / `call 0x427CBC(0x2C)` | 按 **0x2F/0x2C** 施加（7 处调用者）|

**另两个域**：`0x4263B0` / `0x42FC0C` —— 都只做 `call 0x43C72C` + `call 0x427CBC` 一类的**轻量施加**，
⇒ **本族是"一处大实现（`0x43C940`）+ 两处轻量触发点"**。

## 已确认事实：`0x6C 自动使用` 族

**桩 `0x43E1A8`**（`ret 4`）：
```
push 0 / push 3 / push 0x6c / push (arg + 0x4E) → call 0x42518F
```
⇒ **`arg` 是"类型"，桩查的是 `0x4E + 类型` 号特技**，而 `0x6C` 只是**包装参数**。
**3 个域结构一致**：都先取一个"类型值"，`cmp al,3 / jae 跳过`（类型 ≥3 不算），再 `call 0x43E1A8(类型)`。

| 域 | 条数 | 特征 |
|---|---:|---|
| `0x416442` | 28 | `call 0x422EDF` 取到东西 → 查 `byte[0x505F0C]` → `call 0x43FF54` |
| `0x41DC78` | 55 | `call 0x40658F` 取记录 → `cmp al,3 / jae` → `call 0x43E1A8` |
| `0x465AC1` | 67 | `call 0x426A07`（库内记"按 id 分界 `0x1000` 查"）→ `cmp al,3 / jae` → `call 0x43E1A8` |

## 已确认事实：`0x40 狂妄` 族

**三域共用 8 个函数**（`0x45D3A2` / `0x47CAE3` / `0x45D3CC` 三域全用；另 5 个两域用）。
**域体都很大**（`0x45CE5A` 103 条、`0x45CAE9` 98 条、`0x45DAF5` 102 条），且形态是"**战场/单位列表遍历**"：

* `0x45CE5A`：`sub esp,0x1b14`（**栈上开 6932 字节**）⇒ `mov ecx,[ecx] / mov ecx,[ecx+eax*4] / test ecx,ecx`
  ⇒ **对"slot 索引"查一张指针表**；随后 `push 7 / call 0x47CAE3`
* `0x45CAE9`：`mov cl,[eax+8] / cmp ecx,0xFF / je 跳过` ⇒ 查某记录的 `+8` 字节是否为 `0xFF`
* `0x45DAF5`：`call 0x47CAE3(7)` → `cmp eax,[ecx+4] / jae 跳过` → `imul eax,eax,0x3000 / add ecx,0x58 / call 0x4016BE`
  ⇒ **按 `×0x3000` 步长索引一张大表**（`0x3000` = 12288）

**共用函数 `0x45D3A2`**（三域全用，`ret 4`）：
```
push [ebp+8] / call 0x4050F4 ； push 8 / call 0x40BAD4 ； imul eax, edx, 0x40 ； add eax, 0
```
⇒ **把参数换算成"`×0x40` 步长"的记录地址**（0x40=64）。

**⇒ `0x40 狂妄` 不是"伤害修正类"，而是"单位/战场数据遍历类"**（与 `0x3000`/`0x40` 步长、slot 指针表打交道）。

## 实现·使用方法（复算）

```bat
python 大鲸鱼产生专用\_族分析器.py --family "<族名>" <域1> <域2> …    :: 生成族报告（逐域反汇编 + 调用者反查）
python 大鲸鱼产生专用\_族核心.py 0x43E1A8 0x45D3A2                 :: 反汇编指定核心函数
python 大鲸鱼产生专用\_族摘要.py 大鲸鱼产生专用\_族-*.md            :: 把族报告压成可读摘要
```

**定名流程（推荐）**：
1. `_族分析器.py` 出报告 ⇒ 看「族内共用函数」表 ⇒ **被全部域调用的那个 = 桩**
2. `_族核心.py` 反汇编该桩 ⇒ **看它 `push` 的特技号** ⇒ 确认族身份
3. 逐域看**头 16 条**（`_族摘要.py`）⇒ 按"它先查什么、被谁调"写一句定名

## 风险与边界

* 本批**未实机验证**：所有定名基于静态反汇编 + 调用者反查。

## 2026-10-21 静态补证：0x6C 两张表的真实表项

- 0x4D14E0/0x4D17B0 位于 .text3，必须按 PE 节 RawPtr + (VA - SectionVA) 取文件字节；直接用 VA-0x400000 会读错位置。
- 0x4D17B0 是学会策略类别位：bit0=四系、bit1=降能力、bit2=妨碍、bit3=补给、bit4=升能力、bit5=气候、bit6=绝对、bit7=四神；0x4D14E0 是扩展标记，bit0=策略模仿、bit1=辅助穿透。
- 0x6C 的三个有效类型索引 0/1/2：0x4D17B0[0..2] = 01 01 01，均归入 bit0“四系”类别；0x4D14E0[0..2] = 03 03 03，同时开启策略模仿与辅助穿透。
- 因而 0x43E1A8 的 type=0/1/2 → 查询号 0x4E/0x4F/0x50 不只是范围限制：三种类型在静态表上共享同一策略类别与同一扩展标记。类型具体名称仍需结合调用者传入来源或运行时对象确认。

证据：当前 Ekd5.exe PE 节映射复读；02-数据结构\\复刻版6.6山贼策略记录与施法对象.md；02-数据结构\\策略属性归并表-代码点与数据基址.md；样本 SHA 2A853B0189248761F7FC327419DE3CE9489592AD329289ABCED804258220AB21。
