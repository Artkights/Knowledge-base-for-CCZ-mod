# 特技作用清单：每个特技「改什么、用在哪儿」

> 样本：`Ekd5.exe`（写作时 SHA `F3455B30…` = 干净样本 `2A555B0B…` + 奋战攻击 v1 补丁；
> **补丁只改 `0x43646D`/`0x457E2E`**，与本文所有地址无重叠）
> 证据类型：**静态反汇编**（capstone 5.0.7 现读）+ **调用者反查**（`E8 rel32` 扫全节）
> 触发：用户 2026-10-16「**反汇编每一个特技的作用，狠狠查它调用的地方**」

## 结论速览

1. **全量清单已产出**：`大鲸鱼产生专用\_特技作用.md`（**1058 行 / 183 个判定点条目**）。
   每个条目含：**名表id / 名字 / flag / 桩内特技号 / 桩入口 / 判定点 / ★桩被调用于哪 / ★查到后分支 / 写内存 / 立即数**。
2. **覆盖率（本样本）**：
   | 项 | 数 |
   |---|---|
   | 判定点条目 | **183** |
   | 有「查到后分支」 | **75** |
   | 有「桩被调用于」 | **183**（全覆盖）|
   | **无直接调用者**（经函数指针/间接调用）| **13** |
   | 有「写内存」证据 | **39** |
   | 有「碰到已知区」证据 | 3 |
3. **★ 最大发现：多数桩只做「查一下」就 `ret`** ⇒ 桩本身**不含作用**；
   **作用体现在「谁在什么场合调用这个桩」** ⇒ 因此本清单把**桩的调用者**作为主线索。
4. **★ 存在「共用桩」**：例如 **`0x14 以战养战` 与 `0x15 吸收金钱` 共用桩 `0x406B3C`**
   （两者调用点完全相同：`0x404BBB`、`0x406561`）⇒ **靠参数区分的参数化桩**。
   另：`0x17 奋战攻击` 与 `0x18 引导攻击` **桩内号都是 `0x36`**，但桩入口不同（`0x478E5D` vs `0x4210D0`）。
5. **桩调用点分布**：全部落在 `0x400000` 段（246 处）⇒ 无跨段调用。

## 实现·使用方法

### 重建全部清单
```powershell
python 大鲸鱼产生专用\_特技桩映射扫描.py              # 先有映射
python 大鲸鱼产生专用\_特技作用批量分析.py --n 40 --emit 大鲸鱼产生专用\_特技作用.md
python 大鲸鱼产生专用\_特技作用批量分析.py --id 0x17    # 看单个
```

### ★ 用这份清单"看懂一个特技"的四步
1. **按名字/名表id 查到行** ⇒ 拿 **桩内号 + 桩入口 + 判定点**
2. **看「★桩被调用于」** ⇒ 那几处就是**引擎在什么场合查这个特技** ⇒ 反汇编那几处
3. **看「★查到后分支」** ⇒ 那是**查到之后走哪** ⇒ 反汇编那个分支 = **该特技真正做的事**
4. **看「写内存 / 调用 / 立即数」** ⇒ 判断它**改哪个字段、借用哪条链、用什么阈值**

### 已挖透的范例（可照抄这个模式）
`0x17 奋战攻击`：桩 `0x478E5D` → 在 `0x4363F1` 开头 `0x436421 call 0x478E5D`；
`je 0x436491`（不带就返回）⇒ **`0x4363F1` 是奋战攻击专用的连续攻击处理**；
`[ebp+8]`=行动单位 slot、`[ebp-0xC]`=周边目标 slot 列表指针（`0x500EA5`）、
`cmp [ebp-8], 2` 是次数上限。详见 `特技0x17-奋战攻击次数改造.md`。

## 风险与边界

1. **「写内存」证据里可能有假阳性**：`mov [ebp-4], eax` 这类**栈局部变量**不是"字段"，
   判断"改了什么字段"要看**绝对地址**（如 `[0x4927F0+0x84]`）而非 `[ebp-x]`。
2. **`无直接调用者` 的 13 个**：桩经**函数指针/间接调用**（如 `[0x48B0C0]` 表项），
   `E8` 反查看不到 ⇒ **不能判为"未使用"**。
3. **`push[]` 为空的条目**：那是"另一个形态的桩"（没有 `push` 序列）⇒ 与库内"参数化桩"不是一回事，**待细分**。
4. **只反汇编 40 条且到基本块边界停** ⇒ **"查到后分支"之后的实体会被截断** ⇒ 需要时用 `--n` 加大或单独反汇编该分支。
5. **本文所有数字基于"当前 SHA"**（含奋战攻击 v1 补丁）⇒ 引用前按 §2.5 第 3 步**现读 SHA**。
