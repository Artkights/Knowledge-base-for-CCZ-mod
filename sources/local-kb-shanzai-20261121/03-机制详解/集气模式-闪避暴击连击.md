## 结论速览

1. **数组**：集气池 = 单字节数组，基址 `0x4930C8`，地址 = `0x4930C8 + 战场编号×4 + 字节号`；
   总长 **1000 字节 = 250 单位 × 4 字节**；初始化在 `0x41225A`（`memset(0x4930C8, [0x505EC4], 1000)`），
   初值 = 整型 `4017` = `0x505EC4`。
2. **4 字节映射（实机＋代码级双向确认）**：**字节0=连击 / 字节1=物理闪避 / 字节2=暴击 / 字节3=策略闪避**。
3. **★★ 分流是「双门」，不是 4018 单门**：`0x4287A8+0x12` 先查 `[0x505FDC]`，`0x42882C` 才查 `[0x505EC8]`。
   **集气在装的真条件 = `[0x505FDC]==0` 且 `[0x505EC8]==1`**；任一不满足 ⇒ `call 0x43786B` 原版随机。
4. **分支选择器 = `[ebp-8]` = `模式 & 1`**（0=攻击方累积、1=防守方闪避）；
   `[ebp+8]` 是「本次值」，**不是**分支（旧页与纠正台账的口径纠正见 §十一）。
5. **两套公式**：攻击方 `池 + 本次值 ≥ 100 ⇒ 触发(eax=1) 且 池−100`；
   防守方 `池 + 100 − 传入值 ≥ 100 ⇒ 闪避触发(eax=0)，并扣100`，等价**池每挨一次打涨 `100 − 命中率`**；
   命中率 100 ⇒ 涨 0 ⇒ 池永不满 ⇒ **这就是「必中」的实现方式**。
6. **模式三段编码**：`模式%16` = 字节号（存 `[ebp-4]`）、`模式/16` = 上下文（0 物理 / 1 策略）、`模式&1` = 攻/防。
   已用模式值：连击 `0`、物理暴击 `2`、策略暴击 `0x12`、物理闪避 `1`、策略闪避 `19`。
7. **上下文表实索引（纠正）**：物理取 `0x4927F0[0]`(攻)/`[1]`(防)；**策略取 `0x497AF8[1]`(攻)/`[12]`(防)**——
   `0x4287D7` 是 `mov dl,0xC` **赋值 12，不是 13**；`inc edx` 只走策略攻方。旧页「槽位 13」「物理+余数1⇒槽1」均误。
8. **连击免写回特例**：`0x428814 cmp [ebp+0xC],0` + `0x42881A cmp byte [0x492DF8],1` ⇒
   **模式==0（连击）且 `[0x492DF8]`（= ctx+0x608 连击标志）≥1 时跳过写回**，连击进行中本次不改连击池。
9. **消费者共 7 个入口**：判定函数 `0x4287A8` 的 4 个调用者（`0x406130` 连击 / `0x43B52F` 物理闪避 /
   `0x405EDD` 物理暴击 / `0x40CAAB` 策略暴击）＋ 预览侧 3 个（`0x4131CF`、`0x445D3A`、`0x428925`）。
   预览与实战**共用率函数、不共用值**。
10. **`0x428925` 是第 4 类集气读者（新收）**：`[ebp+0x14]>>1` 索引跳转表 `0x428961 = {0x43B600 物理命中, 0x43B730 策略命中}`，
    再过 4018 门读 `cmp byte [edx+ecx*4+0x4930C8], al`，成立则 `neg eax` = 预览红色「必定」——
    **一值两用**（`>>1` 选上下文、原值作字节号）。
11. **必中三处**：`0x43B60A`（`[0x500E9B]≠0`）、`0x43B4E8~0x43B51E`（4018 + `[0x4B3D18]==0` + 攻击者 `unit+5==0` ⇒ 命中率置 `0x64`）、
    `0x43B7D7`（策略特效 `0x1B`）。命中率 ≥100 时 `0x43B526 jae` **跳过 `0x4287A8`**（不写闪避池）。
    阵营编码 `unit+0x05`：**0=我军 / 1=友军 / 2=敌军**。
12. **命中率被钳在 `[25,100]`**（下限 `0x43B4E3 mov eax,0x19`，物理+策略合流后共用）；
    配「池 += 100−命中率」⇒ 命中率 25 时**约每 4 次攻击攒满一次闪避**（用户口径「敌军每四次」的成因）。
13. **未落地项**：「友军必中」只需 2 字节（`0x43B517` `00`→`01`、`0x43B51C` `75`→`72`），**尚未实施**；

14. **`4018` 同址二义**（台账 :118）：它既是集气开关也是「我方回合我方必中」开关，

## 四、模式编码与两张上下文表（含纠正）

| 段 | 含义 | 载体 |
|---|---|---|
| `模式 % 16` | 数组字节号（0..3） | `[ebp-4]` |
| `模式 / 16` | 上下文：0=物理 `0x4927F0`、1=策略 `0x497AF8` | `call 0x40BAD4` 的商（al） |
| `模式 & 1` | 攻/防 ⇒ **直接就是分支选择器 `[ebp-8]`** | `and edx,1 / push edx` |

**上下文表实索引（现读定案）**：

| 上下文 | 攻方槽 | 防方槽 | 字节 |
|---|---|---|---|
| 物理 `0x4927F0` | `[0]` | `[1]` | 攻=`edx`（0/1） |
| 策略 `0x497AF8` | `[1]`（`inc edx`） | **`[12]`（`mov dl,0xC` 赋值）** | —— |

- **纠正**：旧页「策略+余数1 ⇒ 槽位 = 0xC+1 = **13**」为误——`0x4287D7 B2 0C` 是**赋值 12**；
  `inc edx`（`0x4287DB`）只走**策略攻方**。旧页「余数最低位决定 ctx+0/ctx+1」只覆盖物理侧。
- **一句护栏**：`0x4927F0` / `0x497AF8` **既是集气上下文表、又是伤害数组基址**
  （策略伤害槽 = `0x497AF8+0x108+4×i`；`0x4927F0+0x254` 是 MP 代偿数组，不是策略槽）。

**已用模式值全表**：连击 `0`、物理闪避 `1`、物理暴击 `2`、策略暴击 `0x12`（`18%16=2`，只切上下文不改字节）、

## 六、必中链与阵营区分

命中率总函数 `0x43B4B6`（`ecx`=攻击者、`[ebp+8]`=0 物理/1 策略、`[ebp+0xC]`=目标）；
物理走 `0x43B600`、策略走 `0x43B730`，两条在 **`0x43B4DA` 合流**，之后共用：

```asm
0043B4DE  83 F8 19                 cmp  eax,0x19
0043B4E1  73 05                    jae  0x43B4E8
0043B4E3  B8 19 00 00 00           mov  eax,0x19          ; ★ 命中率下限 25
0043B4E8  90 × 21                  nop  × 21              ; ★ 现读仍全 90 ⇒ 可用洞
0043B4FD  B9 B2 0F 00 00           mov  ecx,0xFB2         ; 4018
0043B502  83 3C 8D 00 20 50 00 00  cmp  dword [ecx*4+0x502000],0 ; [0x505EC8]
0043B50A  74 17                    je   0x43B523
0043B50C  80 3D 18 3D 4B 00 00     cmp  byte [0x4B3D18],0 ; 我方回合？
0043B513  75 0E                    jne  0x43B523
0043B515  8B 4D FC                 mov  ecx,[ebp-4]       ; 攻击者
0043B518  80 79 05 00              cmp  byte [ecx+5],0    ; ★ 阵营门：只放我军
0043B51C  75 05                    jne  0x43B523
0043B51E  B8 64 00 00 00           mov  eax,0x64          ; ★★ 命中率=100 ⇒ 必中
0043B523  83 F8 64                 cmp  eax,0x64
0043B526  73 0C                    jae  0x43B534          ; ★ 100 ⇒ 跳过 0x4287A8（不写池）
0043B52F  E8 74 D2 FE FF           call 0x4287A8          ; 集气闪避判定
```

**必中三处**（都在原始基线自带）：

| 处 | 位置 | 判据 |
|---|---|---|
| ① | `0x43B60A` | `cmp byte [0x500E9B],0 / jne ⇒ 必中`（窄域开关，只被 `0x436D96/0x436DB5` 置/清） |
| ② | `0x43B4E8~0x43B51E` | 4018==1 + `[0x4B3D18]==0`（我方回合）+ 攻击者 `unit+5==0`（我军）⇒ `eax=0x64` |
| ③ | `0x43B7D7` | 策略函数特效 `0x1B` 必中 |

**阵营/阶段/命中区分**：

| 维度 | 载体 | 编码 |
|---|---|---|
| 阵营 | **`unit+0x05`** 单字节 | **0=我军、1=友军、2=敌军**（`0x43B518`；`0x406710`） |
| 阶段 | `0x4B3D18` 单字节 | 0=玩家可控阶段（我方回合）；实测 0↔2 切换 |
| 命中 | 返回 0~100 **不是布尔** | 0=不中、100=必中、1~99 交 RNG/集气 |
| 麻痹⇒物理必中 | 目标 `unit+0x1E` 第 0 个 2-bit 窗口 | `0x43B647`+`push 2` 调 `0x423FE8` |

**两条规则定案（用户口径 2026-10-15）**：

| 规则 | 实施点 | 机制 |
|---|---|---|
| ① 我方回合我方必中（物理+策略） | `0x43B4E8`~`0x43B51E`（合流点之后） | 三判据 ⇒ 置 `0x64`；`jae` 跳过集气 |
| ② 敌军每四次必中一次 | `0x43B4E3`（下限 25）＋ §三 防守方公式 | 池 `+= 100−命中率` ⇒ 命中率 25 时每 4 次攒满 |

规则②算式（命中率恒 25）：0→75（不闪）→150−100=50（闪）→125−100=25（闪）→100−100=0（闪）⇒ 周期性节奏。
**注意**：策略表 `0x4D1720` 里的 `1/2/4` 是"走敏捷算式"的开关值**不是百分比**（`≥5` 才直接当命中率）。

## 九、实现·使用方法

- **读某单位某类集气**：`byte [0x4930C8 + 战场编号*4 + 字节]`（编号 = 单位记录 `+4`，0..249）。
- **喂满集气（测暴击/连击/闪避前必做）**：`大鲸鱼产生专用\_喂满集气.py`（只写进程内存）；
  或直接写该字节 / 改整型 `4017`(`0x505EC4`) 影响初值。
- **开/关集气**：写整型 `4018`(`0x505EC8`) 0/1（**同时切必中**，见速览 14）。
- **实机探针**：`大鲸鱼产生专用\_集气模式探针.py --secs 200`
  （断点 `0x405EDD`/`0x406130`/`0x43B52F`，命中即读并放行；模式值看 `[ebp-8]`）。
- **只读采样**：`_42快采集气.py --secs 90`（40ms 档，只记 4 字节）、`_42集气节奏采样.py --secs 300 --hp`。
- **字节现读纪律**：`_样本时间线.py --verify all` **不登记本族** ⇒ "在装/未装"只能现读判：
  `python 大鲸鱼产生专用\_生成输出\_p2字节快照.py 0x41225A:24 0x4287A8:160 0x428925:48 0x43B4E8:96 0x410FE4:16 0x43F27F:8`
  （同一次读取同时打印 SHA256）。
- **★★ 断点纪律（事故 A2）**：`0x4287A8` 是**每次攻击都命中**的高频地址，**禁止挂普通断点**
  （实测 62 次命中即把游戏拖入反复暂停、回合卡死）；要读入参用日志断点+独立放行线程，或条件断点压到个位数。
- **配合自动化**：`_自动读档进战场.py --go-safe` 进战场 → 喂满/探针 → `_推进回合v2.py --go --rounds 5`（R3 ≤5 回合）。
