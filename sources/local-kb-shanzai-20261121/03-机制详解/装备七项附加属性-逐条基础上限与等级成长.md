## 一、当前版本

## 二、逐条独立规则

索引为「装备编号＋属性编号」。每条分别保存基础值、最高等级、每级增量，任何一项都不与其它条目共用。

当前值=基础值＋（min(max(装备等级,1),本条最高等级)－1）×本条每级增量。

1级取基础值，超过本条上限停止成长；最终钳0..65535。支持负成长，降至0后保持0。最高等级是该条成长的封顶等级，不修改装备自身的可升级上限。未配置基础/成长为0、上限255，不擅自改变装备平衡。刷新/换装/升降级重新计算，不累计写回基础表。

属性编号：0攻击、1防御、2精神、3反应（旧称爆发）、4士气、5HP、6MP；装备0..254有效，255为空。基础u16，成长s16，上限u8且1..255。引擎后续百分比等修正仍会作用于最终人物面板，不能把人物面板差值当作本表原值。

## 三、怎样自定义

编辑本目录的配置示例.json；每条都填「基础值」「最高等级」「每级增量」。示例装备30：攻击10/6/+2、防御5/3/+1。示例没有安装。

默认只生成参数候选、前像补丁和回滚，不改变游戏：

```powershell
python 大鲸鱼产生专用\_生成-装备附加属性等级成长.py --configure "大鲸鱼产生专用\_生成输出\装备附加属性等级成长-20261105_015504\配置示例.json"
```

确认配置后退出游戏，上述命令加 --install 经safe_write_exe安装，自动备份及回读；随后运行_改动总账.py与_样本时间线.py（大输出请重定向）。只覆盖JSON里列出的条目，保留其它装备/属性。

剧本也可在用户自己的编辑流程中手填：

```text
信息传送: 39, "30,0,10,6,2"    # 装备30，攻击，基础10，最高6级，每级+2
信息传送: 39, "30,1,5,3,1"     # 同装备防御独立配置
信息传送: 39, "30,5,100,9,*917" # 成长读取变量917
信息传送: 38, "30,0,10,1,5"    # 兼容旧v2：只改1~3条基础值，不改上限/成长
```

39严格要求5个字段、4个逗号；范围不符不写。38沿用旧v2的u16截断和1~3组语义。剧本指令只修改本次运行内存表；本补丁没有增加存档序列化，跨进程永久默认值用JSON写入EXE。没有替用户编辑任何RS/SV文件。
