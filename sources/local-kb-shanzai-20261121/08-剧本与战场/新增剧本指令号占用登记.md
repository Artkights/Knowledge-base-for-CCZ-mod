## 三、明细：`0x72` P1=38「设置装备自定义附加属性」

### 3.1 作用与剧本写法

```
信息传送: 38, "12,0,30"
```

三个数字依次 = **装备编号 , 属性类型 , 数值**：

| 字段 | 取值 | 说明 |
|---|---|---|
| 装备编号 | `0..255` | 物品编号（`Item.e5` 的顺序号），越界 ⇒ 不写 |
| 属性类型 | `0..6` | `0`攻击力 `1`防御力 `2`精神力 `3`爆发 `4`士气 `5`HP `6`MP |
| 数值 | `0..65535` | 取低 16 位（写 word）；支持 `*n` ⇒ 取 `dword[0x502000 + n*4]` |

- **是「设」不是「加」**：直接覆盖 `word[0x4D0564 + 装备编号*14 + 属性类型*2]`，重复执行会覆盖，不累加。
- `*n` 是引擎 `0x426E64` 白送的能力（`mov eax,[eax*4+0x502000]`），本补丁**未新增任何解析代码**。
- 失败条件（handler 返回 0，外层 `0x47D89E` 仍返 1）：装备编号 `>255` / 属性类型 `>6` / `word[0x4D0560] != 0xAA55`（附加属性表未初始化）。

### 3.5 洞的选取证据（`0x4CFB00`）

- 原 1441 B 全 `90`；取 236 B，洞尾之后 `0x4D00A1 = 55 8B EC 33 C0 …`（下一函数序言）。
- 全样本 dword 直引用 `0x4CFB00..0x4CFBDF` = **0 处**；`E8/E9` rel32 与 `0F 8x` rel32 落点 = **0 处**。
- 起点 4 字节对齐，且**只由 `call dword [P1*4+表]` 进入**（入边唯一），无顺序流落入。

### 3.6 编辑器可写性（**已查清，纠正常见误判**）

- `CczString.ini`（`大鲸鱼产生专用\_外部源码\可视化剧本编辑器MKII-配置\CczString.ini`）是 **GBK 编码**，用 UTF-8 去搜「信息传送」会**搜不到**（2026-10-27 前一窗口即因此误判为"没有"）。
- **第 01 行** = 指令名表，含 `72:信息传送` 与 `7b:信息传送测试`。
- **第 14 行** = `0x72` 的 P1 名单，**止于 `33:设置一个矩形范围的黑幕`**（共 34 项）。
- **第 19 行** = 同内容模板 `wchar_t xxcs[34][30] = { … }`。
- **结论：`P1=38` 可直接手填数值**（编辑器名单只是展示，不限制取值范围；`S_85.eex` 本就存在 `P1=35`，超出名单 33）。若要显示名字，第 14 行末尾追加 `,38:设置装备自定义附加属性`，并把第 19 行 `xxcs[34][30]` 改为 `xxcs[39][30]` 且补齐 `L"34…L"38` 项。
