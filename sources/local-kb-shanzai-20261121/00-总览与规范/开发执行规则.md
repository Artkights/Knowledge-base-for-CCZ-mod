# 08 开发执行规则

## 结论速览

- 适用：页内 6.5 口径条目（`E1000`/`D2800` 指定表校验、`形象指定器6.5\System.ini` 校准来源）只对 6.5 成立；复刻版6.6山贼需另行核对。
- 开发前必读顺序：本地知识库对应页 → `工具整合包\plan.md` 顶部最高优先级章节 → 格式仍不确定时按 `05_工具查询索引.md` 查旧工具目录；未确认格式不得强写，只允许只读、原容量内短写回、已确认字段写回或整文件替换。
- 不可回退：`.E5S` 是存档信息/旧兼容对象，不得再作为 R/S 剧本主格式；`.eex` 才是 R/S 剧本/资源主线，扫描 `RS\R_*.eex` / `RS\S_*.eex`。
- 人物形象链路固定为 `Ekd5.exe R/S 编号指定表 -> R=Pmapobj.e5，S=Unit_atk.e5/Unit_mov.e5/Unit_spc.e5`；6.5 人物 R/S 指定表校验 R=`Ekd5.exe:E1000`、S=`Ekd5.exe:D2800`。
- UI 大型树/列表防重复重读：文件已加载且内存模型有效时必须复用并局部刷新，禁止无条件重读或 `Nodes.Clear()` 全量重建；程序化选择 ComboBox/TreeView 必须压制 `SelectedIndexChanged`/`AfterSelect` 级联二次加载。
- 补丁/备份归位入口 `复刻版6.6山贼\大鲸鱼产生专用\_归档检查.py`（归位 → 改注释路径 → 清 `Zone.Identifier` → 重算判定 → 重写 `_补丁清单与判定.md`），不写 `Ekd5.exe`；接手补丁/EXE 任务的开头与收尾各跑一次。可复用结论按「主文档 `<分类>/<主题>.md` → `00-总览与规范/更新记录.md`（样本 SHA + 地址 + 判据）→ `待验证清单.md` → `90-来源归档/复刻版6.6山贼错误知识纠正台账.md`」落盘，库内结论与实机或字节复读冲突时**以复读为准**。

## 详细记录

本页用于把“先查知识库、再查旧工具、最后改代码”的流程固定下来，避免后续开发再次偏离核心制作工具方向。

#### 开发前必读顺序

1. 先读本地知识库对应页面：
   - 文件后缀/目录：`01_格式与文件后缀.md`
   - 人物 R/S 形象：`03_人物形象_RS_形象指定器.md`
   - 待补充知识：`00-总览与规范/待验证清单.md`
   - 旧工具来源：`05_工具查询索引.md`
   - 验证入口：`06_验证与烟测.md`
2. 再读 `工具整合包\plan.md` 顶部最高优先级章节。
3. 若格式仍不确定，按 `05_工具查询索引.md` 查对应旧工具目录。
4. 未确认格式不得强写；只能做只读、原容量内短写回、已确认字段写回或整文件替换，并明确标注边界。测试副本用于发布前对比和隔离验证，不再作为所有写入功能的前置条件。

#### 当前不可回退规则

- `.E5S` 是存档信息/旧兼容对象，不得再作为 R/S 剧本主格式。
- `.eex` 才是 R/S 剧本/资源相关主线格式；核心剧本制作扫描 `RS\R_*.eex` / `RS\S_*.eex`。
- 人物形象读取必须以 `B形象指定器\形象指定器6.5\System.ini` 为校准来源。
- 6.5 人物 R/S 指定表固定校验：
  - R 形象：`Ekd5.exe:E1000`
  - S 形象：`Ekd5.exe:D2800`
- 人物形象链路固定为：`Ekd5.exe R/S 编号指定表 -> R=Pmapobj.e5，S=Unit_atk.e5/Unit_mov.e5/Unit_spc.e5`；`RS\R_XX.eex / RS\S_XX.eex` 只属于 R/S 剧本、场景和战场 EEX 语境。

#### UI 大型树/列表防重复重读规则

- 对剧本树、战场 S 剧本树、R 场景剧本树等大型 WinForms 树控件，保存、定位、弹窗关闭、变量窗口刷新和跨页面跳转后，默认不得无条件重读文件或 `Nodes.Clear()` 全量重建。
- 当前文件已经加载且内存模型仍有效时，必须优先复用内存模型并做局部刷新：文本节点只更新文本节点，命令参数只更新命令节点，同一 Section 内结构变化只刷新该 Section。
- 只有用户显式切换剧本、目标文件已消失、外部文件发生变化、当前内存模型失效或局部刷新无法定位安全边界时，才允许完整重读和全树重建。
- 程序化选择 ComboBox/TreeView 时必须压制选择事件，避免 `SelectedIndexChanged` / `AfterSelect` 级联触发二次加载。

#### 补丁与备份归档规则（常驻）

用户要求：使用本工作区期间**定期检查、自动归位**补丁文件与备份，根目录只保留游戏本体。落地方式：

1. 归位目标：`大鲸鱼产生专用\`。补丁 txt（以 `.1.0.6.6` 开头的文件）与速查表放本目录；同一功能线的旧方案（如 `HP辅助说明显示-C2/C3/D/E/F`）进 `_已被取代\`，只留最新一版在本目录。
2. 备份归位：`大鲸鱼产生专用\Ekd5备份\` 下按用途分 `可用版存档\`（`Ekd5.exe.GOOD_*`）、`补丁前备份\`（`Ekd5.exe.bak_before_*`）、`崩溃版\`（`bak_CRASHED_*`）、`基线\`（其它 `bak_*`）、`数据备份\`（`*.e5.bak_*` 等）。
3. 说明文档归位：`游戏文档\`（攻略、更新记录、武将说明、游戏说明、`复刻版6.6山贼传-引擎知识库.md`）。
4. 归位后**必须**同步修正补丁 txt 注释行里的备份相对路径（本目录内用 `Ekd5备份\<分类>\...`，`_已被取代\` 内用 `..\Ekd5备份\...`），并逐字节重算每个补丁对当前 `Ekd5.exe` 的生效判定。
5. 执行入口：`复刻版6.6山贼\大鲸鱼产生专用\_归档检查.py`（一键完成 归位 → 改路径 → 清标记 → 重算判定 → 重写 `_补丁清单与判定.md`）。只移动文件、只改注释路径、只删 `Zone.Identifier` 流，不改补丁指令字节、不写 `Ekd5.exe`。
6. 清标记：脚本同时删除新进文件的 `Zone.Identifier`（"来自 Internet"）备用数据流，避免运行 exe 时弹「打开文件 - 安全警告」。用户端已设 `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Attachments\SaveZoneInformation=1`（不再保留区域信息），脚本作为兜底。
7. 触发时机：每次接手补丁/EXE 相关任务的开头与收尾各跑一次；用户新打完补丁后也跑一次。

#### 持续更新规则

每次出现以下情况，必须同步更新本知识库和 `plan.md`：

1. 用户纠正文件格式、工具来源或传统制作习惯。
2. 从旧工具中确认新的字段偏移、字段含义、读写规则。
3. 新增或改变核心读写能力。
4. 验证入口、烟测命令或保存策略发生变化。
5. 发现当前实现与旧工具行为不一致。

#### 知识即时落盘规则（常驻，2026-10-13 用户提出）

用户要求：**有用的知识只要能存进本地数据库，就立刻落盘，避免多次思考。** 落地方式：

1. 触发条件：本次会话产出可复用结论（地址、偏移、字段语义、数据结构、调用链、判定条件、工具用法、验证手法、坑位），且已有证据（字节复读 / 实机命中 / 旧工具源码 / 烟测）。
2. 落地顺序（按需，至少第 1 项）：
   - 主文档：`<分类>/<主题>.md`（同主题只维护一页，七节模板）；
   - 索引：`README.md`、`01-核心引擎/引擎工作索引.md`、`00-总览与规范/工具查询索引.md` 增加入口；
   - 记录：`00-总览与规范/更新记录.md` 追加当日条目（样本 SHA + 地址 + 判据）；
   - 未闭环：`00-总览与规范/待验证清单.md`（`P0/P1/P2` 分级）；
   - 旧结论被推翻：`90-来源归档/复刻版6.6山贼错误知识纠正台账.md` 增加一行（原口径 / 当前证据 / 替代结论 / 处置）。
3. 反向约束（先查后推）：接到引擎/数据问题先检索知识库，确认没有现成结论再逆向；库内结论与实机或字节复读冲突时**以复读为准**，并立即按本规则纠正入库。
4. 自动化入口：工作区根目录 `AGENTS.md`（DSH 每次会话自动加载的指令链）已固化同一规则；该文件只写"必须遵守"的短规则，细节仍留在知识库。
5. 质量护栏：Markdown 用带 BOM 的 UTF-8；链接用知识库相对路径；地址必须附目标 SHA 与证据类型；临时日志、失败记录、备份与构建产物、未验证的跨 SHA 推断不落盘（后者只进"待验证项"）。

#### 面向创作者的优先级

优先完成以下核心创作页的稳定读写和可视化确认：

1. 剧本制作
2. 形象设定
3. 地图制作
4. 战场制作
5. 兵种设定
6. 角色设定
7. 地形编辑
8. 宝物/物品设定

探针、报告、风险检测只作为高级辅助，不得喧宾夺主。
