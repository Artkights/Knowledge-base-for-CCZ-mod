## 结论速览

1. **开场只有一条命令**：`python 大鲸鱼产生专用\_开场.py --task "<任务关键词>"`
   —— 它一次给出：**自检提醒 / 交接 / 台账 / 会话摘要 / 样本时间线 / 三层检索 / 候选工具函数名 / 判据模板**。
   **实测 0.1 秒**（旧版 32.5 秒，因为每次重算样本时间线）。
2. **检索只有一条命令**：`python 大鲸鱼产生专用\_知识检索.py "<人话关键词>"`
   —— **跨三源**（知识库 md + 工具 docstring+正文 + 源码正文按需扫）+ **同义词扩展**。
   例：说「锁血」会自动去查 **`保命` / `LockThread` / `HP`**（因为库里叫"保命"）。
3. **提醒不靠人**：计划任务 **`CCZ-SelfCheck`（每 30 分钟）** 跑 `_自检.py`，写 `_自检提醒.md`；
   `_开场.py` 每次把它打在**最前面**。⇒ **"想起来"变成"磁盘上已经写着"**。
4. **别靠记忆的 4 条固定命令**（见本页末「固定动作」）。
5. **六个断点（B1~B6）已逐个修掉**，每个都有对应工具与验收方式 —— 见下表。

## 实现·使用方法（按顺序照做）

### 第 0 步（每次换会话/换任务，唯一第一动作）

```bat
python 大鲸鱼产生专用\_开场.py --task "<你听到的任务关键词>"
```

**它必须打出这些段**，缺哪段就去修对应工具（这本身就是自检）：

```
【0】自检提醒 …………………………… 计划任务 CCZ-SelfCheck 每 30 分钟刷新（不需要人喂）
【1】交接 ……………………………………… ai使用库\AI协作\交接.md
【2】共享台账末尾 ……………………… 谁做了什么
【3】会话摘要 ……………………………… 另一个 AI 最近在干什么
【4】样本时间线 ………………………… 现读/缓存 SHA（不信手写）
【5】任务检索 ……………………………… 三层 + 同义词；并列出候选工具的**函数名**
【6】判据模板 ……………………………… 前 … → 后 …
```

### 第 1 步 真需要细查时，单独检索

```bat
python 大鲸鱼产生专用\_知识检索.py "锁血 血量"      :: 允许两个词，不够会自动降级
python 大鲸鱼产生专用\_知识检索.py "0x0E" --only tool
python 大鲸鱼产生专用\_知识检索.py --rebuild        :: 索引 1140 条，重建约 32 秒
```

**关键行为**（都实测过）：

* 会打印 `↳ **同义词扩展**：保命 / lockthread / hp`
* **原词全命中**优先；全灭才降级"命中越多越靠前"
* 第三层**源码正文按需扫描**：`def lock(m, hp)` 这种**函数名/变量名**也能搜到

### 第 2 步 用现成工具，不新写

```bat
python 大鲸鱼产生专用\_自动读档进战场.py --go-safe     :: 权威读档（R1 断言 No.001）

python 大鲸鱼产生专用\大鲸鱼自动战斗.py --rounds 5 --no-manage  :: 峰值锁血 + 判据自检（旧 _验收回合推进.py 已退役）
```

### 第 3 步 收工

```bat
python 大鲸鱼产生专用\_归档工具源码.py apply          :: §5 强制归档
python 大鲸鱼产生专用\_自检.py --print               :: 立刻刷新自检提醒
```

并把结论按 `AGENTS.md` §1 落盘 + 台账追加一行。

## 风险与边界

* **B2 的缓存有代价**：样本时间线缓存 5 分钟 ⇒ **刚改过 EXE 后必须 `--fresh`**，
  否则看到的是旧 SHA。索引指纹只算 `mtime+size`，**同秒内改文件可能漏判**（概率极低）。
* **同义词表是人工维护的**（`_知识检索.SYNONYMS`）。发现"人话搜不到"就往里加一条；
  自检 D 项会用 13 个常用人话词定期探针，零命中就报警。
* **缓存文件必须可删**：`_知识检索索引.json`、`_开场_时间线缓存.json`、
  `_自检提醒.md` 都是产物，删掉会自动重建，**不要把结论只放在缓存里**。
* **自检只提示不修改**：它不会自动改文件（避免越修越乱）。待办要人来/我来处理。
