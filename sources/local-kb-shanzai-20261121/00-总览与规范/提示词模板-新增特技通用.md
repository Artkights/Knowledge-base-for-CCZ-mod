# 提示词模板 · 新增 / 移植特技（通用）

> **怎么用**：新建一份特技提示词时，**复制本页**，§1~§5 与 §7~§9 **原样保留**，
> 只填 §6「本特技差异」。差异部分不许写进通用段。
> **通用段要改 ⇒ 先改本页**（否则每个特技各写一套，互相矛盾）。

## 结论速览

1. **三段式**：通用规则（本页）+ 差异（新页 §6）+ 验证用例（新页 §7）。
2. **规则页不放证据**：地址、反汇编、字节快照一律外链；规则页只回答"做什么 / 不许做什么"。
3. **每条规则必须带反例**（"做歪长什么样"）—— 只说该做什么，读者会按自己的理解填空白。
4. **值域按载体形态写死**（单字节 `00~FF` / `imm8` / `dword`），不写"大概够用"。
5. **页内"现行/当前"必须跟 SHA**，否则视为可疑陈述，先现读再信。

## 一、开工前（五件硬动作，缺一不许动字节）

1. **现读优先**：`_样本时间线.py`（SHA + 落点）、`Get-FileHash`（页与文件）、
   `_dsh反汇编工作台.py db/da`（目标字节与指令边界）。**不许用手写 SHA 或旧快照。**
2. **查库**：`_开工门禁.py --full --task "<关键词>"`；结论来自库内就写「库内命中 页:行」。
3. **复用优先**：现成补丁 / 生成器 / 工具 → 扩展现有 → 才允许新建；新建 docstring 必须写
   「已查 N 个现成实现，不采用原因 = …」。
4. **号位现读**：名表全表 dump + `0x4101D9` / `0x42518F` 调用点扫描（判断该号是否已被查询）。
5. **写前三件**：前像逐字节断言 → `_dsh写锁.safe_write_exe`（备份 `edk5（N）<补丁名>`）→ 写后复读。

## 二、号位规则（通用）

| # | 规则 | 说明 |
|---|---|---|
| 1 | **必须写明"号存在哪里"**：名表行 / 洞内立即数 / 参数字节 | 三者的换号成本与风险完全不同 |
| 2 | **优先做成参数字节**（经验：`0x6F` 族 v29 把号位改成 `0x458404` 字节参数，换号只改 1 字节）| 代价：+N 字节洞体；且要避开"dword 读窗口把相邻参数拼进来"的坑 |
| 3 | **换号 = 三处同步**：号位载体 + 新名表行（名+flag）+ 旧行清「预留」| **同一次写完**；分两次会出现"洞认新号、名表指旧号"的中间态 = 功能消失 |
| 4 | **名表只控制显示，不控制逻辑** | 只改名表 ⇒ 新号不触发、旧号仍生效 = 双错 |
| 5 | **禁选**：已被占用的号、撞宝物表的号（`0x9C`/`0x9D`）、同名重复组里非首个的号 | 选号前 dump 全表，不许凭印象说"这号是预留" |
| 6 | **值域写死** | 按载体形态写：单字节 `00~FF` / `imm8`（>`0x7F` 会符号扩展）/ `dword` |

## 三、语义规则（通用）

1. **一句话核心语义** + **三个参数**（谁对谁 / 什么时候 / 做到什么程度），每个参数配一个反例。
2. **两格制**（载体 + 次数）：只持一格不生效；次数为 0 时按设计选择"跳过/视作 1"，**必须写明是哪种**。
3. **生命周期五段**：战斗开始初始化（幂等，不叠加）→ 判定顺序（不成立不扣次数）→ 成功才扣 1
   → 归零后不触发且不清字段 → 载体为空则整技视为不存在。
4. **打断类**：停移动 + 清路径缓冲 + 取消攻击意图，**三者同属一个动作**，不可只做局部。
5. **判定时机写死**：逐格 / 落点 / 回合末，只能选一个，并写明"选错的后果是什么"。

## 四、工程规则（通用，细则见 `AGENTS.md` §3.6.2）

- **挂点**：覆盖 = 整条指令且区间内无 `jmp/jcc` 落点；**入边唯一**；洞内线性；
  回跳前还原寄存器/标志位**含原指令副作用**；**优先影响面最小的点**（不是函数入口）；
  黑名单（`0x43BC5A` 族、`0x405DE1` 内两处）先查表排除。
- **洞**：判洞三步（第②步按指令边界对齐）；起点合法指令边界；占用登记 `--check`；
  扫洞的"干净" = **与工作基底同 SHA**。
- **精简**：洞体目标 ≤150 B；>300 B 必须逐条点名写清"已查哪些引擎函数、为什么不用"；
  过总纲 §7 七项检查表；**代码结束即止，不留填充**。
- **验证**：四条不可省（现读字节 / 前像断言 / 写锁备份 / 实跑判据）；**判崩必须无调试器**
  （x32dbg 只用于取证，两者不能同时）；首次 1 回合 → 过则直接 5 回合，硬上限 5。

## 五、通用禁止项（红线）

1. **只改名表**（只显示不生效）或**只改号位**（生效但显示错）。
2. **改指令边界换号**（`push imm8`→`push imm32` 等）—— 会吃掉后续 `E8`。
3. **手写 `[unit+0x0C]=3`** 代替原生退场 ⇒ 残尸。
4. **在伤害结算里过早 `HP=0 + call 0x441744`** ⇒ 瞬退。
5. **`pushad` 出口不 `lea esp,[ebp-0x3C]`** ⇒ 寄存器读成局部变量 ⇒ 跳数据区。
6. **用单位号 `==0` 判空槽** ⇒ 空槽是 `0xFFFF`（刘备的单位号就是 0）。
7. **阵营读 `+0x0F`** ⇒ 在 `+0x05`（我军 = 0）。
8. **"钳伤害槽 ≤HP"** 当解药 ⇒ 引擎已钳，是空操作。
9. **从被污染样本扫洞 / 凭印象指定号 / 把"生成提示词"当成"实现"**。

## 七、验证用例骨架（复制后把占位符换成实际地址）

**判定**：全对 = 可用；错 1~3 条 = 回改该章；错 4 条以上 = 整页重写。

| 组 | 条数 | 问什么（通用化） |
|---|---:|---|
| A 号位 | 5 | 换号改哪几处 / 能不能改指令换号 / 目标号是否被占用 / 只改名表会怎样 / 挂点函数的前提参数能不能改写 |
| B 语义 | 3 | 某个"解药"是否已被证伪 / 现象出现时先做什么 / 参考实现为什么成功、本实现缺什么 |
| C 数据 | 4 | 索引偏移是否有前置项 / 枚举是否有例外 / 空槽判据 / 阵营与坐标字段 |
| D 流程 | 4 | 首次上洞跑几回合 / 判崩能否开调试器 / 洞体事实源 / 洞体规模是否合规 |
| E 一致性 | 2 | 相邻参数是否被误认 / 作废号是否被复用 |

**实做前自测四条**：A1（换号三处）、A2（别改指令边界）、A5（挂点前提参数）、E1（相邻参数误认）。

## 八、失败信号 → 违反哪条规则（通用）

| 现象 | 违反 |
|---|---|
| 完全不生效 | 号位载体没改 / 只改名表 / **挂点函数的前提参数传错**（最常见，且最难发现）|
| 生效但显示「预留」 | 名表新行没写 |
| 旧号仍触发 | 旧行没清「预留」 |
| 打死又复活 | 缺"全槽判死"（对照原生链补一次）|
| 打完残留 | 缺"用完即清"（追加项没写回 `FF`）|
| 转移/增伤"白做" | 多段连击第二次覆盖了伤害槽 |
| 单体也触发 | 枚举例外没跳过（如 `0x0B`）|
| 转给不该转的阵营 | 阵营字段读错 |
