# 整理与搬迁作业规范（目录清理 / 归档 / 批量移动）

## 结论速览

1. **五步硬流程**：出清单（逐项 大小/mtime/SHA256 + 引用核查）→ 用户勾选 → 逐项 `Move-Item -LiteralPath` → 取证 → 回填索引。缺一步即视为未完成。
2. **只移不删**。删除必须用户当次明确授权；唯一例外是「本次操作自建、且未被引用的 0 字节临时物」，仍须记入移动清单。
3. **判据别用 `git status`**：`.gitignore` 忽略根 `/*` 与 `大鲸鱼产生专用/*`，搬迁前后行数可能同为 91 ⇒ git 视图对本工作区搬迁**不敏感**。真判据 = 关键文件 SHA + 目录/文件计数 + 移动清单。
4. **目的地由用户/复核方定一次**，执行中若调整必须回写清单（例：2026-10-21 把 3 个 Ekd5 副本从 `_EXE副本\` 改到 `_Ekd5版本档案\_根目录副本_<日期>\`）。
5. **引用核查是降级闸门**：`Select-String` 命中即降「待确认」档，不许直接移（实测救回两个：`大鲸鱼工具箱.py:76-78` 的安装器、根 `大鲸鱼专用工具库\` 的唯一源码留档）。

## 实现·使用方法

**① 出清单**：每项写「条目 / 类型 / 大小 / mtime / SHA256（文件类）/ 引用核查结果 / 建议动作」；
分三档：A 可直接移、B 待确认（有引用命中）、C 不许动（游戏本体 / 用户数据 / 现行配置）。

**② 引用核查命令**（缺一不可）：
```powershell
Select-String -Path '大鲸鱼产生专用\*.py' -Pattern '<文件名>' | Select-Object -First 20 Path,LineNumber,Line
Get-ChildItem '大鲸鱼产生专用' -Recurse -Include *.ps1,*.bat,*.cmd | Select-String -Pattern '<文件名>'
```

**③ 执行**：`Move-Item -LiteralPath <原> -Destination <归档> -Force`，**一项一条命令**，禁止通配符批量；
归档目录命名 `_<主题>清理_<YYYYMMDD>\` 或 `_<主题>归档_<YYYYMMDD>\`，内部保留原相对结构。

**④ 取证**（全部贴进 `_移动清单.md`）：关键文件 SHA 前后、目录/文件计数前后、`git status` 行数前后（仅记录，不作判据）、
逐项「原路径 → 新路径 → 时间 → SHA256」。

**⑤ 回填索引**：`README-工作区布局.md` 的 §二 目录表 / §三 关键文件 / §六 可删候选 / §八 更新时间；被移条目在旧文档里的互引要一并改。

## 风险与边界

- **不许用 `Remove-Item` 清场**：移动已完成就别再删；工具脚本自建的临时空壳，删前先断言「创建时间晚于本次操作开始」。
- **不许把「空」当「没用」**：空目录可能是脚本的产物目录，先看 `Attributes` 有无 `ReparsePoint`。
- **不许动**：`RS\`、`SV\`、`Ekd5.exe`、`*.e5`、`*.dll`、`*.avi`、`E5\`、`map\`、`SoundTrk\`、`WAV\`、`BT.DAT`、`AutoDLL.ini`、`.git\`。
- **体积预估别拍脑袋**：按「个数 × 单件均值」算（2026-10-21 预估 ≤30 MB，实际 34 MB）。
