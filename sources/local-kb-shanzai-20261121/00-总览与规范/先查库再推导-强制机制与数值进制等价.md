> **本页定位（2026-10-24 收敛）**：只讲**机制**（三级检索、兜底页名清单、十进制↔`0x` 等价）。
> 要**闸门**（不查库就写不出结论）看 [`查库门禁-分析类落盘必须先查库.md`](查库门禁-分析类落盘必须先查库.md)；
> 要**照抄命令**看 `全链条逻辑-开场检索自检归档.md`。三页互不重复，别轮流通读。

## 结论速览

1. **用户口径 2026-10-15**：「**先查库，再推导，务必啊**」＋「**强检测哦，因为人类普遍爱 10 进制，
   所以写的可能……但是数据偏向 `0x` 也就是 16 进制**」。
2. **本页解决的是"机制"，不是"纪律"** —— 纪律已被违反 **3 次**（浮动伤害、`+0x254`、物品记录地址推导），
   所以把拦阻**做进工具**：`_开工门禁.py`（三级检索 + 兜底页名清单 + 进制自检）、
   `_知识检索.py`（进制等价 + 归档降噪）。
3. **★ 三条硬结论（实测得来）**：
   - **`kb_search` 单次未命中 ≠ 库里没有**：本库**页名与内容经常对不上**
     （内容讲"物品记录地址推导"的页叫 `宝物物品设定.md`）；
   - **用"产物文件名"当关键词最灵**：搜 `物品记录地址推导` **一击命中 3 页**
     （`宝物物品设定.md:265` / `当前进度与交接.md:327` / `更新记录.md:2185`）；
   - **十进制/十六进制结果天差地别**：搜 `0x1A` 命中专页（35 条），搜 `26` 是 **297 条噪声**
     （`0x26`、`2026` 里都含 "26"）。
4. **`_开工门禁.py` 步1 现在的三级检索**：① 整串命中 → ② **分词命中**（任务词按空白/顿号切开）
   → ③ 仍为空则**列出全库页名（按目录分组）**，并提示"用产物文件名再搜"。
   **旧版用整串子串匹配（`if task not in t`）⇒ 任务词一多必然 0 命中**，这正是我漏查的直接原因。
5. **`_开工门禁.py` 步5 新增「进制自检」**：任务词里出现十进制数字 ⇒ 打印
   `26 → 0x1A` 并提示"**再用十六进制搜一遍**"。
6. **`_知识检索.py` 三项改动**：① `--all` 默认**跳过 `90-来源归档`**（192 页，库内自述"默认不读"），
   且**明示"已跳过…加 `--all` 可搜"绝不静默**；② **数值进制等价**（`0x1A`↔`26`）**只做排序加分**，
   命中时打印「⤴ 进制等价命中」；③ 页内含等价写法时提示"本库数据偏向 `0x`，全库检索用十六进制更准"。

### 二、`kb_search` 为什么会假阴性（实测）

- **多词查询要求全命中**：`物品记录 地址 推导 49F820` ⇒ **0 命中**；
  同一主题用**产物文件名** `物品记录地址推导` ⇒ **命中 3 页**。
- **页名与内容脱节**是常态：库里有专门的**「按任务查」README** 就是为补这个，但它只覆盖已登记的任务。

### 三、十进制 vs 十六进制（用户口径的量化证据）

| 查询 | 命中 | 头部结果 |
|---|---|---|
| `0x1A` | 35 条 | **`03-机制详解/恢复HP-MP道具恢复量计算-6.6已定位.md`**（正确答案，排第一） |
| `26`（默认跳过归档） | 199 条 | 噪声（`2026`、`0x26` 等子串） |
| `26`（`--all`） | 297 条 | **头部全是 `90-来源归档` 页** |

⇒ 两个正向补偿：**进制提示**（引导换写法）+ **页内十进制注解**（让另一种写法真实存在）。
**页内注解才是根治** —— 搜索永远搜不到"页里没写的字"。

## 实现·使用方法

| 场景 | 命令 / 做法 |
|---|---|
| 开工门禁（**唯一强制动作**） | `python 大鲸鱼产生专用\_开工门禁.py --task "<任务>"` |
| 手工跨源检索 | `python 大鲸鱼产生专用\_知识检索.py "<关键词>"` |
| **连归档一起搜** | `… --only all` 之外，加 **`--all`**（默认跳过 `90-来源归档`） |
| 只搜云端 | `… --only cloud` |
| 十进制/十六进制互查 | 直接两种写法各搜一次；门禁步5 会**自动提示**换算 |

**新建知识页之前的强制两步**（本轮教训工具化）：
1. **用产物/文件名当关键词再搜**（例：`物品记录地址推导`、`xxx.xlsx`）；
2. **扫一遍门禁步1 打印的全库页名清单**（默认只在"关键词 0 命中"时打印）。
**两步都空，才允许新建页。**

## 风险与边界

1. **进制等价只做加分、不作硬条件** —— 实测把 `26` 的等价 `0x1a` 并进同义词后，
   297 条噪声全被"原词全命中"选中、真知识反被压下。
2. **默认跳过归档是"降噪"不是"删数据"** —— 归档内容仍在索引里，`--all` 即可搜到；
   且每次都会打印"已跳过…"的提示。
3. **"26"这类短十进制数仍会有噪声** —— 子串搜索的物理极限（`2026`/`0x26` 都含它）。
   可靠做法是**改用十六进制**，或用更长的组合词（如 `道具 26 回复`）。
4. 门禁的「进制自检」只看**任务词里的十进制数字**（1–4 位）；
   十六进制输入不触发（无需换算）。
