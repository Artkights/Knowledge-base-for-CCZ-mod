# 注入补丁交付格式——人类可读规则

> 适用：给**外部基底**（别人的游戏、别的工作区）做 `.1.0.6.5` / `.1.0.6.6` 注入式补丁时，交付的那个 txt 怎么写。
> 起因：2026-11-02 逐鹿1.0 交付，用户口径「写好文字说明，那些乱七八糟、只有 AI 才能看得懂的别写的」
> ＋「做成可自由切换特技号的，改一个字节即可」。
> 与 `特技补丁写法总纲-引擎优先与精简理念.md`（管引擎代码怎么写）不冲突：本页只管**交付文本长什么样**。

## 1. 一条总则

使用者拿到文件要能自己做成三件事：**看懂效果、改参数、撤销**。
凡是要他回来问我们一句的地方，都算这份补丁不合格。

## 2. 文件结构（顺序固定）

| 顺序 | 内容 | 写法 |
|---|---|---|
| 1 | 头部说明 | 全部 `#` 注释，内容见 §3 |
| 2 | 版本行 | `.1.0.6.5` 或 `.1.0.6.6`（按目标补丁工具） |
| 3 | `o` | 原样一行 |
| 4 | 代码块 | `-地址` ＋ 每行 ≤16 字节，可多行续写 |
| 5 | 可改参数块 | 见 §4，**必须从代码主体里切出来** |
| 6 | 数据 / 名表块 | 注释标「可选」 |

## 3. 头部说明写什么

必写六项：

1. 一句话效果 ＋ 计算公式 ＋ **一个具体数字例子**（例：伤害 100、特效值 30% ⇒ 上限 −30）；
2. 数值边界：范围（0~100 百分比）、最低值（下限 1）、无效条件（无特技 / 特效值 0 / 伤害 0）；
3. 副作用：例如「当前血量可能高于上限，会显示 100/70」；
4. 生效范围：物理 / 策略、是否只对攻击方；
5. 怎么导入：游戏自带补丁工具直接导入，不用改别的东西；
6. 怎么撤销：指向同目录回滚件。

**禁写**（这些只有内行看得懂，写了等于没写）：
SHA256、文件偏移、寄存器名、汇编助记符，以及 `hook / 洞 / 入边 / 基线 / 栈平衡 / 前像` 这类术语。
`-地址` 行本身是工具必需格式，保留；但**注释里不要解释它**。

## 4. 可改参数块（核心：改一个字节就能换号）

要求四条：

- 一行 `-地址` ＋ 一行字节，例如 `68 D9 00 00 00`；
- 前后用 `# ---------- ▼ … ----------` / `# ---------- ▲ … ----------` 包住；
- 注释写明：**改第几个字节、能改成什么、同一行其余字节不要动、必须挑空号**（重号会与已有特技叠加）；
- 该块前后的代码**各自独立成块**（地址连续、不重叠），这样用户改号不必重算地址。

判别标准：换号后全文只应差 1 个字节。

## 5. 回滚件

- 单独一个文件，字节取自**原版基线**（不能依赖"已经打过补丁的 EXE"，否则它自己就失效）；
- 注释写清「导入后回到打补丁前」，并说明「换过特技号、或改过参数，同样用这一个回滚件」。

## 6. 生成后必须自检（脚本里做，不靠眼看）

1. **解析回读**：块数、每块长度、地址升序、相邻段无缝且不重叠；
2. **拼回一致**：把切开的参数块与代码块拼回去，必须与完整代码**逐字节相同**；
3. **模拟换号**：把参数块那个字节改成另一个值，全文应**只差 1 个字节**；回滚件与注入件的地址要一一对应。

## 7. 隔离

对方游戏的具体地址 / 字节 / 数据只落 `大鲸鱼产生专用\其他游戏\<项目>\`；
进本知识库的只能是**通用格式规则**（本页）和可复用做法，不带对方数据。
