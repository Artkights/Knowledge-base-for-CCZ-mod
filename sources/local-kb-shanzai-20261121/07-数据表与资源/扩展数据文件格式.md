# 扩展数据文件格式（Effect.e5 等）

## 结论速览

`CCZ-ExtendModifier` 生成 4 个配置文件，由 `ExtendData.dll` 在运行时读取：

| 文件 | 内容 | 结构（源码实测） |
|---|---|---|
| **`Effect.e5`** | **特技数据** | `1024 角色 × 256 槽 × 4 字节` = **1,048,576 字节** |
| `MeffStudy.e5` | 策略数据 | `1024 × 32 × 2`（`person_meff`，2 字节/槽） |
| `Forge.e5` | 锻造配方 | `1024 × 64`（`FORGE_ENTRY_SIZE = 64`） |
| `Effectmsg.e5` | 特技消息配置 | `256 × 8`（`effect_message[256][EFFECT_MSG_FIELDS]`） |

## 适用版本

- 曹操传 6.6 系；文件由 `CCZ-ExtendModifier` 生成，`ExtendData.dll` 读取。

## 已确认事实

### 1. `Effect.e5`（★ 最重要）

`ExtendModifierTEJI.cpp` 的 `loadData` / `SaveData` 直接给出公式：

```c
// 初值模式（改文件）
ifstream file("Effect.e5", ios::binary);
file.seekg(per * 256 * 4, ios::beg);          // ★ 偏移 = 角色号 × 1024
file.read((char*)&person_effect, 256 * 4);    // 读一整个角色的 256 个槽

// 内存模式（改运行时）
ReadProcessMemory(hpro, (LPVOID)(0x4F0004), &addr, 4, 0);
ReadProcessMemory(hpro, (LPVOID)(addr + per*256*4), &person_effect, 256*4, 0);
```

- **文件偏移 = 角色号 × 0x400**；一个角色 1024 字节 = 256 槽 × 4 字节。
- 槽 4 字节 = `[特技号, 特效值, 经验值, 剩余回合]`（`[0]=0xFF` 空槽，
  `[3]=0xFF` 永久）。
- 文件总长 = `1024 × 1024` = **1,048,576 字节**（实测一致）。

### 2. 我们此前实测的交叉印证

- `Effect.e5` 实测 **1,048,576 字节** = `1024 × 0x400` ✓
- 角色 330 在文件的 `330 × 0x400 = 0x52800`，槽 4 在 `+0x18`
  ⇒ `24 14 00 FF`（0x24 值 20）**实测命中** ✓
- 角色 47 的 `0x24` 在 `0xBC10` = `47×0x400 + 0x10` ✓

### 3. 与游戏自带 `.E5S` 存档的关系

- 游戏存档 `SV\SV001.E5S` 里**也有**特技相关数据，但**不是**这个 1 MB 表
  （实测搜 `24 14 00 FF` 无命中）⇒ 两者的存储形态不同。
- `ExtendData.dll` 另写 **`.EXS`** 扩展存档（`person_effect` 整块）。

```bat
:: 改文件（初值模式）—— 必须原位写，且改完要重启游戏
大鲸鱼产生专用\_pyrun.cmd 大鲸鱼产生专用\_改Effect数据源.py --char 0 --slot 2 --skill 0x24 --value 75

:: 改内存（内存模式）—— 立即生效
用 ExtendModifier：把「当前:初值」点成「当前:内存」，选角色、设特技与值、保存
```

## 风险与边界

- **改 `Effect.e5` 影响所有存档**（启动时加载）；测试完务必还原。
- **不要用"读全部→写全部"改这个文件**（会截断，实测踩过：1048576 → 1048556）；
  必须 `r+b` + `seek` **原位写**，并在写后校验总长度。
- 读档时 DLL 会用 `.EXS` 覆盖内存表 ⇒ 改内存后读档可能失效。
