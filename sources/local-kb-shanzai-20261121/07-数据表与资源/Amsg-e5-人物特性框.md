# Amsg.e5 —— 人物特性框（说明介绍）

> 目标样本：`复刻版6.6山贼\Amsg.e5`
> SHA256 `66C8DF5B00981F185C1A417A426A7F80F1549AFBE876A1AA42F271D9DDE8F6BB`
> 大小 409800 字节（= 2049 × 200）
> 引擎：`Ekd5.exe` SHA256 `BE86A64935BFC1314AB2B51D9519E5625435B239756115476F69315C31C3213A`
> 证据类型：**字节取证 + 静态复读（capstone 精确解码）**

## 结论速览

- `Amsg.e5` 是**定长 200 字节（0xC8）记录表**，共 **2049** 条。
- **隔条存放**：偶数槽 = 特性**名称**（前 16 字节，GBK + 0 填充）；奇数槽 = 对应**说明正文**（GBK，`\r\n` 分段）。
  - 例：`rec[3] @ 0x258` = `忠魂义绝`（名称）；`rec[4] @ 0x320` = 该特性的说明全文。
- 文件头（`rec[0]`）= 自述文字 `山贼人物特性框文件。`
- 读取算法（`0x4C0600` 等函数实测）：
  `offset = (2 * idx + 1 + k) * 0xC8`，其中 `k = 0`（名称）或 `1`（说明），`idx` 取自 **`byte[0x500E28]`**。

## 适用版本

- 复刻版6.6山贼（`Amsg.e5` SHA256 `66C8DF5B00981F185C1A417A426A7F80F1549AFBE876A1AA42F271D9DDE8F6BB`；`Ekd5.exe` `BE86A64935BFC1314AB2B51D9519E5625435B239756115476F69315C31C3213A`）。
- 6.5 或其他版本不得套用。

## 已确认事实

### 1. 记录结构（字节取证）

| 记录 | 文件偏移 | 内容 | 说明 |
|---|---|---|---|
| `rec[0]` | `0x000000` | `山贼人物特性框文件。` | 文件自述 |
| `rec[1]` | `0x0000C8` | `英雄之器` | 名称 |
| `rec[2]` | `0x000190` | `英雄之器：\r\n自身免疫DEBUFF且永远获得敏捷buff。…` | 说明 |
| `rec[3]` | `0x000258` | `忠魂义绝` | 名称 |
| `rec[4]` | `0x000320` | `使用攻击指令时，降低目标敏/士/精。\r\n\r\n小将专属刀法：…` | 说明 |
| `rec[5]` | `0x0003E8` | `嗔目豪夺` | 名称 |

- 名称槽：前 16 字节有效（最多 8 个汉字），其余补 0。
- 说明槽：整 200 字节可用（实测最长约 168 字节）。
- 编码：**GBK（CP936）**；`\r\n` 为硬换行（界面按行显示）。

### 2. 读取链（静态复读）

| 位置 | 作用 |
|---|---|
| `0x0046D100` | **对话过程**（对话框 `343` 说明介绍）—— `WM_INITDIALOG`/`WM_LBUTTONDBLCLK`/自定义消息 `0x591` 分发 |
| `0x0046D157` | `cmp eax, 0x591` → 命中则 `push [ebp+8]; call 0x4C0600` |
| `0x004C0600` | 读 **名称**：`idx = [0x500E28] * 2`；`offset = (idx+1)*0xC8`；读 0xC8 字节 → `SetDlgItemTextA(hDlg, 0x803, buf)`（控件 `2051`） |
| `0x004C06A9`~ | 读 **说明**：`inc idx`（= 奇数槽）→ 同样 `(idx+1)*0xC8` → 写入控件 `2052` |
| `0x4C0810` | ASCII 字符串 `AMSG.E5`（在 `.api` 段；被 3 处 `push` 引用：`0x4C062E` / `0x4C06C7` / `0x4C077F`） |
| `0x00500E28` | **当前特性索引**（字节）；读点：`0x44D4EA`、`0x456CCE`、`0x4C0609`、`0x4C075A` |

**关键算式（写进代码里的）**：
```
offset = (2*idx + 1 + k) * 0xC8      k=0 名称, k=1 说明
```
即：`idx=0` → 名称 `rec[1]`、说明 `rec[2]`；`idx=1` → 名称 `rec[3]`、说明 `rec[4]`（正是「忠魂义绝」）。

## 实现·使用方法

### 查看/编辑内容

- 名称槽在 `(2*idx+1)*0xC8`，说明槽在 `(2*idx+2)*0xC8`，均为 GBK、定长 200 字节。
- 名称最多 8 个汉字（16 字节含结束符）；说明可用满 200 字节（含 `\r\n`）。
- 改文字**必须保持记录长度 200 字节**（超长会溢出到下一槽）。

### 新增一个特性栏位（用户目标：再增一个「忠魂义绝」这类栏位）

需要三步，缺一不可：

1. **数据**：在 `Amsg.e5` 里找一对空槽（或扩文件），写入名称（`(2*idx+1)*0xC8`）与说明（`(2*idx+2)*0xC8`）。
2. **分配**：让某个武将/装备能取到该 `idx`。索引来自 `byte[0x500E28]`，
   需查清它的**赋值来源**（当前仅确认 4 个读点，写点未定 → 待验证 P0）。
3. **界面**：对话框 `343` 目前只有 1 个名称 + 1 个说明控件。
   若要**同时显示多个特性栏位**，需改模板新增 `STATIC` 控件，并在对话过程里多读几槽。

## 风险与边界

- 记录长度固定 200 字节：**名称超 16 字节 / 说明超 200 字节会踩坏下一条**。
- `[0x500E28]` 的**写点尚未定位** —— 不知道"当前特性"由谁决定，就无法把新栏位分配给指定武将。
- 对话框 `343` 改模板 = 改 `.rsrc` → 动 PE，**必须走 `大鲸鱼产生专用/_dsh写锁.py` + 备份 + 复读**。
- 资源字符串为**标准 UTF-16LE**（已实测确认，见 `界面框架与资源索引.md`），
  但 `Amsg.e5` 内容为 **GBK**，两者不同，勿混。

## 证据来源

- 字节取证：`Amsg.e5` 按 0xC8 切分逐条打印（`rec[0]`~`rec[5]` 见上表）。
- 静态复读：`capstone` 精确解码 `0x4C0600`/`0x4C06A9`/`0x46D100`。
- 字符串引用：全 exe 搜索 `AMSG.E5` → `.api` VA `0x4C0810`，3 处 `push`。
- 索引字段：`0x500E28` 的 4 个读点（`0x44D4EA`/`0x456CCE`/`0x4C0609`/`0x4C075A`）。
- 样本 SHA：`Amsg.e5` `66C8DF5B00981F185C1A417A426A7F80F1549AFBE876A1AA42F271D9DDE8F6BB` / `Ekd5.exe` `BE86A64935BFC1314AB2B51D9519E5625435B239756115476F69315C31C3213A`

## 待验证项

- **P0**：`byte[0x500E28]` 的**写点**（谁设置"当前特性索引"）—— 决定新栏位能否分配给指定武将。
- **P0**：`0x4C0750` / `0x4C07C0` 两个函数的调用者（是否还有别的界面也读 Amsg.e5）。
- **P1**：2049 条记录中已用/空槽清单（便于找空位新增）。
- **P1**：名称槽是否真的只用前 16 字节（是否有超过 8 汉字的实例）。
