> 用户口径 2026-10-16：「（goal ③）继续 `Data.e5` 段#0/#2/#3/#4」

## 三、已确认事实

### 3.1 记录步长与条数（实测证据）

- 人物名偏移：`刘备 @0x0000`、`关羽 @0x0020`、`张飞 @0x0040`、`马超 @0x0060`、`赵云 @0x0080`
  ⇒ **相邻间距恒为 `0x20 = 32`** ✓
- 相邻人名间距分布：**`32` 字节 × 2 次**（其余间距为跳名所致）✓
- `32768 / 32 = 1024` ⇒ 与武将表上限一致 ✓

### 3.3 与"运行时武将记录"的关系（**未验证，勿混用**）

- **本表 = `Data.e5` 段 #0（静态、32 字节/条、1024 条）**；
- **运行时武将记录 = `[0x4CEA00] + 编号 × 0x48`（72 字节/条）**，其 `+0x2A` = 阵营、`+0x2C` = 等级；
- **二者字段布局不同**（本表 `+0x2A` 落在记录 32 字节之外 ⇒ **不同一张表**）⇒
  **不要把 `+0x12~+0x16` 与运行时记录的任何偏移互套**。

## 四、实现·使用方法

```python
d = open("Data.e5","rb").read()
seg0 = d[0x18C:0x18C+32768]
def person(i):                       # i = 0..1023
    r = seg0[i*32:(i+1)*32]
    return {
        "name": r[0:12].split(b"\x00")[0].decode("gbk","replace"),
        "seq":  r[0x0F],
        "atk":  r[0x12], "int": r[0x13], "lead": r[0x14],
        "agi":  r[0x15], "luck": r[0x16], "base": r[0x17],
    }
```

## 五、风险与边界

- **只读结论**；写 `Data.e5` 需先备份 + 写后复读（本项目工具已具备该能力）。
- **字段顺序（武力/智力/统率/敏捷/运气）是根据"数值与人物设定吻合"推断**，
  未与引擎读取代码逐字段核对 ⇒ 引用前建议再用一句话三方对照（如读`曹操`的智力应最高）。
- 标 `?` 的偏移尚未定案。
