## 结论速览

1. **`SV000.EXS`（1,384,448 B）= 战场地图快照**：非零区 `0x32000 ~ 0x132100`，
   内含 **`0x100000`（1 MB）连续格子数据 + `0x100` 字节头**；**每格 4 字节**：
   `WORD 值`（小端）+ `0x00` + `0xFF`；**未用格 = `FF FF 00 FF`**。
2. **`SV000.E5S`（277,126 B）= 存档主体**：开头是 **`WORD` 数组（值域 0~429，疑为 ID/编号列表）**，
   `0x8000` 起是**关卡 / MOD 说明文本区**（含"刘备：群雄…"、"黄巾讨伐战"、"胜利条件：杀完！"等）。
3. **`SV.E5S`（271 B）= 存档索引**（档位/进度标记，后段大量 `01`）。
4. **存档不含任何 `.e5` 段副本** —— 逐段搜索 `Data.e5`（10 段）与 `E5\Item.e5`（513 段）**全部 0 命中**
   ⇒ **存档是"数值化状态"，数据表仍从 `.e5` 读**。
5. **武将名字不在 `SV000.EXS`**（刘备/关羽/张飞搜不到）⇒ 地图/单位数据用**编号**而非名字。

### 2. `SV000.EXS` 布局
```

0x32000 ~ 0x1320FF  数据（0x100100 = 1 MB + 256 B）
0x132100 ~ 末尾     全 0
```
**非零字节 786,418 / 1,384,448（56.80%）**。

**0x32000 处实测**：
```
A5 01 00 FF  71 02 00 FF  10 64 00 FF  FF FF 00 FF  FF FF 00 FF  FF FF 00 FF …
└─421─┘      └─625─┘      └0x6410┘     └──── 未用格 ────┘
```
⇒ **每格 4 字节 = `WORD 值` + `0x00` + `0xFF`**；1 MB ÷ 4 = **262,144 格**（如 512×512）。
