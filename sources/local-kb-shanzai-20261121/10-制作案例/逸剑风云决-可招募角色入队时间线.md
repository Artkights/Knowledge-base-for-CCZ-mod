# 逸剑风云决 · 可招募角色入队时间线

> 用途：给《侠客风云传前传》复刻逸剑角色时，确定「打到哪一关、队伍里该有谁」。
> 证据基准：逸剑风云决 Wiki（yijianwiki.cn）对 **v1.24.32 解包数据** 的导出——NPCs 表（角色 ID/等级）、Quests 表（任务效果字段 `加入队伍` / `离开队伍`、任务条件字段 `前置任务` / `好感≥N`）。
> 攻略印证：B 站「力拔山兮气盖世呐」v1.24.25 全图鉴流程攻略（上篇）、游侠网、3DM、九游、17173、NGA。
> 本文所有「确认」= 解包数据与攻略能对上；「待证」= 只有一边，不能当定论。

## 结论速览

- 全库解包数据里带 `加入队伍` / `离开队伍` 效果的**任务页共 147 个**，这是数据侧唯一可靠的招募证据；`NPCS.json` 本身不写「是否队友」。
- 7 个重点角色里，**6 个能靠数据+攻略双证**：卫霍、上官虹、司马铃、吕仙儿、冷无情、江小彤；**白锦的早期入队数据侧没有标记**（靠好感邀请），只能标待证。
- **江小彤不是纯 NPC**：她在终章主线【玉龙吟】(24020) 的步骤 29138 明确 `加入队伍` 且好感 +100。但本体前期不可招募；队友表里列的 10017（幼年版）条件写着「未接取：升级一次基础心法」，是数据残留，不是真实招募条件。
- 顺序（本体）：卫霍 → 上官虹 → 司马铃 → 白锦 → 冷无情 → 吕仙儿 → 江小彤。
- 「加入队伍」不等于常驻：冷无情在雷家村只是剧情临时入队，永久入队要打完覆海蛟；卫霍、上官虹在中后期主线会被强制离队再归队。
- 章节名（初出茅庐篇 / 入门弟子篇）是攻略分篇，**不是游戏官方章节**；官方只有主线任务名，本页用主线任务做锚点。

## 1. 数据侧证据怎么读

| 数据字段 | 位置 | 能回答什么 |
|---|---|---|
| NPC ID / 等级 / 门派 | NPCs 表（每个 NPC 详情页） | 角色身份；同名多实例要挑主线版 |
| 任务效果 `加入队伍: NPC/x(ID)` | Quests 表「任务效果与奖励」 | 哪一步把人加进队伍 |
| 任务效果 `离开队伍: NPC/x(ID)` | 同上 | 何时被移出队伍（剧情强制） |
| 任务条件 `前置任务` / `好感≥N` | Quests 表「任务条件」+ 队友表 | 招募门槛 |
| 队友表「入队条件 / 离队条件」 | 专页 `队友`（23 人） | 哪些人能通过「邀请入队」成为队友 |

读法要点：一个角色可能多次 `加入队伍`。第一次往往是剧情临时入队，最后一次才是常驻；判断常驻要同时看「后面还有没有 `离开队伍`」和「队友表有没有登记」。

## 6. 存疑与待证

1. **白锦早期入队无数据标记**：Quests 表只有 16653/16654（霹雳门余波）的 `加入队伍`，那是后期剧情再入队；早期落英林招募走的是「好感邀请」，不写任务效果。复刻时以攻略节点为准。
2. **卫霍 7038 离队后无再加入记录，但 21042 又出现离队**：说明中途存在非任务途径的归队（好感邀请），数据侧没有覆盖，需要实机或存档验证。
3. **江小彤 10017 是数据残留**：队友表把它列为可招募，条件却是「未接取：升级一次基础心法」（新手教学任务），明显是占位/脏数据；真实入队对象是 8500，发生在玉龙吟。
4. **上官虹/司马铃的离队是主线强制**，不是玩家操作，也不代表失去队友资格；8063-8065 会归队。
5. **冷无情 12523 的 `加入队伍` 是雷家村临时随行**，12525 就离队；把这一步当「永久入队」是常见误判。
6. **章节名不统一**：攻略用「初出茅庐篇/入门弟子篇」，游戏内只有主线任务名。本页一律用主线任务 ID 当锚点，避免章节叫法对不上。
7. **版本差异**：数据是 v1.24.32，攻略是 v1.24.25；更早的 1.20.4 攻略节点可能有出入（例如早期武学/DLC 内容）。
8. **女帅幻象（46004）是幻象**，条件与吕仙儿完全相同，不是独立队友。
9. **霍长青（10804）**队友表写「对话邀请入队」，但数据侧找不到对应任务效果，标待证。
