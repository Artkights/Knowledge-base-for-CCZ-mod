## 结论速览

1. **文档身份 = 原版《曹操传》＋ 6.1–6.3 世代（多来源合集）**，不是 6.6。
   判据：战场单位 `4B2C50`／步长 `0x24`、人物记录 `Data号×0x48 + 0xD60000` **立即数常量**、
   致命一击 = **概率检定**（`0x47FB32`）、伤害公式内**含 ±随机**（`push 7`）。
   ⇒ **算法与语义可全盘借用；地址、参数极性、取值域一律不得直用。**
2. **世代判别法（本页最有用的方法，4 条即可判定"这份资料属于哪一代"）**：
   ① 战场单位基址/步长；② 人物记录取法（常量 `D60000` 还是指针 `[0x4CEA00]`）；
   ③ 致命一击是"概率"还是"集气累计"；④ 伤害公式内是否还有内联随机。
   6.4/6.5/6.6 世代 = `0x4A7B20` / `0x30` / `[0x4CEA00]` / 集气 / 无内联随机（库内已登记）。
3. **★ 6.6 的伤害公式 `0x43BC5A` 的 arg1 类型变了**：6.6 是**被攻击方单位指针**
   （`0x43BC66 movzx eax,byte [ecx+4]` 直取战场形象编号）；原版 `0x43BC4B` 的 arg1 是
   **被攻击方 Data 记录指针**（先 `call 0040BE7D` 取 Data 号，再 `0043E4D6` 转战场编号）。
4. **★ 6.6 的 arg2 极性与原版相反**：6.6 `0x43BD0C: cmp [ebp+0xC],0 / jne 0x43BD2A`
   ⇒ **arg2==0 才执行命中/格挡检定**。故 6.6 **预览传 `1`（跳过检定＝理论伤害）**、
   **实战传 `0`（检定＝实际伤害）**；原版正好相反（`!=0` 才检定，预览传 0、实战传 1）。
   ⇒ 拿原版文字照搬到 6.6 会把"理论/实际"整体说反。
5. **`0x4927F0+0x254` 不是"策略伤害槽"**：6.6 物理伤害函数 `0x405DE1` 入口把 `ctx+0x84` 与
   `ctx+0x254` **各 memset `0x74` 字节**（`0x405DF1`/`0x405E06`），`+0x254` 只在
   **防御MP（效果 `0x3C`）**分支被写（`0x405FA9 mov [ecx+edx*4+0x254],eax`、`0x40600F add …`）
   ⇒ 语义 = **每个目标的"MP 代偿吸伤量"数组**；策略伤害数组属**策略上下文**（库内 `0x497AF8`）。
   （库内 `02-数据结构/战斗数据结构.md` 速览第 2 条的并列写法按本条收窄。）
6. **★ 预览函数 `0x44049E` 的入参定性（并反过来验证我们已装 cave 的取参是对的）**：
   `[ebp-0x28]` = **入参 ECX = 被预览(目标)单位指针**；
   `[ebp-0x2C]` = `0x44065E` 缓存 = **攻方单位指针**
   （`0x440656 mov cl,[ebp+0xC]` → `0x440659 call 0x4061F9` → `0x44065E mov [ebp-0x2C],ecx`）。
   已装 cave（蹦床 `0x457DB4` → 体 `0x457DD0`）把 `[ebp-0x2C]` 当 arg2(攻方)、`[ebp-0x28]` 当 arg3(目标)，
   **与上述一致**（静态复读级）。原版没有 `[ebp-0x2C]` 这个局部。
7. **`ctx`（`0x4927F0`）字段表获得独立来源交叉确认**：`+00` 攻方 slot、`+01` **当前目标** slot（逐目标覆写）、
   `+04` 攻方 Data 号、`+08` 攻方人物记录、`+0C` 攻方单位指针、`+10` **目标 slot 数组**（`0xFF` 结束）、
   `+84` 物理伤害数组、`+254` MP 代偿数组、`+604` 暴击标志、`+608` 连击/循环计数、`+614`(= `0x492E04`) 反击链计数。

### 四、原版可复用的算法（语义级，落 6.6 前须重定位）

- **致命一击**：率函数 → 概率/集气判定 → **伤害 `×3/2`**（`IMUL EAX,EAX,3; …SAR EAX,1`）→ 置 `ctx+0x604`；
  目标带**"防致命一击"**时伤害清零。6.6 的 `150 + K/2 + 特效0x70` 百分比式**保留了 `150`（=3/2）这个基数项**。
- **攻击方类相克表**（职业 `1..5` 跳转）：弓/弓骑/炮 → 对骑兵(3)/训虎(0x11)/训熊(0x10) `×3/2`；
  步兵 → 对骑兵 `×3/5`（下限 1）、对弓兵(2)/炮(5) `×3/2`；骑马攻击(装备属性 0x2D)按效果值百分比加成；
  反击（arg3≠0）`×3/4`。⇒ 与库内"兵种相克"页口径可互证。
- **AI 打分校核**（原版 `438A20` 估算 / `438D96` 汇总）：可击杀 = `0x50`；`伤害×10 ÷(目标士气+道具)` ≥1 = `0x10`；
  `HP×100 ÷(目标士气+道具)` ≤40 = `0x10`；可控标记 1 = `0x0A`，否则 `0x02`；目标混乱 `+8`；
  主将 `+8`、非主将 `+4`；权值 <`0x4B` 且攻击者是文官 ⇒ 返回 0。
  ⇒ 6.6 的对应函数与权值**未核**（见待验证）。
- **策略→效果码映射**：`42313E` 用跳转表把策略号映射为效果码（`40` 损HP／`50` 谍报／`62` 降低敏捷／
  `64` 降低士气／`60` 降低能力／`61` 降低防御／`71` 混乱／`70` 中毒／`72` 麻痹／`74` 封咒／`FF` 八阵图／
  `80` 加HP／`90` 加MP／`BF` 恢复状态／`A8` 增加移动／`A2` 敏捷／`A4` 士气／`A0` 能力／`A1` 防御／
  `B8` 再次行动／`C0` 天气／`AF` 霸气 …）。**策略伤害数组在策略上下文**（原版 `42313E` 的 `[EBP-8]`；
  6.6 对应 `0x497AF8`）。
- **原版特效号 ↔ 装备属性号（十进制）严格同值**：`35..38`=混乱/中毒/麻痹/禁咒攻击、`41`=致命一击攻击、
  `42`=远距离攻击、`43`=穿透、`44`=无反击攻击、`45`=骑马攻击、`46`=引导攻击、`57`=**防致命一击**、
  `58`=防二次攻击、`60`=MP辅助防御、`61`=减轻远距离损伤、`62`=自动使用道具(豆袋)。
  ⚠ 文档内联注释有一处**错标**：`push 0x28` 注成"无反攻击"，实为 **`0x28`=反击后反击**（`[492E04]>1` 时再判），
  **`0x2C` 才是无反击攻击**。⇒ 文档注释不可当结论，一律回代码看分支条件。

## 实现·使用方法

1. **用这份文档的正确姿势（三步）**：
   ① 先按"世代四条判据"给资料定代；② 在 6.6 用**同构 + 常量 xref** 找对应函数
   （工作台：`xref <常量>`、`fields <disp> <宽度>`、`db` 回读）；③ **参数极性与取值域必须现读**，不抄文字。
2. **6.6 的两种"取指针"习惯用法**（替代原版的到处 `IMUL 0x24 + 4B2C50`）：
   `call 0x4061F9`（`cl` = slot → ECX = `&unit[slot]`）、`call 0x40658F`（ECX = 单位 → ECX = 人物记录指针）。
3. **已装暴击预览补丁的取参：静态复核通过**（`0x457DB4` 蹦床 → `0x457DD0` 体：
   体 arg1=伤害、arg2=`[ebp-0x2C]`=攻方、arg3=`[ebp-0x28]`=目标；
   体内 `lea ecx,[ebp-0x20]`（结构 `{0, 目标slot}`）→ `call 0x40C7D8`）。

## 风险与边界

1. **特效号跨世代禁止互译**：原版 `0x24` = **中毒攻击**（`push 0x24` → 设中毒状态；装备属性 `36`），
   防致命一击 = `0x39`；而 6.6 的 `0x24` 经实机确认为 **防御暴击（免伤/减伤）**。
   两套编号各自成立，**不得互相解释**（涉及 `0x24` 的结论继续以库内实机页为准）。
2. 文档自身是**多来源合集**：道具/策略表基址混用了 `4A1140`（道具本质属性，条目 0x19）与
   `4AF4C0`（另一版的口径），涉及数据表时必须现读 6.6，不得按文档推算。
3. 文档给出的**地址一律视为"同构线索"**：本页已实测两处同址（`43DADA`/`4064F1`/`4927F0`）、
   多处偏移（`405E03→405DE1`、`43BC4B→43BC5A`、`4404BD→44049E`）⇒ **同一函数也可能改址**。
4. 文档内联注释存在错标（见上文 `0x28`/`0x2C`）⇒ 只把**代码分支**当证据。
