# 引擎可调用函数（普罗源码登记）

## 结论速览

普罗源码 `constants.h` 里登记了 9 个**引擎函数地址**，补丁里可直接 `call`。
比逐个反汇编推断函数签名可靠得多。

## 适用版本

- 曹操传 6.6 系 + `ExtendData.dll`；地址为**运行时绝对地址**。

## 已确认事实

| 宏 | 地址 | 用途 | 备注 |
|---|---|---|---|
| `ADDR_FN_SHOW_MESSAGE` | `0x42F699` | 显示消息 | |
| `ADDR_FN_CONSUME_ITEM` | `0x41C74D` | 消耗道具 | |
| `ADDR_FN_SHOW_PERSON` | `0x479728` | 显示武将情报 | `teji.cpp` 用它开情报框 |
| `ADDR_FN_CHANGE_DIR` | `0x457428` | 改朝向 | |
| `ADDR_FN_ITEM_TOOLTIP` | `0x40BE92` | 道具提示 | |
| **`ADDR_FN_EFFECT_TEXT`** | **`0x428372`** | **特效值 → 显示文本** | 签名 `(char* buf, DWORD value, DWORD kind)`；`__stdcall`（调用方 `sub esp,0xC`） |
| `ADDR_FN_AUTO_STRATEGY` | `0x4225FB` | 自动策略 | |
| `ADDR_FN_CHECK_TARGET` | `0x419D6D` | 检查目标 | |
| `ADDR_FN_CHECK_DEFEND` | `0x41BC16` | 检查防御 | |

### `ADDR_FN_EFFECT_TEXT` 用法（`teji.cpp` 实例）

```c
typedef void (*EffectTextFunction)(char *a, DWORD b, DWORD c);
EffectTextFunction f = (EffectTextFunction)0x428372;
char buf[40];
f(buf, (DWORD)person_effect[data_id][idx][1], nums_kind);   // nums_kind 来自名表 +0xF
__asm { sub esp, 0xC }                                      // 补栈
```

- `nums_kind` = 特技名表 `0x4CC600 + id*0x10 + 0xF` 处的 **1 字节**。
- ⇒ 它决定显示格式（如 `-%d` / `+%d%%` / `%s +%u`）。

## 实现·使用方法

补丁里若要显示特技相关文本（例如伤害预览追加"（防御暴击 -20%）"），
可以直接 `call 0x428372`，不必自己拼格式串。

## 风险与边界

- `__stdcall` vs `__cdecl` 要按实际补栈；源码里用 `__asm { sub esp, 0xC }` 说明
  它是 `__stdcall` 且有 3 个参数（12 字节）。
- 地址与 `Ekd5.exe` 版本绑定，换版本需重验。

## 证据来源

- `CCZ-ExtendData/ExtendData/constants.h`、`teji.cpp`。
