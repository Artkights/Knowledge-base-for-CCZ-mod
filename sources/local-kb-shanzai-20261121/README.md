## 5. 已知的坑（新会话最容易踩）

| 坑 | 事实 |

| 手写样本 SHA | 会被并发会话改写；**每轮现读** `_样本时间线.py` |

## 7. 维护规则

- Markdown 一律 **带 BOM 的 UTF-8**；`.cmd`/`.bat` 一律 **GBK**。
- **一个结论只在一个页面写全**：其它页只写本专题部分并**链接**过去
  （本库历史的"重复记录 + 互相矛盾"主要源于同一结论在多页各写一遍）。
- 每页页首必须有 `## 结论速览`（3~6 条可直接用的结论），正文放细节。
- 引擎类结论写**三件套：地址 + 字节 + SHA**。
- 新结论落盘后：更新 `00-总览与规范/更新记录.md`；未闭环项登记 `00-总览与规范/待验证清单.md`；
  推翻旧结论时在 `90-来源归档/复刻版6.6山贼错误知识纠正台账.md` 加一行。
- 体检：`python 大鲸鱼产生专用\_知识库体检.py`（BOM / 死链 / 重复标题 / 路由）。
