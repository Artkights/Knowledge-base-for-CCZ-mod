## 证据等级（仓库口径）

- `verified`：当前样本、工具源码、复读、烟测或实机已确认；
- `external`：可复核的外部文档/论坛资料，未完成当前版本验证；
- `unverified`：线索或推断，只能进待验证队列；
- `deprecated`：被新证据替代的旧结论。
