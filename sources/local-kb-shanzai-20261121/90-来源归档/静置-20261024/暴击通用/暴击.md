## 结论速览

- 适用与版本：本页三个「★当前生效」小节（v4 / v5 / v6）**都已过期** —— v5（洞 `0x452C00`）实测减伤入参 V 不可靠，v6 取到真实值后在 `0x43A6D4` 崩溃**已回滚**；引用当前样本必须跑 `_pyrun.cmd _样本时间线.py` 现读，不要引用本页任何 SHA。
- 挂钩点字节随版本变化（v4 `0x452AF1` / v5 `0x452C00` / v6 `0x452E68`）⇒ 引用"挂钩点 9 字节"时必须**同时给出 版本 + SHA + 字节**三件套。
- 暴击判定链（不受版本演进影响）：`410F1C` 内先 `410F2B call 423FE8(08)`（`unit[1E]` 暴击位），失败再 `410F53 call 426B33`（`41B500` 读 `unit[10]` HP>0 + `423FE8(08)` 位匹配），仍未通过才 `410F63 call 410F0A` 必定暴击桩（装备特效号 `29` / 个人特效号 `1A` → `60031A` EDX=`35C0` → 核心引擎 `4101D9` → 执行 `4223A9`）；返回值 `al=00` 无暴击 / `al=02` HP=0 / `al=FF` 暴击成功。
- `unit[1E]` 判定位：`04` = 攻击阻止（检测点 `43F93E`）、`08` = 暴击状态（`426B41`、`410F2B`）、`10` = 中毒（`423FA6`）。
- 倍率锚点（引擎双向核对，样本 SHA `135A22E7…`）：物理暴伤走 `0x42E4FD` = `1+((暴击率+100)>>1)/100`（`150% + 暴击率/2%`），策略暴伤走 `0x40CAB4` = `1+((暴击率+100)>>2)/100`（`125% + 暴击率/4%`），两者共用 `0x425AD9`（`a*b/100`，`ret 8`）；暴击率=100 时分别是 200% 与 150%。
- PE 偏移坑（本项目专属）：`Ekd5.exe` 的 `.code` 节 VA=`0x1000` / Raw=`0x400` ⇒ **文件偏移 = `0x400 + (VA − 0x401000)`**；写成 `0x400 + (VA − 0x400000)` 会落到别的函数（旧字节锁已拦下一次）。

## 详细记录

#### 概述

曹操传中的暴击（也称"必杀"）是一种在物理攻击时触发的高伤害特殊效果。当暴击触发时，攻击伤害会大幅提升。

暴击判定分为两层：
1. **基础暴击判定**：由 `426B33` 函数进行，基于攻击者状态和能力
2. **必定暴击特技**：当基础判定失败时，检查攻击者是否拥有"必定暴击"特技

#### 暴击位的设置/清除机制

##### unit[1E] 是一个衍生字段

`unit[1E]` 位于**战术单位结构体**中（`30H` 字节结构，基址 `4A7B20`），而非人物运行时记录或策略记录。旧文档把 `4A3E77/61H` 误称为角色单位；当前复核已确认那是策略记录表。该状态字段在攻击准备阶段会参与衍生计算，新增写入仍应优先使用已验证状态函数。

##### 两套单位结构体对比

| 属性 | 战术单位 (Tactical) | 人物运行时记录 (RuntimeCharacter) |
|------|-------------------|---------------------|
| 结构体大小 | `30H` (48 字节) | `48H` (72 字节) |
| 基址 | `4A7B20` | 动态基址指针 `[4CEA00]` |
| 指针公式 | `index × 30H + 4A7B20` | `Data号 × 48H + [4CEA00]` |
| 获取函数 | `4061F9` | `4061E4` / `40658F` |
| 内容 | 战场当前状态 | 人物能力、兵种、装备、等级等 |

##### 攻击者能力检查流程 43F8C0 详析

在物理攻击执行之前，43F8C0 会检查攻击者的各项状态：

```asm

43F8D7: mov eax, 500E9A
43F8DC: cmp [eax], 02          ; 检查攻击类型=物理攻击
43F8DF: jnz 43F8F5
43F8E1: cmp [eax+01], 00     ; 检查 500E9B != 0
43F8E5: jz 43F8F5
43F8E7: mov cl, [eax+01]       ; 攻击子类型
43F8EA: call 41E918            ; 查表: cl*10 + 4A7510
43F8EF: mov al, [ecx+0C]       ; 读取攻击类型的标志字节
43F8F2: mov [ebp-08], al       ; 暂存到局部变量

; Mod引擎状态检查序列:
43F8FB: call 4D3242(05,00,32)  ; 检查状态A
         → 如果返回非全0 → [ebp-07] = al
43F90C: call 4D25B6(00, attacker)   ; 检查状态B
         → 如果返回非0 → [ebp-06] = 00 (清除)
43F91E: call 4D25CB(00, attacker)   ; 检查状态C

43F939: push 04               ; ★ 检查 bit 04
43F93E: call 423FE8            ; unit[1E] 的 bit 04?
43F945: jz 43F94E             ; 如果未设置 → 攻击正常

##### 暴击位 (08) 的设置来源（推断）

| 来源 | 触发条件 | 清除条件 |
|------|----------|----------|
| 兵种特性 | 特定兵种天然暴击 | 无（永久） |
| 武器/宝物 | 装备暴击加成物品 | 卸下装备 |
| 攻击类型 | 特定攻击指令自带暴击 | 攻击结束 |
| Buff/法术 | "奋起"/"会心"类法术 | 回合结束/被解除 |

##### 静态分析瓶颈

当前纯静态分析无法确定 `unit[1E]` 的写入代码，原因：
1. 模组引擎函数（4DXXXX/4EXXXX）深度封装，调用链复杂
2. 状态位可能由 4E4000 内部的 4EE0C8 → 4EE09C/4EE060 子函数写入
3. 也可能在战斗初始化阶段（44AF8F 回合重置循环附近）预设

**建议**：在 x64dbg 中对战术单位的 `[unit_ptr + 1E]` 内存地址设置**硬件写入断点**，然后执行一次物理攻击，即可直接捕获写入点。

#### 与连击机制的关系

暴击和连击是独立的判定：
- 基础暴击：通过 unit[1E] 位匹配 + HP检查
- 必定暴击：通过特技桩→调度→核心引擎
- 连击：通过"爆发力"比对（见 连击.md）
- 两种效果可以同时触发，独立计算

00425ADC  8B 45 0C        mov  eax,[ebp+0xc]      ; 参数2 = 加成值
00425ADF  0F AF 45 08     imul eax,[ebp+8]        ; × 参数1（原伤害）
00425AE3  33 D2           xor  edx,edx
00425AE5  B9 64 00 00 00  mov  ecx,0x64           ; 100
00425AEA  F7 F1           div  ecx                ; ÷100（无符号）
00425AED  C2 08 00        ret  8
```

⇒ 语义 = `a * b / 100`。两条暴击链都靠它把"加成值"折成实际伤害。

### 一、攻击（物理）暴伤 —— `0x42E4FD`

```asm
0042E500  8B 4D 10        mov  ecx,[ebp+0x10]     ; ctx
0042E50C  6A 70           push 0x70               ; 特效 0x70「强化致命一击」
0042E50E  E8 C6 1C FE FF  call 0x4101d9           ; 查特效 → eax
0042E513  8B 4D 0C        mov  ecx,[ebp+0xc]      ; 标记 = 暴击率 + 100
0042E516  D1 F9           sar  ecx,1              ; ★ >>1
0042E51C  03 C8           add  ecx,eax            ; ★ 有特效0x70 则**加算**其效果值
0042E521  FF 32           push [edx]              ; 原伤害
0042E524  E8 B0 75 FF FF  call 0x425ad9
0042E52C  01 02           add  [edx],eax          ; 伤害槽 += 该值
```

⇒ **倍率 = `1 + ((暴击率+100)>>1)/100`**，即 `150% + 暴击率/2 %`（取整向下）。

### 二、策略暴伤 —— `0x40CAB4`

```asm
0040CAB4  83 45 F8 64     add  dword ptr [ebp-8],0x64   ; ★ 标记 = 暴击率 + 100
0040CAB8  8B 45 F8        mov  eax,[ebp-8]
0040CABB  C1 E8 02        shr  eax,2                    ; ★ >>2
0040CABE  FF 75 10        push [ebp+0x10]               ; 原伤害
0040CAC1  50              push eax                      ; 加成值
0040CAC2  E8 12 90 01 00  call 0x425ad9
0040CAC7  01 45 10        add  [ebp+0x10],eax           ; 伤害 += 该值
```

⇒ **倍率 = `1 + ((暴击率+100)>>2)/100`**，即 `125% + 暴击率/4 %`（取整向下）。

### 三、逐点核对

| 暴击率 | 攻击：引擎 / 公式 | 策略：引擎 / 公式 |
|---|---|---|
| 0 | `1+50/100`=150% / 150% ✅ | `1+25/100`=125% / 125% ✅ |
| 20 | 160% / 160% ✅ | 130% / 130% ✅ |
| 30 | 165% / 165% ✅ | — |
| 40 | 170% / 170% ✅ | 135% / 135% ✅ |
| 50 | 175% / 175% ✅ | — |
| 100 | 200% / 200% ✅ | 150% / 150% ✅ |

**偏差（唯一来源 = 整数右移取整）**
- 攻击：`>>1` ⇒ 暴击率为**奇数**时比公式低 **0.5%**（例 率=1：引擎 150%，公式 150.5%）。
- 策略：`>>2` ⇒ 暴击率**非 4 的倍数**时比公式低 **≤0.75%**（例 率=3：引擎 125%，公式 125.75%）。

### 四、另外两处细节

1. **物理用 `sar`（算术右移）、策略用 `shr`（逻辑右移）**；标记恒为正 ⇒ 实际无差别。
2. **特效 `0x70`（强化致命一击）在物理侧是「加算」**：`加成 = (标记>>1) + 效果值`；
   **策略侧那段没有这个加算**（`0x40CAB4` 段未出现 `call 0x4101d9` 查 `0x70`）⇒ 待单独确认。

### 五、与「预览」的关系（用户指出的盲点）

- **预览面板显示的是「未暴击」伤害** ⇒ 因为预览链**不调用**暴击加成函数（`0x42E4FD` / `0x40CAxx`）。
- 因此要显示「暴击后」的预览，必须**自己按上面倍率折算**：

```
暴击预览伤害 = 未暴击预览伤害 × 暴击倍率 × (100 − V)/100      # V = 目标 0x24 的值
    攻击倍率 = 1 + ((暴击率+100)>>1)/100
    策略倍率 = 1 + ((暴击率+100)>>2)/100
```

- 当**暴击率 = 100%** 时，攻击倍率为 **200%**、策略为 **150%** ⇒ 这两个锚点可用于实机核对。

## ★★ 2026-10-14 用户补充：集气模式开关 `0x505EC8`（整型 `4018`）

- **整型变量 `4018` = `0x505EC8`；`= 1` 启用「普罗集气模式」。**
- 集气模式下，角色每次攻击都会累计**闪气 / 暴气 / 连气**（显示在伤害预览面板），
  **满 100 时预览项显示红色 ⇒ 必定触发**；判定式为 `已有集气 + 本次理论率 ≥ 100`。
- ⇒ **99% 暴击率不会暴击**，必须累计到 100。**这与"单次概率掷骰"完全不同**，
  验证暴击相关补丁时**必须先把集气喂满**，否则会像我一样"干等 0 命中"。
- 累积值放在 `0x4930C8 + 单位索引*4`（`0x4287A8` 使用）。
- 两分支归属详见 `03-机制详解/暴击伤害公式与预览.md`。

### 2026-10-14 实证补充：集气判定核心 `0x42893F`

- `0x42893F` 段：`cmp byte [edx+ecx*4+0x4930c8], al`（集气 ≥ 本次值）
  ⇒ `jb` 不触发；否则 `neg eax`（触发并扣减）。
- `0x42882C` 段：`mov byte [ecx+0x4930c8], dl` **写集气值**；
  开关为 0 时 `call 0x43786b`（**原版随机路径**）。
- `0x4131F7` 段：**预览面板显示集气**（含 `cmp cl,0x64` 满 100 判定）。
- 集气数组 = `0x4930C8 + 单位索引*4`（索引取单位记录 `+4` 字段）。
- 完整代码见 `03-机制详解/暴击伤害公式与预览.md`「集气机制的代码实现」。
