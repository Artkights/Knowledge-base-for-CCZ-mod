## 三、设计草案（待用户确认后才生成补丁）

### 3.1 挂点
```
0x423327 : E8 91 1E 00 00   (call 0x4251BD)
        →  E9 <洞>            (5 字节同长度替换，不动指令边界 ✓)
```

### 3.2 洞内代码（衔接）
```asm
; 进入时：0x423324 已 push [ebp-8]，栈顶 = 列表指针
push dword [ebp-8]      ; 再压一份给 handler
call <handler>
add  esp, 4
call 0x4251BD            ; 原样调用（栈顶仍是 0x423324 压的那份）
jmp  0x42332C            ; 回到 mov esp,ebp
```

### 3.3 handler 逻辑（约 250~350 字节）
```
1) list = [ebp-8]
2) for i = 0; ; i++:
     slot = byte [list + 0xD + i]
     if slot == 0xFF: break
     rec = 0x4061F9(slot)                     ; 人物记录
     val = 查特技 0x6F 效果值(rec)             ; push 0/1/0x23/0x6F; call 0x4101D9
     if val == 0: continue
     ; ---- 转移量（修法A：绝不超过原伤害绝对值）----
     dmg  = [ctx + 0x108 + i*4]                ; ★ 负数
     mag  = -dmg  (取绝对值)
     xfer = mag * val / 100
     if xfer > mag: xfer = mag                 ; ★ 修法A
     [ctx + 0x108 + i*4] = dmg + xfer           ; 原目标少挨打（负数 + 正 = 绝对值变小）
     ; ---- 挑承接者：血最低（修法C：不 append 进列表）----
     best = -1; bestHP = 0x7FFFFFFF
     for s = 0..N:                              ; 遍历战场单位表 0x4A7B20 + s*0x30
         if 单位无效/死亡: continue
         if s == slot: continue
         hp = [0x4A7B20 + s*0x30 + 0x10] (u16)
         if hp < bestHP: bestHP = hp; best = s
     if best < 0: continue
     ; ---- 写承接者 ----
     t = [ctx + 0x108 + best*4]                  ; 负数
     t = t - xfer                                 ; 更负 ⇒ 多挨打
     if (-t) > bestHP: t = -bestHP               ; 钳到 ≤ 其血量
     [ctx + 0x108 + best*4] = t
```

### 3.4 三个必须改的点（相对 6.4）
1. **符号反了**：6.4 存正数（`sub` 原槽、`add` 承接槽）；**6.6 存负数**（`add` 原槽、`sub` 承接槽）⇒ 照抄 6.4 会变成"给敌人加血"
2. **没有 `0x4AC748` 候选表**：改遍历战场单位表 `0x4A7B20 + slot*0x30`（步长 `0x30`），用 `+0x10` 取 HP
3. **必须带修法 A（`xfer ≤ 原伤害`）与 C（不 append 列表）**，否则复现 6.4 那个"满血复活"

### 6.3 实现要点（与设计草案的差异）
1. **符号自适应**（新增）：运行时先读伤害槽符号
   - 槽 < 0（HP 增量语义）⇒ 原槽 `+= xfer`（减轻）、承接槽 `-= xfer`（加重）
   - 槽 > 0（伤害数值语义）⇒ 反过来
   ⇒ **两种引擎约定都正确**，避免静态歧义（`0x4232FD neg eax` 与飘字 `0x421C53 cmp eax,0` 互相矛盾）
2. 调 `0x42518F`（分流包装）而非直连 `0x4101D9`：它自己处理 `0x40B922` 分流，
   且**保存/恢复 ecx**；另加 `mov edx,ecx` 保证 `0x4101D9` 内部 `mov ecx,[edx]` 有有效指针
3. 修法A：`xfer = min(|dmg| × 效果值 / 100, |dmg|)`
4. 修法C：**不**把承接者追加进目标列表
5. 承接者：**同阵营**（比较 `+0x0F`）、**HP>0**（存活）、`Data号≠0`、**非自己**、
   **HP 百分比最低**（`hp × 1000 / hpmax`，`hpmax` 取 `人物记录 +0x1B`，为 0 时退回 hp）
6. 承接钳制：其结果绝对值不超过承接者当前 HP

## 三、权威字段口径（本轮更正，务必以此为准）
战场单位表：**`0x4A7B20 + slot × 0x30`**（`0x4061F9(cl=slot)` 返回该指针）

| 偏移 | 含义 | 宽度 |
|---|---|---|
| `+0x00` | 单位号（Data号；`0xFFFF`=空槽）| word（低 16 位）|
| **`+0x05`** | **阵营（我军 = 0）** | byte |
| **`+0x06` / `+0x07`** | **x / y 坐标** | byte |
| **`+0x10`** | **HP（当前）** | **dword** |
| `+0x1E` | 异常状态（中毒 = `&0xC0`）| byte |
| `+0x0F` | **不是阵营**（我误用过）| byte |

- HP 上限：**人物记录** = `0x4061E4(单位号)` → `[0x4CEA00] + 单位号 × 0x48`，**`+0x1B` = HP 上限（u16）**
- 证据：`大鲸鱼产生专用\_废弃实验\一次性脚本_20261021\_tmp对照测量.py`（`u()`/`set_hp()`/`hpmax()`）、`大鲸鱼产生专用\_废弃实验\一次性脚本_20261021\_tmp补满血.py`、`0x41B500`（`mov eax,[ecx+0x10]`）
