# 信息传送测试 7B 五类测试（6.6 → 6.5pl 移植）

## 结论速览

- 6.6 新增 5 条 `7b` 指令（7b-1..7b-5）；6.5pl 补丁把它们移植到 **`0x4E7400..0x4E7D02`**，统一入口 **`0x4E7500`**。
- 6.5 命令分派表基址 **`0x410A38`**（命令 N → 表 + `(N-2)*4`）：`0x7B` 条目在 **`0x410C1C`**，原值 `0x004D0000`（零区），现为 **`0x004E7500`**；命令上限字节 **`0x4109F8`** 由 `0x79` 改为 **`0x7B`**。
- `0x7A` 条目 **`0x410C18`** 指到 **`0x4E7600`**（`B8 05 00 00 00 C3` = `mov eax,5; ret`），使 0x7A 走“未知命令”返回值 5，与改前 `ja 0x410A2F` 路径一致；**没有安装 0x7A 对话3**。
- 7B 参数：**P1 = 测试类型（1..5，数值/类型 4）**，**P2 = 逗号分隔数字串（字符串/类型 5）**；不是旧 7B 的 4 个变量槽。
- 类型 1 = 道具/装备数量：`编号,n,0` 装备数量 ≥ n；`编号,n,1` 道具数量 ≥ n。**6.6 只有 2 个数字（仅道具），6.5pl 扩成 3 个**，第三个 0=装备、1=道具。
- 类型 2 = 武将入队（`DATA号,1/0`）；类型 3 = 地形（`0/1,编号,地形号`）；类型 4 = 天气（`0..4`）；类型 5 = 异常状态（`0/1,编号,状态,0/1`）。
- 已装样本 SHA `EA02CA0B…` → **`7310DE90B8CCFDDEBAAFCC802A63334420EB4944FD3E2ED5711C43DCC6BAB55A`**；备份 `edk5（4）…`（干净）与 `edk5（5）…`（7B + 0x7A 返回 5）。
- 同一补丁也已装到 **`[本地盘]\qq\qq群\Ekd5_原始的.exe`**：`1621D11E…` → `886FA14E…`；备份 `edk5（6）…`（前像/复读 12 段全一致）。
- **未实机验证**：需在剧本里放一条 7B 命令跑一次；本文所有结论来自静态反汇编 + 前像/复读。

## 已确认事实

### 1. 命令分派与入口（6.5 样本现读）

- `0x4109E6` 分派器：`call 0x40FCB2` 取命令字节 → `cmp eax,0x79; ja 0x410A2F`（`eax=5`）→ `sub eax,2; call [eax*4 + 0x410A38]`。
- 表项：`0x7A` @ `0x410C18`、`0x7B` @ `0x410C1C`；干净样本两者都是 `0x004D0000`（`0x4D0000` 起 0x100 字节全 0）。
- 本补丁写入：
  - `0x4109F8`：`7B`（原 `79`）
  - `0x410C18`：`00 76 4E` → `0x004E7600`（原 `00 00 4D`）
  - `0x410C1C`：`00 75 4E` → `0x004E7500`（原 `00 00 4D`）
  - `0x4E7600`：`B8 05 00 00 00 C3`（`mov eax,5; ret`）
- **`0x47E9F0` 一个字节都没改**（现读 `C3 90 90 90 90`）。
- 源补丁原写法：`0x410C1C → 0x0047E9F0`，再在 `0x47E9F0` 写 `E9 0B 8B 06 00`（jmp 0x4E7500）。但本样本 `0x47E9F0` 是**上一个函数的 `ret`**（前一函数以 `pop edi; pop esi; pop ebx; leave; ret` 收尾，ret 正好在 0x47E9F0），直接改会破坏该函数返回。故本实现改为**命令表直指 0x4E7500**，并把 0x7A 指到 `mov eax,5; ret` 占位。

### 2. 7B 代码本体

- `0x4E7500`（7B 入口，`ret` 收尾的 cdecl 单参数函数）：
  - `push 4; mov ecx,[ebp+8]; call 0x4183F7` → P1（测试类型，1..5）；
  - `push 5; ... call 0x4183F7` → P2（字符串指针）；
  - 按 P1 选择：1→`0x42FBB5`（→0x4E7400）、2→`0x42FAEE`（→0x4E7700）、3→`0x42FB17`（→0x4E7800）、4→`0x42FB62`（→0x4E7A00）、5→`0x4E7C00`；
  - `push P2; call edx; add esp,4`。
- 跳板（`.code` 的 NOP 区，干净样本全是 `90`）：`0x42FAEE`、`0x42FB17`、`0x42FB62`、`0x42FBB5`。
- 5 个测试函数均**自包含**；逐条收集 call 目标后，外部调用只到引擎：
  - 7b-1：`0x40D623`（装备栏表 0x4B0770）、`0x41A22B`（已装备扫描）、`0x4837C2`/`0x40B444`/`0x530000`（道具数量）
  - 7b-2：`0x42AC58`（DATA 是否入队）
  - 7b-3：`0x456079`/`0x4061F9`（DATA/战场编号→单位）、`0x435991`（地形）
  - 7b-4：`0x41553B(0x4B3D08)`（当前天气）
  - 7b-5：`0x423FE8`（状态位测试）
  - ⇒ **不依赖 0x72/0x7A 的洞区**。
- 7B 代码与源补丁在 `0x4E7400..0x4E756D`、`0x4E7700..0x4E78CF`、`0x4E7A00..0x4E7A51`、`0x4E7C00..0x4E7D02` **逐字节一致**（与全量补丁副本 `_tmp_65_patched.exe` 对比，差异 0）。

### 3. 五类测试的语义（与 6.6 发布文稿对照）

| 类型 | 6.6 名称 | 6.5pl 字符串 | 判定 |
|---|---|---|---|
| 1 | 道具数量 ≥ n | `编号,n,0/1` | 0=装备数量（仓库+已装备）、1=道具数量；`count >= n`（`setae`） |
| 2 | 武将是否入队 | `DATA号,1/0` | 1=在队 true，0=不在队 true |
| 3 | DATA/战场编号是否在指定地形 | `0/1,编号,地形号` | 0=DATA，1=战场编号 |
| 4 | 当前天气 | `0..4` | 与当前天气号比较 |
| 5 | 异常状态 | `0/1,编号,状态,0/1` | 状态 1麻 2禁 3混 4毒；第四位 0无 1有 |

- 6.6 发布文稿原文（`90-来源归档\桌面资料-引擎发布文稿5.6-6.6修-docx入库.md:5932-5959`）：7b-1 填 2 个数字（道具编号,n）；7b-2 填 2 个（DATA号,1/0）；7b-3 填 3 个（0/1,编号,地形）；7b-4 填 1 个（0..4）；7b-5 填 4 个（0/1,编号,状态,0/1）。
- 6.5pl 的 7b-1 是 **3 个数字**（多第三个 0/1），这是与 6.6 的**唯一参数差异**（用户口径 2026-10-20）。
- 6.6 原生对照：入口 `0x47E9F0`（函数头 `55 8B EC`），分派表 `0x47EA2F`；类型 1..5 的表项依次为 `0x42FBB5`（道具数量）/`0x42FAEE`（入队）/`0x42FB17`（地形）/`0x42FB62`（天气）/`0x42CC8E`（异常状态，跳 `0x4E7E20`）；表项 0 `0x42FB85` 未用。6.6 的 7b-1（`0x42FBB5`）只解析 **2 个数字**（`0x42C6C5`，count=2/stride=2），所以 6.6 版只有“道具数量”没有“装备数量”。

## 实现·使用方法

1. 剧本里写 7B 命令：**P1 填测试类型 1..5**；**P2 填字符串**（逗号分隔数字，不要空格、不要中文逗号）。
2. 示例：
   - 装备：`1` + `"10,2,0"` → 10 号装备数量 ≥ 2。
   - 道具：`1` + `"10,2,1"` → 10 号道具数量 ≥ 2。
   - 入队：`2` + `"5,1"` → DATA 5 号武将在队。
   - 地形：`3` + `"0,10,0"` → DATA 10 号武将在平原（地形 0）。
   - 天气：`4` + `"3"` → 当前天气 = 3。
   - 状态：`5` + `"1,5,2,1"` → 战场 5 号部队有禁咒。
3. 若编辑器仍按旧 7B 模板（4 个变量槽）写，类型/字符串对不上；必须用 6.6 的 7B 模板（数值 + 数字串）。
4. 回滚：把 `edk5（4）…` 写回目标 EXE（走 `_dsh写锁.safe_write_exe(..., exe_path=...)`），或重新应用干净备份。

## 风险与边界

- **未实机验证**：7B 命令尚未在游戏内跑过；首次使用请先存档，跑一条最简 `1 + "0,1,1"` 看返回值/跳转。
- 0x7A 只做“返回 5”的占位，**没有对话3功能**；如果剧本用 0x7A，会按未知命令返回 5（与改前一致），不会显示立绘。
- `0x47E9F0` 未改；**不要再用源补丁的 `-47E9F0 E9…` 写法**（会覆盖上一函数的 ret）。
- 道具数量读 `0x530000 + 编号`；装备数量 = `0x4B0770` 表（200 项 ×3B，ID 在 +0x13）+ 已装备扫描（`0x41A22B`）。若本 MOD 改过物品表/装备栏布局，需重新核对。
- 6.5pl 与 6.6 参数不同：6.6 的 7b-1 只有 `编号,n`；把 6.6 剧本直接拿到 6.5 会少第三个参数而解析失败。
- 只装了 7B；**0x72 增强、0x7A 对话3、0x4E0500 立绘洞、0x4E7000 的 72 辅助代码均未装**。
