# 异常状态：整体梳理（一页收敛 + 库内口径冲突裁决）

样本：`复刻版6.6山贼\Ekd5.exe`
核对时 SHA256：`2A555B0B0D476CE1B10510406586A6F148513EDCA740BAF67CCBC422F06F0083`（备份 372 / 补丁 67）
性质：**只读梳理**（本次会话对 `Ekd5.exe` 的写入已全部回滚，见末节）。
用法：任何涉及异常状态的问题**先看本页**，再按"详见"跳到专页；本页负责**裁决库内互相冲突的口径**。

## 结论速览

1. **状态字节 = `unit+0x1E`（1 字节）= 4 组 2-bit 窗口**，窗口值 1~3。
   **窗口序（引擎助手 `0x423FE8` 的权威口径）**：窗口0 `0x02`=麻痹 / 窗口1 `0x04`=禁咒 / 窗口2 `0x08`=混乱 / 窗口3 `0x10`=中毒；
   字节掩码 `0x03 / 0x0C / 0x30 / 0xC0`。`0xFF` = 正常（显示分支单独判等）。
2. **★ 库内最大冲突已裁决**：库里同时存在两套口径，**两套都"对"，但测的不是同一个量**：
   * **窗口口径**（`0x423FE8`，32 个调用点 + `0x478A10` 显示循环 + 活体实测）：`选择子 = 2<<i`，**测第 i 个 2-bit 窗口是否非零**；窗口值 = **剩余回合数**。
   * **单 bit 子掩码口径**（`0x4018=1` 集气以外的多处特技/补丁，如异常追袭用 `bit0=0x01/bit1=0x02/bit2=0x04/bit3=0x08`）：
     它测的是**同一个字节的第 i 位**，**不是第 i 个窗口**。
   ⇒ **两套掩码数值上互不通用**；**不要互相换算**，也不要用单 bit 表去反推回合数。
3. **每状态持续回合可独立设置** ⇒ 改 `0x4240CE` 起 4 字节（每状态 1 字节，取值 1~3）：
   原版 `02 04 20 C0` = 麻痹2 / 禁咒**1** / 混乱**2** / 中毒3；全 3 回合写 `03 0C 30 C0`。
   ⚠ **它是"初始值"不是"最终回合数"**：施加时设一次，之后每回合 `0x42402C` 递减（`>1` 减一；`==1` 走恢复判定）。
4. **恢复模式 = 整型变量 `4023` = `0x505EDC`**（`0x502000+4023*4`）：`0` 看脸（`0x43786B`）/ `1` 伪随机（`0x455E25`）/
   **`2` 直接清除 = 必恢复**。全 exe 只有 1 处引用 ⇒ 运行时可写、改字节无意义。
5. **怯力 = 禁咒同一窗口，5/6 号状态无效**：`0x423FE8` 只遍历 4 次、名表只有 4 个异常名、两张表各 4 字节。
   普罗编辑器新增的 5/6 号状态**没有对应内存位**。
6. **写入只有 3 条路径**，统一入口是 `0x45AA37`（单位数值统一设置器）：
   | 路径 | 形态 |
   |---|---|
   | `0x42119B → 0x4240D6` | 随机状态攻击：逐类掷骰后取选择子 → **置位**（OR `0x4240CE[i]`） |
   | `0x42402C`（每回合结算）→ `0x45AA37` | **清除**：`(unit[0], 6, 选择子\|0x80, 1, unit[4])`；`bit7` = 清除方向 ⇒ `0x423FB9` |
   | 直写点 `0x4083D3` / `0x4095A5` / `0x4512B7` | `mov byte [reg+0x1E], r8`（策略施加等，**不推荐**裸写） |
7. **`0x45AA37` 类别 6 = 异常状态**：值 `& 0x80` ⇒ `0x423FB9`（清除）/ 否则 ⇒ `0x4240D6`（置位）；
   类别 `0..5` = 六项能力档位（`unit+0x18..+0x1D`）、`7` = HP、`8` = MP；**类别 ≥ 9 掉进 NOP 区**。
8. **判据优先级（本会话事故后确立）**：**作者口径 > 现样本字节 > 发布贴/外部资料**。

## 二、★ 两套口径的裁决（本页核心价值）

### A. 窗口口径（引擎权威）

- 解码器 `0x423FE8`（`push 选择子` + `ECX=单位`，`ret 4`）：循环 i=0..3，`选择子 >>= 1`、`状态字节 >>= 2`、`and eax,3` ⇒ 判断**第 i 个窗口非零**，返回布尔。
- 显示循环 `0x478A10`：`测试位 = 1 << (i+1)` 传给 `0x4240E2`（同族），取名字 `0x486D06 + i*5`。
- **含义**：`0x02` = "**麻痹窗口非零**"（等价于"麻痹还剩 1~3 回合"），**不是**"bit1 = 麻痹"。

### B. 单 bit 子掩码口径（多个消费方在用）

- 例：库内**异常追袭**特技（`0xED`，已写入、惰性）的 256 字节权重表 `0x4D4200`：
  `bit0=0x01→麻痹(2)`、`bit1=0x02→禁咒(1)`、`bit2=0x04→混乱(2)`、`bit3=0x08→中毒(5)`，`bit4-7` 忽略；
  含中毒组合权重 6~10。
- 另例：`0x47FB32` 附近的随机状态族、`0x40DDAF` 的标志→名表行号映射（`0x02→0x32 / 0x04→0x33 / 0x08→0x30 / 0x10→0x31`）。

### C. 为什么"两套都对"，以及**不能混用**的原因

- 窗口值 `2` 的字节位模式是 `0x02` **和** `0x04` 同时为 1（2-bit `10` = bit0 的权值 2）。
  ⇒ 单 bit 表会把"麻痹 2 回合"读成"麻痹 **且** 禁咒"。
- 窗口值 `3` 的位模式是 `0x02|0x04|0x08` 同时为 1 ⇒ 会被读成"麻痹 + 禁咒 + 混乱 三种都有"。
- **实证后果（重要）**：异常追袭权重表把"中毒窗口=2"的字节（`0x80`）读成 0（因为 `0x80` 是 bit7，被忽略）
  ⇒ **中毒窗口 2 回合时完全不加成**；"中毒窗口=3"（`0xC0`）被读成 `0x08` 单 bit ⇒ 只在 `b & 0x01 or 0xB0` 之外命中毒权重。
  ⇒ 该补丁的"特效值 × **状态回合数**"**并没有真的按回合数**，而是按单 bit 组合的固定权重。
  **登记为待修正项（见第七节）**。
- **裁决**：
  1. 要**判断某个状态在不在**：用 `0x423FE8` + `2<<i`（窗口口径）——引擎视角，最可靠。
  2. 要**取回合数**：**不要**用任何单 bit 表；直接按窗口解码（第 1 节"取回合和"公式，或按窗口逐项读）。
  3. 要**自己写特技**：优先调 `0x423FE8`；若只想"这个字节非零"也可直接 `test`，但**别把 `0x02/0x04/0x08/0x10` 当状态位表**。
- 另注：`0x423FE8` **只返回布尔、不返回窗口值** ⇒ 引擎没有"取某状态剩余回合数"的现成助手（想要就得自己 `shr/and`）。

## 三、四张内嵌表 + 关键函数（现样本原始字节）

```
0x4240CA: FC F3 CF 3F   ; 取反掩码表（0x42402C 递减时 and 用它清窗口）
0x4240CE: 02 04 20 C0   ; ★ 施加初值表（每状态 1 字节，值 1~3）→ 麻痹2/禁咒1/混乱2/中毒3
0x4240D2: 03 0C 30 C0   ; 另一张 4 字节表（被 0x423FB9 与 0x4399C2 使用；语义见"风险"节）
0x4240D6: 55 8B EC ...  ; 施加函数（OR 初值表）
```

| 函数 | 签名 / ABI | 语义 |
|---|---|---|
| `0x423FE8` | `push 选择子` + `ECX=单位`，`ret 4` | 状态窗口测试（返回布尔） |
| `0x4240D6` | `ECX=单位` + `push 选择子位图`，`ret 4` | **置位写入**：selector 逐位，位=1 就 `or dl,[i+0x4240CE]`，最后 `or [unit+0x1E],dl` |
| `0x423FB9` | `ECX=单位` + `push 参数`，`ret 4` | **清除方向**：selector 逐位，位=**0** 才 `or dl,[i+0x4240D2]`，最后 `and [unit+0x1E],dl`（`参数=0x0F` ⇒ 全清） |
| `0x42402C` | `ECX=单位` + `push arg2`，`ret 8` | **每回合结算**：逐窗口，`arg2≥0x64` 强制清；`值==1` 走恢复判定；`值>1` 减一 |
| `0x478A10` | `push 状态字节` + 输出缓冲，`ret 8` | 状态字节 → 状态名字串（`0xFF`→「正常」） |
| `0x45AA37` | 5 参（见速览 6） | **单位数值统一设置器**（能力档位/异常状态/HP/MP） |
| `0x425AD9` | `(a,b)`，`ret 8` | `a*b/100` |

## 风险与边界

- **两套口径不可混**（第二节）：混用会把"麻痹2回合"读成"麻痹+禁咒"。
- `0x423FB9`（清除方向）用 `0x4240D2 = 03 0C 30 C0` 做 `and` 的掩码，**语义仍未完全吃透**：
  按指令读，`and` 的掩码应含"要保留的位"，而 `03 0C 30 C0` 是"窗口满值"，两者不自洽
  ⇒ 登记为待验证项（P1），**在它上面做补丁前必须先做对照实验**。
- `0x4240D6` 的**选择子位序疑点**：`0x42119B` 的表3 = `04 10 02 08`（bit1..bit4），而 `0x4240D6` 只扫 bit0..bit3 且不预移位
  ⇒ 若直接传，会**错位一类并越界丢一类**。仍未实机确认（P1）。
- **裸写 `unit+0x1E` 有四处直写点**（`0x4083D3`/`0x4095A5`/`0x4512B7` 等）——优先走 `0x45AA37`，别自己 `mov`。
- 「武将情报显示剩余回合数」（发布贴第 2 条）在本样本**仍未定位到实现**（`0x478A10` 只拼名字，不含数字）。
- **写 `Ekd5.exe` 只能走** `大鲸鱼产生专用\_dsh写锁.py` 的 `safe_write_exe()`（AGENTS.md §3.5）。
