# 异常状态：五项效果调整（麻痹/中毒/禁咒/混乱/怯力）与现行样本对照

样本：`复刻版6.6山贼\Ekd5.exe`
核对时 SHA256：`2A555B0B0D476CE1B10510406586A6F148513EDCA740BAF67CCBC422F06F0083`（备份 370 / 补丁 65）
用途：**"4/5 种异常状态调整"这项功能的唯一权威页**。以后调这项、或有人贴 6.4 修正版发布贴的代码，
先看本页对照表——**发布贴里的地址在本样本有一半对不上**（见第 3 节，已逐条字节复核）。

## 结论速览

1. **状态字节**：`unit+0x1E` = **4 组 2-bit 窗口**，窗口内数字 = **该状态剩余回合数**（1~3）。
   窗口序：**窗口0 麻痹 `0x03` / 窗口1 禁咒(封锁) `0x0C` / 窗口2 混乱 `0x30` / 窗口3 中毒 `0xC0`**。
   代码里的查询选择子是 **`02/04/08/10`**（`2<<i`），**不是** `03/0C/30/C0`。
2. **"不良状态持续 1-3 回合"不是读某张 4 字节表，而是"施加时的初值"**：
   施加走 `0x42119B → 0x4240D6`，`0x4240D6` 用**掩码表 `0x4240CE` = `02 04 20 C0`** 把窗口 OR 成 `2/1/2/3`
   （麻痹2 / 禁咒1 / 混乱2 / 中毒3）。随后每回合由 `0x42402C` 逐组 `>1 → 减一`，`==1 → 判定清除`。
   ⇒ **要改"持续几回合"就改 `0x4240CE` 这 4 字节**：
   `03 0C 30 C0` = 全部 3 回合；`10 20 40 80` = 全部 2 回合；`01 04 10 40` = 全部 1 回合。
   ⚠ 掩码表原值 `02 04 20 C0` 与 `0x4240D2` 的 `03 0C 30 C0` **只差 1**（`02→03`/`20→30`），极易混；见第 2 节。
3. **恢复模式**：由 `0x505EDC` 控制，取值 **`0` / `1` / `2`** 三条路（`0x424078`–`0x4240A1`）：
   `0` = 原版看脸（`call 0x43786B`）／`1` = 伪随机阈值（`call 0x455E25`，基准 `0x501BF5`）／
   `2` = 走第三支（既不随机也不阈值 ⇒ 直接清除）＝必恢复。
   **`0x505EDC` = 剧本整型变量 `4023`**（整型基址 `0x502000 + 4023×4` ✓ 验算一致）。
   ⇒ 这是"**保留**发布贴第 3 条、但地址/运行方式要按本样本理解"的一项。
4. **现样本状态（已逐字节复核）**：
   | 分项 | 现状 |
   |---|---|
   | 麻痹→被物理必中 | ✅ **已改** `0x43B645 = 6A 02` |
   | 麻痹→被策略必中 | ❌ **仍原版** `0x43B7AB = 6A 08`（= 混乱，不是麻痹 `02`） |
   | "混乱增加仇恨"→麻痹 | ❌ **仍原版** `0x438A6F = 6A 08` |
   | AI 策略麻痹优先度 +0x1B | ❌ **未打**（`0x439955` 现为 `83 45 FC 00`） |
   | 中毒 20%（失血） | ⚠ **数值不符**：实际 `0x44E007 = 6A 0F`（**15%**），不是 `0x14`(20%) |
   | 中毒后回血减半 | ✅ **已改** `0x423FAF = D1 6D 08` |
   | 怯力（失去物理攻击范围） | ❌ **未独立**：`0x43F939 = 6A 04`（该处查的是**禁咒窗口**） |
   | 武将情报显示剩余回合数 | ❓ 未在本样本定位到"显示数字"实现，见待验证项 |
5. **怯力在 6.5/6.6 未独立**（用户原话：「6.5 的怯力状态并未独立出来，是和禁咒放在一起，因此 5 号 6 号状态无效」）
   ⇒ 普罗编辑器里新增的 **5 号 / 6 号状态在本样本无效**，不要把 5/6 号当成可用槽位。
6. ⚠ **发布贴的 `+0x1E` 位掩码表是错的**：帖子里 `麻痹0x02/禁咒0x04/混乱0x08/中毒0x10` 是**查询选择子**；
   真实的**窗口掩码**是 `03/0C/30/C0`（`0x423FE8` 以"选择子右移 1 位、窗口右移 2 位"逐组比较）。

## 已确认事实

### 1. 状态字节 `unit+0x1E`（4 组 2-bit 窗口）

| 窗口 | 掩码（字节） | 查询选择子 | 名称 | 窗口值语义 |
|---|---|---|---|---|
| 0（位0-1） | `0x03` | `0x02` | **麻痹** | 剩余回合 1~3 |
| 1（位2-3） | `0x0C` | `0x04` | **禁咒**（显示名"封锁"） | 同上 |
| 2（位4-5） | `0x30` | `0x08` | **混乱** | 同上 |
| 3（位6-7） | `0xC0` | `0x10` | **中毒** | 同上 |

- 状态测试助手 `0x423FE8`（`push 选择子` + `ECX=单位`，`ret 4`）：选择子每轮**右移 1**、状态字节每轮**右移 2**，
  `and eax,3` 判该窗口非零 ⇒ `0x01` **永不命中**。
- 名称表 `0x486CFC`（stride 5）：`无 / 正常 / 麻痹 / 封锁 / 混乱 / 中毒 / 行动完毕`。
- 取回合和：`(b&3) + ((b>>2)&3) + ((b>>4)&3) + ((b>>6)&3)`。

### 2. 三张内嵌表 + 两个函数（本样本原始字节，已 `db` 回读）

```
0x4240CA: FC F3 CF 3F   ; 取反掩码表（清窗口用，~03 / ~0C / ~30 / ~C0）
0x4240CE: 02 04 20 C0   ; ★ 施加掩码表（按 selector 的 bit0..bit3 索引）→ 初值 麻痹2/禁咒1/混乱2/中毒3
0x4240D2: 03 0C 30 C0   ; 窗口掩码表（被 0x423FB9 与 0x4399C2 使用）
0x4240D6: 55 8B EC ...  ; 施加函数（OR 掩码），未被本项补丁改动
```

- **`0x4240D6(ECX=unit, push selector)`**：`selector >>= 1` 逐位，位为 1 就 `or dl,[0x4240CE + i]`，
  最后 `or [unit+0x1E], dl`。⚠ 它**不预移位**（只扫 bit0..bit3）⇒ `0x42119B` 的表3 `04 10 02 08`
  传进来会**错位一类且越界丢一类**（旧登记的 P2 疑点，仍待实机）。
- **`0x42402C(ECX=unit, arg2)` = 每回合结算**：
  `i=0..3` → 选择子 `= 2<<i` → `0x423FE8` 取窗口值 AL：
  * `arg2 ≥ 0x64` ⇒ 直接强制清除；
  * `AL == 1` ⇒ 走恢复判定（`0x424078`，按下述 `0x505EDC` 三支）；
  * `AL > 1` ⇒ `AL-1` 写回（`and` 取反掩码 / `or` 新值）；
  * 清除动作 = `push(选择子|0x80), 6, unit[0], 1, unit[4]` → `call 0x45AA37`（通用派发器）。
- **`0x423FB9(ECX=unit, arg)` = 按"置 0 位"清窗口**：`arg=0x0F` ⇒ 4 个窗口全清（因为 4 位全 1 ⇒ 一个掩码都不 OR）。
  调用者 `0x44E00C`（`push 1 / push 0x0F`），见第 4 节中毒。

**中毒结算链（本样本实测路径）**：
```
0x44EE88  call 0x44DFC7            ; 触发（每回合？待验证）
0x44DFC7: 遍历单位 → 0x418C90 返回类型，==2 时
          0x44DFFA push 0x10 → call 0x423FE8   ; 查中毒窗口
          0x44E005 push 1 / push 0x0F → call 0x44E024   ; 清 4 个状态窗口 + 结算
0x44E024(ECX=unit, arg=0x0F, flag=1):
          call 0x40658F ; call 0x407263 → EAX=HP上限
          push HP上限 / push arg(0x0F) → call 0x425AD9  ; = 0x0F*HPMax/100 = 15%HPMax
          if 0: eax=1
          call 0x41B500 ; 与 [ebp-8] 比较后扣血
```
⚠ 6.4 的"中毒=失血 20% + 策略/地形回血 -50%"在本样本对应：
**失血 15%（`0x44E007`）+ 回血减半（`0x423FAF`，已打）**——**两者都已在引擎里，只是百分比是 15 不是 20**。

### 4. 恢复模式 `0x505EDC`（= 剧本整型变量 `4023`）

```asm
00424078  A0 DC 5E 50 00   mov al,[0x505EDC]
0042407D  3C 00            cmp al,0
0042407F  75 0B            jne 0x42408C
00424081  50               push eax
00424082  FF 75 0C         push [ebp+0xC]
00424085  E8 E1 37 01 00   call 0x43786B      ; 支0 = 原版"看脸"
0042408C  3C 01            cmp al,1
0042408E  75 11            jne 0x4240A1
00424090  B9 F5 1B 50 00   mov ecx,0x501BF5
00424095  E8 8B 1D 03 00   call 0x455E25      ; 支1 = 伪随机（与阈值比较）
0042409A  39 45 0C         cmp [ebp+0xC],eax
0042409D  73 02            jae 0x4240A1
0042409F  33 C0            xor eax,eax        ; 判定失败 → 保留
004240A1  85 C0            test eax,eax
004240A3  74 17            je 0x4240BC        ; 不清除
```
- 地址换算：`0x502000 + 4023×4` = `0x502000 + 0x3EDC` = **`0x505EDC`** ✓
- 全 exe 只有 **1 处**引用（`0x424079`）⇒ **静态镜像里没有写入者**，值由运行时（剧本/存档/编辑器）设定。
- 取值语义（3 支）：`0` 看脸 ／ `1` 伪随机 ／ **`2` 落在"两支都不进"** ⇒ 直接清除 = **必恢复**。
- ⚠ 旧页曾把 `0x505EDC` 记为"双路径开关"（只识别 0/1）——**本页更正为三支**。

### 5. 怯力（5/6 号状态）为何无效

- 普罗编辑器给出 6 个状态槽（`debuff[6]`：麻痹/封咒/混乱/中毒/5号/6号），但引擎里：
  * `0x423FE8` 只遍历 **4 个窗口**；
  * 状态名表 `0x486CFC` 只有 4 个异常名；
  * `0x4240CE` / `0x4240D2` 都只有 **4 字节**。
- ⇒ **没有第 5/6 个状态的内存位**。发布贴把"怯力"实现为**复用窗口1（禁咒）**的行为（`0x43F939 push 4`），
  因此"怯力"与"禁咒"在本样本**同生共死**，不能各自设置持续时间/效果。
- 若要真正独立出怯力，必须新增位（超出 1 字节窗口 ⇒ 需扩字段或用别的字节），属**改造级**工作，先别做。

## 实现·使用方法

### 改"持续回合数"（推荐做法）

| 想要 | 写 `0x4240CE`（4 字节） |
|---|---|
| 全部 3 回合（发布贴口径） | `03 0C 30 C0` |
| 麻痹3 / 禁咒1 / 混乱2 / 中毒3（**原版**） | `02 04 20 C0`（= 现字节，**未打**） |
| 全部 2 回合 | `10 20 40 80` |
| 全部 1 回合 | `01 04 10 40` |

⚠ 字节值 = **窗口掩码 × 回合数**：1 回合 = `01/04/10/40`；2 回合 = `02/08/20/80`；3 回合 = `03/0C/30/C0`。
（因为窗口是 2 bit，OR 进去的是"数值本身"。）

### 改"恢复模式"

- 运行时改整型变量 **`4023`**（地址 `0x505EDC`）即可，**不用改 exe**：`0` 看脸 / `1` 伪随机 / `2` 必恢复。
- 注意它**只影响"窗口值 == 1"那一步**（`0x424078`）；`arg2 ≥ 0x64` 的强制清除不受它控制。

### 改"麻痹/中毒/禁咒/混乱"的具体效果

| 效果 | 落点 | 期望字节 |
|---|---|---|
| 麻痹 → 被物理必中 | `0x43B645` | `6A 02`（✅ 已打） |
| 麻痹 → 被策略必中 | `0x43B7AB` | `6A 02`（现 `6A 08`） |
| 麻痹 → AI 仇恨/优先度 | `0x438A6F`（仇恨）、`0x439955`（策略优先度 `+0x1B`） | `6A 02` / `C6 45 FC 1B` 或 `83 45 FC 1B` |
| 中毒 → 每回合失血 % | `0x44E007` | `6A 14`=20%（现 `6A 0F`=15%） |
| 中毒 → 回血减半 | `0x423FAF` | `D1 6D 08`（✅ 已打） |
| 禁咒/怯力 → 无物理攻击范围 | `0x43F939` | `6A 04`（现字节；窗口1=禁咒窗口，改号前先想清楚共用关系） |

**改号注意**：`0x423FE8` 的选择子是 `02/04/08/10`（`2<<i`）。所以"麻痹=2、禁咒=4、混乱=8、中毒=16"。
发布贴写 `PUSH 4` 时它落在**禁咒**窗口，不是新状态。

## 风险与边界

- **不要**把 `0x4240CE`(施加初值) 与 `0x4240D2`(窗口掩码) 混用：两者只差 1 字节，用途完全不同。
- `0x4240D6` 的"选择子位序不匹配"疑点（第 2 节末）仍**未实机确认**；在它上面做补丁前先做对照实验。
- `0x43B7AB` / `0x438A6F` 两处把"混乱"改成"麻痹"前，必须确认对应逻辑**不是混乱专属**（否则混乱被削两次、麻痹被叠两次）。
- 怯力与禁咒共用窗口 ⇒ **不能分别设置持续时间**；想分别设置必须先扩位（改造级）。
- `0x44E007` 的 `6A 0F` 是**当前生效值**；发布贴说 20% (`0x14`)，用户若要 20% 需显式改字节。
- `4023` 是**运行时变量**：改 `Ekd5.exe` 字节不影响它；它由剧本/编辑器写。
- 任何写入 `Ekd5.exe` 都必须走 `大鲸鱼产生专用\_dsh写锁.py` 的 `safe_write_exe()`（AGENTS.md §3.5）。

## 2026-10-16 11:30 ★ 更正：`0x4240CE` 是「每状态独立初值表」，可自定义每个状态的回合数

```asm

004240D9  6A 00 51            push 0 / push ecx        ; [ebp-4]=0(i)、[ebp-8]=unit
004240DC  33 D2               xor edx,edx              ; dl = 累计掩码
004240DE  8B 4D FC            mov ecx,[ebp-4]
004240E1  83 F9 04            cmp ecx,4 / jae 出口
004240E4  D1 6D 08            shr dword [ebp+8],1      ; selector 右移 1
```

### ⚠ 更正说明（本页早前「附录」里的两处错误，以本节为准）

### 仍然成立、需要注意的一点（不是"坏"，是"性质"）

**它是"初始值"，不是"最终回合数"**：窗口值只在施加时设一次，之后由每回合结算 `0x42402C` 递减
（`>1` → 减一；`==1` → 走恢复判定：`4023`=0 看脸 / 1 伪随机 / 2 必恢复）。
⇒ 设 3 = **最少 3 个回合**，之后还需通过判定才解除。
