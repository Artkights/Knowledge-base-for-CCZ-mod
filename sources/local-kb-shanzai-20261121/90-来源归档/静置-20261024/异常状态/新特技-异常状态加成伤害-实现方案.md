# 新特技：异常状态加成（特效值 × 回合数，无视防御/精神）—— 实现方案

需求（用户 2026-10-13 口述）：
**攻击（含策略）命中处于异常状态的敌人时，按其状态剩余回合数，附加「特效值 × 回合数」的无视防御/精神的伤害。**

用户已定：
- 回合数取法：**C 方案** = 先按「全局设定的异常持续回合」出效果，之后再升级为「补丁自维护的每单位倒计时」。
- 作用状态：**四个都要**（中毒 / 禁咒 / 混乱 / 麻痹），且**可组合** → 本方案按「命中几种就把它们的持续回合**相加**」实现（改成一取最大只是几字节的事）。
- 特效号：由我挑一个「引擎会查询且当前空闲」的号（待定，见下）。

## 一、为什么「无视防御/精神」很好实现

因为加成是**不吃任何减免**的纯加值，所以**不必解析伤害公式**，只要在「伤害已算完、即将落地」的位置把加值叠上去即可 —— 天然无视防御（物理）与精神（策略）。

## 三、实现（代码洞 + 挂点）

### 挂点选择
挂 **`0x4363B0` 入口**（5 字节远跳）而不是改 mod 的 `.api` 代码：它是 vendor 函数、只有一个调用者、签名清晰（伤害 + 目标都在栈上），且**物理与策略共用**（KB 的 Stage 4 同点）。⚠️ 动手前要确认它**每次伤害只被调用一次**（否则会重复叠加）——若发现每段伤害调用多次，改挂 `0x4338A2` 之后。

### 洞内逻辑（伪码）
```
保存所有寄存器与标志（pushad/pushfd）
伤害 = [ebp+8]，目标 = [ebp+0xC]
状态位 = byte [目标 + 0x1E]
回合和 = 0
for (i, (mask, shift)) in [(0xC0,6) 中毒, (0x0C,2) 禁咒, (0x30,4) 混乱, (0x03,0) 麻痹]:
    if (状态位 & mask):
        回合和 += (全局持续回合字节 >> shift) & 3      ; ← 坐标待定（见下）
if 回合和 == 0: goto 返回
攻击者 = dword [0x4B4250] + 0x0C 处的战术单位指针
特效值 = 0x42518F(单位=攻击者, 个人号=新号, 装备号=新号, 叠加=1, 模式=0)
if 特效值 == 0: goto 返回
伤害 += 特效值 * 回合和                            ; ← 无视防御/精神，直接加
[ebp+8] = 伤害
恢复寄存器与标志
执行被覆盖的原 5 字节
jmp 回 0x4363B5
```

### 还差的两三个坐标（下一步，已做一轮尝试）
1. **全局「异常持续回合」字节地址**：

## 四、风险与回滚

- 挂点是 vendor 函数入口：**必须完整复现被覆盖的 5 字节**，并用 `pushad/pushfd` 保护上下文，否则会破坏伤害链路。
- `0x4363B0` 若在一次伤害中被多次调用 → 加成会重复，需要改为挂在 `0x4338A2` 之前的单次位置。
- 回滚：恢复 `0x4363B0` 原 5 字节 + 洞区归零；按既有纪律出补丁 txt（无 BOM + CRLF）+ 备份 + 写后复读 + `_归档检查.py`。
