## 实现·使用方法：三条路线（按风险从低到高）

### 路线 A：**单掩码版（= 现有 A1，一字换状态）** ✅ 最省事
只改一个参数字节即可换目标状态：
```bat
:: 例：改成"封锁"或"混乱"，只需把 -00457EEC 的值从 10 改掉
:: 百分比从 14(20%) 改成 0A(10%) 等，同理
python 大鲸鱼产生专用\_生成-中毒物理易伤-A1.py --go
```
* **优点**：代码已全部验证（静态）、洞内零栈足迹、登记在册。
* **局限**：**一次只能一种状态、一个百分比**；改状态要重出补丁。
* **⚠ 必须先定**：这个"掩码值"按哪个口径（见风险 1）。

### 路线 B：**表驱动版（一次覆盖 4 种状态 + 组合，各自不同百分比）** ★ 推荐
把"掩码 + 单百分比"换成**一张以状态字节为索引的表**：
```
取 status = byte [目标+0x1E]
status &= 掩码（可选，把不关心的位屏蔽掉）
pct    = byte [表 + status]        ; 表 256 B（或只取低 4 位 ⇒ 16 B）
若 pct != 0:  伤害 += 伤害 × pct / 100     ; 用 0x425AD9
```
* **成本**：代码 ≈ 30 B（洞里 120 B 可用，绰绰有余）；表 16 B 或 256 B。
* **优点**：① **一次落盘覆盖全部状态与组合**；② 每种状态/组合**各给各的百分比**；
  ③ **天然规避"口径歧义"** —— 表按**整字节**索引，**中毒到底是 `0x10` 还是 `0x08` 由表填哪个格子决定**，
  交付时把两种口径的格子都填上（毒 = 两者都算），**不用先赌对编码**。
* **验证**：表内容可随补丁文本一起出，改表 = 改 1 个字节段，不需重编译代码。

### 路线 C：**全局百分比插槽 `0x500C48`（不新增 hook）** ⚠ 不建议
* KB 已排除：该槽的读点 `0x43BE3A` **只在"攻击者带 `0x19` 冲锋攻击"时才走到**（`0x43BDBF` 的 `0x4E6000` 另有
  "评估值==100"门控）⇒ **不是通用通道**，用它做"中毒易伤"会**大部分情况不生效**。

## 风险与边界

1. **★ 状态位口径未定（P0，最高优先）**：库里两套口径并存且**明确不可换算** ——
   * "2-bit 窗口"（`0x423FE8` 消费）：中毒疑似 = **窗口 4**（status bits 6-7，`arg = 0x10`）
   * "单 bit 子掩码"（异常追袭等消费）：中毒 = **`0x08`**
   ⇒ **A1 现在的 `0x10` 在哪种口径下才是中毒，必须实机读一次**：
   让一个单位中毒，读 `byte [unit+0x1E]`，看它是 `0x10` / `0xC0` / `0x08` / `0x40`。
   **在读到之前，不要断言"A1 打上就会对中毒生效"。**
2. **`0x4363B0` 每次伤害被调几次（P0）**：若 >1 次，A1/路线 B 都会**重复叠加**。
   KB 给的替代挂点是 **`0x4338A2` 之后**，或加"本次攻击已加成"标志。
   **实机做法**：x32dbg 在 `0x4363B0` 设断点 → 打**一次**普攻 → 数 `hit_count`（§6 允许，用完立刻删断点）。
3. **`0x4363B0` 是**共用挂点**：`【6.6山贼】新特技-异常追袭`（个人特技 `0xED`）曾挂同一处（8 B）。
   该补丁**已退役**（现读是干净 5 字节）⇒ 两者**互斥**，同时要就得合并成一份注入。
4. **伤害落地可能覆盖加成**：`0x4200A2` 入口即 `jmp 0x43D458`；
   若落地路径里有"伤害=0/被免疫"的早退，加成会被丢弃 ⇒ **契约里要写"被免疫时不加成"是预期行为**。
5. **数学溢出**：A1 用 `伤害 += 伤害 × pct / 100`（`imul` 32 位）。
   `伤害 ≥ 2^31/255 ≈ 8,421,504` 时**溢出**（现实中达不到，但若做"百分比 500%"这类极端表必须处理）。
6. **预览路径**：A1 挂点是"物理与策略共用"的修正函数（KB 原话）⇒
   **改它会同时影响"预览显示"和"实战结算"**（§8 要求：这类改动必须记录）。
   本轮未实测预览是否同步变化 ⇒ **列入验收项**。

### 二、最终设计（只做中毒，单参数版）
