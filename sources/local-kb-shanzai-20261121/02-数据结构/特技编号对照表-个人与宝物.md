# 特技编号对照表（个人特技号 ⇄ 宝物特效号）

> 样本：`Ekd5.exe` SHA `F3455B30…`；全部**现读**（`_编号对照表.py`）
> 完整表：**`大鲸鱼产生专用\_特技编号对照表.md`（373 行 / 95 对配对 / 两表全表）**
> 起因：逐族反汇编发现 `0xFE ☆神圣庇佑☆` 的域查 `0xCC`，库内又记 `0x45D513` 查个人 `0xFE`/装备 `0x59`
> ⇒ 必须先把"编号体系"理清（**做任何特技补丁的前提**）

## 结论速览

1. **本样本有【两张】255 行的 16 字节名表，行号 = 号，且【同号不同义】**：
   | 表 | VA | 文件偏移 | 非空条目 |
   |---|---|---|---:|
   | **个人特技表** | `0x4CC600` | `0x9E800` | 249 |
   | **宝物特效表** | `0x4CB800` | `0x9DA00` | 254 |
   ⇒ **引用任何"号"时必须写清属于哪张表**（库里早有一页 `_特技名表-两表对照.md` 讲这件事）。
2. **★ 系统性规律（本次确立）**：**个人 `0x00~0x1E` ⇄ 宝物 `0xE0~0xFE`，偏移正好 `+0xE0`**
   （名字与 flag 逐条一致）⇒ **做"特技号替换"类补丁时，个人号与宝物号要一起改，且相差 `0xE0`**。
3. **★ 宝物表【低区 `0x00~0x2F` 是另一套老编号】**，其中若干效果与高区**重复**：
   `反击风暴`（低 `0x10` / 高 `0x10`？见下表）、`策略模仿`（低 `0x1B`）、`主动连击`（低 `0x22`）…
   ⇒ **查一个效果可能有两个宝物号，必须实机确认哪个在用。**
4. **空效果号**：宝物 `0xDE`=`FE空效果`、`0xDF`=`FF空效果`；个人 `0xFF` 亦为空。
5. **配对表共 95 对**（按"名字相同/去标点后相同"配对）⇒ 明细见工具产物。

## 实现·使用方法

```bat
python 大鲸鱼产生专用\_编号对照表.py      :: 重新生成 `_特技编号对照表.md`（373 行：配对表 + 两表全表）
```

**做特技补丁时的检查清单**：
1. 先确定你改的是**个人特技表**还是**宝物特效表**的号；
2. 若目标是"某个效果"，**先在下表两处都查**（`+0xE0` 段 与 低区 `0x00~0x2F`），确认引擎实际用哪个；
3. 若要"整体替换某个效果"，**个人号与宝物号（差 `0xE0`）要一起改**，否则"装到装备上"和"带在个人身上"行为不一致；
4. 域反汇编里 `call 0x4101D9(a,b,1,0)` 的 **`a` 是"主号"、`b` 是"备选号"**（例 `0x41A8B8` 查 `(0xCC, 0x38)`）
   ⇒ **`a`/`b` 分别对应个人/装备，顺序不固定，必须看域的实现**。

## 风险与边界

* `+0xE0` 规律**只在 `0x00~0x1E` 段验证过**（逐条名字+flag 一致）；更高段是否仍成立**未验证**。
* 宝物表低区与高区**存在同名条目**（如 `引导攻击`）⇒ **不能假设"一个效果只有一个号"**。
* 本页只解决"编号"，**不解决"哪个号真被引擎使用"** ⇒ 仍需实机（断点 `0x4101D9` 读参数）。
