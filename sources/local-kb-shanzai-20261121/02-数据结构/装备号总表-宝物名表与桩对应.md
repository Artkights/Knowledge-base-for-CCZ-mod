# 装备号总表 —— 宝物名表（0x4CB600 = UE 0x9D800）与全部特技桩对应

## 结论速览

- **宝物/装备名表基址**：**文件偏移 `0x9D800` = VA `0x4CB600`**（每行 16B：名字 12B GBK + 3B 0 + flag 1B）。
  ⚠ **不是 `0x4CB800`**：旧口径按 VA 0x4CB800 读会落到文件 `0x9DA00`，**偏 +0x200 = +32 行**
  （所以 0x71 曾被读成"月华流转"；实为 **冠绝于世**）。
- **兵种/个人名表**：文件 `0x9E800` = VA **`0x4CC600`**（本页用它作个人号命名）。
- **桩的 4 个 push**：`push A / push B / push C / push D` → `[ebp+8]=D` 个人号、`[ebp+0xC]=C` 装备号。
- **全样本共 139 个特技桩**（对 `0x4101D9` / `0x42518F` 的 4-push 调用），
  **77 个不同装备号**，其中 **60 个桩的装备号 = `0x00`（无装备渠道）**；
  **41 个桩的装备名与个人名不同**（跨渠道别名），其余同名或为 0。
- **典型**：
  | 桩 | 装备号 | 装备名 | 个人号 | 个人名 |
  |---|---|---|---|---|
  | `0x43C3E1` | `0x71` | **冠绝于世** | `0x55` | **万夫莫敌** |
  | `0x405957` | `0x58` | 戮力同心 | `0x71` | 戮力同心 |
  | `0x478EAE` | `0x69` | 一骑当千 | `0x47` | 一骑当千 |
- **产物**：`大鲸鱼产生专用\_装备号总表.md`（全 256 行 + 139 桩 + 按装备号分组）、`_装备号总表.csv`；
  生成器 `大鲸鱼产生专用\_装备号总表.py`（现读字节，不依赖旧号）。

## 适用版本

- 样本 `Ekd5.exe` `4A761A94A72D80D17A260E9BCBA0E0A4F2F6C8469CCE0C2F19BDEF2D0A0427CF`（2026-10-18 现读）。
- UE 偏移与文件偏移一致（`0x9D800`）；VA 需按 `.api` 节换算：`VA = 0x4BE000 + (file - 0x90200)`。

## 已确认事实

### 1. 两张名表的基址（现读字节反推）

| 表 | 文件偏移 | VA | 行号含义 |
|---|---|---|---|
| 宝物/装备名表 | `0x9D800` | **`0x4CB600`** | 装备号 |
| 兵种/个人名表 | `0x9E800` | `0x4CC600` | 个人号 |

验证（VA 0x4CB600 现读）：

| 行 | 宝物/装备名 | 兵种表同号名 |
|---|---|---|
| `0x55` | 策略反伤 | 万夫莫敌 |
| `0x58` | **戮力同心** | 特效模仿 |
| `0x69` | **一骑当千** | 每回合恢复SP |
| `0x71` | **冠绝于世** | 戮力同心 |

### 2. 桩的解析规则

```
push A / push B / push C / push D  →  call 0x4101D9 / 0x42518F
[ebp+8]  = D  ← 个人号（0x41301E 只对它取低字节，交 0x4198BE 按 16B 行索引查兵种表）
[ebp+0xC]= C  ← 装备号（走 0x43C794，查宝物表空间）
```

### 3. 装备名 ≠ 个人名的 41 个桩（跨渠道别名，节选）

| 桩 | 装备号/名 | 个人号/名 |
|---|---|---|
| `0x43C3E1` | `0x71` 冠绝于世 | `0x55` 万夫莫敌 |
| `0x40BF9C` | `0x1C` 猛击强攻 | `0x72` 势不可挡 |
| `0x40CD27` | `0x57` 强化穿透 | `0xC0` 化力为疗 |
| `0x410EDE` | `0x3F` 失效 | `0x21` 辅助全格挡 |
| `0x413263` | `0x4D` 疾风破防 | `0x75` 疾风攻击 |
| `0x41ABCE` | `0x2E` 凤凰躯 | `0xBF` 绝对反击 |
| `0x4210F7` | `0x43` 却邪织命 | `0x00` 覆海之龙 |

（完整 41 行见 `_装备号总表.md` 第二节。）

### 4. 装备号被多个桩引用的情况

- `0x00`（无装备渠道）× 60
- `0x42` 主动连击 × 2、`0x62` × 2、`0x6B` × 2，其余各 1 个桩。

## 实现·使用方法

```bat
python 大鲸鱼产生专用\_装备号总表.py      :: 重新生成 _装备号总表.md / .csv
```

- 要查某个装备号叫 **什么**、被 **哪个桩** 引用：打开 `_装备号总表.md` 第三节（按装备号分组）。
- 要查某个特技的个人号/装备号：第二节按桩地址排序；或用 CSV 过滤。

## 风险与边界

- **基址坑**：旧页面/旧工具里写 `VA 0x4CB800` 的地方会偏 32 行（例如 `_查配对表.py`、`_两张名表全貌.py`、`_查6F存量.py` 的常量）。
  `_特技名表导出.py` 用的是**文件偏移 0x9D800**，输出正确，只是文档里把 VA 标成 0x4CB800。
- 装备号 `0x00` 在表里不是名字（是无效行），统计时必须单独处理。
- 桩扫描会漏掉"非 4 个立即数 push"的桩（如 push ecx/寄存器形态），本表只覆盖立即数桩。
- 装备号 `0xFF` 在 `0x43D355` 出现，是终止/无效值，不是真实装备。

## 证据来源

- 现读字节：VA 0x4CB600 / 0x4CC600 各 256 行（`_装备号总表.py`）；GBK 串定位（万夫莫敌仅在 0x4CCB50）。
- 反汇编：`0x41301E`（`[ebp+8]` 取低字节→`0x4198BE` 16B 行索引）、`0x43C794`（装备号另一路）、`0x4198BE`（`shl ecx,4; add edx,ecx`）。
- 用户截图：UE `0x9DF10` 行 `0x71` = `B9 DA BE F8 D3 DA CA C0` = **冠绝于世**（与 VA 0x4CB600 现读一致）。
