## 结论速览

1. **两张表各自 255 行 × 16 字节**，行格式 = 名字 12B（GBK，尾部 0 填充）+ 2B 零 + **显示 flag 1B（行内最后一字节，偏移 15）**。
2. **引擎在用名表**：UE 文件 `0x9E800` ＝ **OD/VA `0x4CC600`**（该节换算 `+0x42DE00`），**行号 = 特技/特效号**。
   ★ 实证：**被 6 处代码以立即数基址引用**（`0x41B714`、`0x421F01`、`0x421F55`、`0x44D8D2`、`0x466E53`、`0x467B22`）⇒ 引擎确实拿它查名。
   ★ 口径：本库 `01-核心引擎/复刻版6.6山贼特效与扩展接口.md:116` 记为「**原有兵种特技**（每行 16 字节、通常 255 行，扳手源码确认）」；
   「个人特技」是更早的旧标签。**本工作区一律按用户口径称『兵种特技名表』**；兵种与个人**共用同一号空间**，故两种分配指向同一张名表。
3. **宝物特效名表**（用户口径 2026-10-16 + 截图逐行核对 ✓）：UE `0x9D800` ＝ VA `0x4CB600`，**行号 = 宝物特效号**。

   行 `0xD1/0xD6/0xD7/0xF1/0xF5/0xF6/0xF8/0xFA/0xFE` 名字自称 `NN空效果`；用户口径：**有些名字对应多个宝物特效**（同一显示名覆盖多个号）。

   `0x41B713`（号=函数参数）、`0x421F00`、`0x421F54`（号=`[ebp-0xC]`）、`0x44D8D1`（号=`ecx`）、`0x466E52`、`0x467B21`（号=某记录 `+7` 字节）——**全部指向兵种特技名表**。

4. **显示 flag（实测）**：01 = +%d；02 = +%d%%；03 = -%d%%；04 = %d%%；05 = %d；06 = %d次。
   例：`0xF5 ※削减全能力` = `03 -%d%%`、`0xF6 ※物理易伤` = `02 +%d%%`、`0xF1 策略猛击` = `04 %d%%`、`0x24 防御暴击` = `00 不显示`。
5. **两张表是彼此独立的两张表**（并非『同一号的两个空间』）：**同号不同名**，引用号必须带表名。
6. f 列 = **后缀类型码**（每行偏移 15）：`00` ⇒ **通常显示空白**（函数有『拼接目标 arg3==0 就什么都不加』的早退 `0x4621C1 je 0x462236`；有目标时才拼 `--`）——**用户实机确认 `0x02 破妄归真` 后缀空白**；`01` ⇒ `+%d`（值=0 ⇒ `--`；值=0xFF ⇒ `杀`（GBK `C9 B1`=U+6740，**不是『色』**，我先前认字错过））；`02` ⇒ `+%d%%`（值=0 ⇒ `--`）；`03` ⇒ `-%d%%`；`04` ⇒ `%d%%`；`05` ⇒ `%d`；`06` ⇒ `%d次`；**`07` 及以上 = 文字描述类**（引擎先 `call 0x460510` 生成文本，再用 `%s` 拼到名字后）。分派代码 `VA 0x4621C1`..`0x462271`；后缀指针表 `VA 0x462274`（`[f-1]*4`）；格式串池 `0x48E68C`..`0x48E6B0`；`%d次`@`0x48C541`。
