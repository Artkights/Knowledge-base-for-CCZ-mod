# 四个全局的定性（做特技补丁的前提）

> 样本：`Ekd5.exe` SHA `F3455B30…`；证据：**按指令边界对齐的引用扫描**（`_查全局2.py`）+ 上下文反汇编
> 起因：逐族反汇编（第 1~4 批）里反复出现这几个全局，但库内无结论 ⇒ 升级为本轮 P0，此处收口

## 结论速览

| 全局 | 读点 | 写点 | 定性 | 置信度 |
|---|---:|---:|---|---|
| **`0x505FDC`** | 多处 | **1 处**（`0x425EF0`）| **★ 二值模式开关**：写入后**立刻**用它选分支 | 高（有直接证据）|
| **`0x505F5C`** | **仅 1 处** | **0 处** | **"只被功勋卓著读、全程无人写"** ⇒ 恒为 0 的死条件 | 高（全映像扫描）|
| **`0x501BF9`** | 3 处 | **8 处** | **取值 `0xFF/1/2/5/6` 的状态机/行动标志** | 中（值域已知，语义待实机）|
| **`0x501B00`** | 5 处 | 0 处 | **一张表/数组的基址**（多处以 `[eax+0x501B00]` 形态用）| 中 |

## 已确认事实

### 1. `0x505FDC` = 二值模式开关（有"写入后立刻选分支"的铁证）

```
00425EEB  call 0x41DD72
00425EED  test eax,eax
00425EEF  inc  eax
00425EF0  mov  byte [0x505FDC], al      ★ 写：eax==0 ⇒ 写 1
00425EF5  jmp  0x425EFE
00425EF7  mov  byte [0x505FCC], al      ← 另一分支写 0x505FCC（不同全局！）
00425EFC  mov  al, 5
00425EFE  push eax
00425F09  cmp  byte [0x505FDC], 0       ★ 立刻用它选分支
00425F10  jne  0x425F19
00425F12  call 0x425F56                  ← 模式 A
00425F19  call 0x41E6A4                  ← 模式 B
```

**为什么它重要**：`0x57 借力打力`（域 `0x45D316`）入口 **`cmp byte [0x505FDC], al / jne 退出`**；
功勋卓著族 `0x42AB8E` 用它决定"加成 ×2"还是"整段跳过"。
⇒ **它是跨族的行为开关**，改它会影响多个特技。

### 2. `0x505F5C` = 只读不写的**死条件**

全映像（按指令边界对齐）扫描结果：**只有 1 处真引用** —— `0x42ABC8`（就在功勋卓著核心 `0x42AB8E` 内）：

```
0042ABC8  cmp byte [0x505F5C], 0 / je 0x42ABD6      ← 「为 0 才走默认加成」
```
**没有任何写点** ⇒ 若该全局在数据段初值为 0，这个分支**永远走"默认"**；
反之若初值非 0，则"整段跳过"永远成立。**⇒ 这正是"改一个字节就能改行为"的典型候选点**
（但**必须先实机读它的初值**再决定动不动）。

### 3. `0x501BF9` = 取值 `0xFF/1/2/5/6` 的状态机

| 位置 | 动作 | 值 |
|---|---|---|
| `0x417D4F` | 写 | **6** |
| `0x43ACBD` | 写 | **1** |
| `0x43B314` | 写 | **2** |
| `0x43AD94` / **`0x43D50D`（二次行动域）** / `0x44AD48` | 写 | **0xFF** |
| `0x465FE6` / `0x467CFC` | 写 | **5** |
| `0x43DEFA` | 写 | `al`（动态）|
| `0x4125DA` | 读 | `cmp byte [0x501BF9], al` |
| `0x44A5DD` | 读 | `mov al, byte [0x501BF9]` |

⇒ 值域 `{1,2,5,6,0xFF}` ⇒ **疑似"行动/阶段类型"**（`0xFF` = 未定/结束）。

### 4. `0x501B00` = 一张表的基址

| 位置 | 形态 |
|---|---|
| `0x42ABE6` | `cmp byte [eax + 0x501B00], 0`（**功勋卓著核心**：非 0 才真正加功勋）|
| `0x43EBA7` | `cmp byte [eax + 0x501B00], 0`（同族形态）|
| `0x420C01` | `add eax, 0x501B00` |
| `0x425470` | `add edx, 0x501B00` |
| `0x47B744` | `mov ecx, 0x501B00` |

⇒ **是基址**（5 处都拿它当基址用）；项长/项数与语义未定。

## 实现·使用方法

```bat
python 大鲸鱼产生专用\_查全局2.py 0x505FDC 0x505F5C 0x501BF9 0x501B00
```

**★ 关键判据（本页第一条教训）**：
**查全局引用必须"按指令边界对齐"**，不能直接搜 4 字节常数 ——
我第一版直接搜 `DC 5F 50 00` 报出 **61 处**"引用"，其中绝大多数是
**地址计算常数**（`imul ecx,ecx,0x61 / add ecx,0x4A3E77` 之类的立即数里**恰好含**该字节序列）。
按边界重扫后 `0x505FDC` 的**真引用只有 2 处**（1 读 1 写）。

## 风险与边界

* **未实机验证**：`0x505F5C` 的初值、`0x501BF9` 各值的含义、`0x501B00` 表的结构，都需运行时确认。
* `0x505FDC` 是**跨族开关** ⇒ 改它前必须先把"哪些特技受它影响"列全（至少：功勋卓著族、借力打力）。
* 写 `0x501BF9` 的 8 处里有一处就在 `0x38 二次行动` 的域（`0x43D50D`）⇒ 与"二次行动"强相关。

## 待验证项

* **P0**：`0x505F5C` 的**运行时初值**（决定功勋卓著是否"整段跳过"）—— 只读采样即可
* **P0**：`0x505FDC` 的运行时取值 + "受它影响的特技清单"（先列全再谈改动）
* **P1**：`0x501BF9` 的 `{1,2,5,6,0xFF}` 各代表什么（配合"二次行动"实机分支）
* **P1**：`0x501B00` 表的起始/项长/项数（`mov ecx,0x501B00` + `call` 那处可定位）
* **P2**：`0x505FCC`（与 `0x505FDC` 在同一函数里被另一分支写入）的语义
