# 经典战棋引擎功能开发与移植（复刻版6.6山贼·工作区适配版）

> **来源与许可（必读）**：本 skill 改编自《曹操传 Mod 公共知识库》的 `engine-feature-development`
> （<http[本地盘]//github.com/lanceyuki/caocao-mod-public-knowledge-base>）。
> 许可：曹操传 Mod 公共知识库非商业使用许可 1.0 —— 非商业可复制/改编，**须署名 + 附来源与许可链接 + 说明修改**，
> **任何商业用途均禁止**。修改：已按本工作区的工具、规则与实测教训改写（新增七步工具映射、五级证据、
> 本工作区踩坑表）。**本 skill 与 `AGENTS.md` 冲突时，一律以 `AGENTS.md` 为准。**

## 何时使用

- 要**新增或修改**战斗 / 状态 / 属性 / 界面 / 特技等引擎行为；
- 要在写补丁前**追清**一个已有机制的判定链、数据链与最终消费者；
- 要把参考版本或旧补丁的**功能移植**到本样本（`Ekd5.exe`）；
- 补丁应用后出现**启动失败 / 异常分支 / 崩溃 / 回归**；
- 要判断某个二进制补丁**是否可行、怎么证明它有效**。

**不用**：只改地图 / 美术 / 文本 / 剧本数据、不涉及二进制引擎行为时，走对应的数据或内容工作流。

## 七步工作流（每步都对应本工作区的现成工具，不许另起）

| 步 | 动作 | 本工作区现成手段 | 出口（答不上就不许进下一步） |
|---|---|---|---|
| 1 | 锁定目标 + 保护基线 | `_开场.py --task "<关键词>"`、`_样本时间线.py`、`_dsh写锁.py status` | 能说出：目标文件、参考材料、**当前基线 SHA**、本次允许改变的行为 |
| 2 | 写**行为契约**与验收场景 | 本页模板 | 命中 / 未命中 / 边界值 / 原生门控 / 回归路径**各有可观察场景** |
| 3 | 以目标引擎为准追证据 | `_知识检索.py`、`_dsh反汇编工作台.py`（离线批量）、`mcp__kb__exe_info/exe_bytes`（只读复读）、x32dbg（执行级） | 找到真实路径 + 调用约定 + **可观察的消费者** |
| 4 | 设计**最小且可回滚**的改动 | 前像断言 + 旧字节锁 + 备份 | 有字节级计划、前像、回滚方式、覆盖路径理由 |
| 5 | **单一生成源**构建产物 | 生成器脚本（**不手改补丁文本**） | 从干净副本可重复生成同一结果 |
| 6 | **分层验证** | `_42结束回合.py --probe`（phase/enemy_alive/ours_ready）、`_集气模式探针.py`、`大鲸鱼自动战斗.py --go --breakpoint`（旧 `_x32断点探针.py` 已退役） | **判据：前 … → 后 …** 两值对照都打出来 |
| 7 | 沉淀可复用知识 | `kb_write_page` / `kb_changelog_append` / `ledger_append` + `交接.md` | 方法层与样本层分开写，样本字节标注"样本线索" |

## 行为契约模板（第 2 步直接套）

```text
触发条件 / 执行时机：
作用对象 + 数据来源 + 计算输入：
预期输出 / 副作用：
哪些原生门控、优先级、状态、装备、已有机制会改变结果：
哪些路径必须保持原样：
边界场景（命中/未命中/边界值/早退/回归）：
每条标注：【已确认】/【推断】/【待查】
```

**说明书文本只是语义线索**，必须用目标代码流核实；**"能编译""补丁已应用"都不是行为验收**。

## 五级证据（不可越级替代，只报实际做到的层级）

| 级 | 证明什么 | 本工作区手段 | 不能证明什么 |
|---|---|---|---|
| 1 静态检查 | 生成字节、指令边界、跳转目标、前像断言、节不重叠 | 工作台、`exe_bytes` | 程序会跑、会生效 |
| 2 应用 / 文件读回 | 磁盘文件真的变成预期字节 | `_dsh写锁.py` 写后复读 + `_改动总账.py` | 内存里也是、运行时走这条分支 |
| 3 运行时读回 | 进程内该地址当前字节/值正确 | x32dbg `memory_read`、采样脚本 | 该分支**执行过** |
| 4 受控启动 + 路径观察 | 目标能起、目标函数/分支被执行 | `_自动读档进战场.py --go-safe`、x32dbg 命中读数 | 玩家看到的效果 |
| 5 游戏内验收 + 回归 | 契约里的成功/失败/边界/原生行为都对 | `_42结束回合.py --probe`、自动战斗、`--ratio` 保命验收 | 未跑的场景 |

**硬规则**：断点命中 = 只到第 4 级；"值符合预期" = 只是瞬时状态。
**本工作区战斗/伤害/暴击/闪避/连击结论一律必须在集气模式 `4018=1` 前提下取得**，并在结论里注明。

## 补丁设计四条硬要求

1. **优先不动原生分支语义**，并说明该位置为何覆盖所需全部路径。
2. **原位核实**：前像、完整指令边界、周边数据、现有引用、实际占用范围。
   **全零 / NOP 区域不能单独证明可安全写入**（可能是活跃布局或被交叉引用）。
3. **搬迁数据要按完整值域**：确认索引范围与终止边界；跳转/调用/循环要证明目标、长度、符号性与边界。
   注意**整数宽度与符号扩展**（有符号/无符号比较、操作数宽度、计数器终止），模拟首项/末项/越界。
4. **改写返回路径时**：桥接逻辑必须有清楚、独占的栈帧；逐条推演命中 / 未命中 / 提前返回 / 原生门控分支的
   栈高度、返回地址、寄存器与标志位恢复。调用约定（`ret N` vs 调用者 `add esp,N`）**从机器码确认，不看函数名**。

## 生成器与写入

- 补丁字节**只有一个事实源**：生成器或结构化源码；不要让手改文本与生成器各自演化。
- 用程序算相对位移并断言前像、映像范围、块长度、模块边界不重叠。
- 写盘**唯一合法入口**：`大鲸鱼产生专用\_dsh写锁.py` 的 `safe_write_exe()`
  （三重校验 → 备份 → 写入 → 复读比对 → 审计行）；**禁止** `open(exe,'wb')` / `shutil.copy2`。
- 写入前确认**目标 SHA 匹配**且**游戏进程未运行**（x32dbg 附加过的进程退出后会变僵尸 ⇒ 先关 x32dbg）。

## 收尾

按契约逐项报告：静态检查、文件读回、运行时读回、受控启动、路径观察、游戏内结果——**只报实际做到的层级**，
并记录：未覆盖路径、失败与修复原因、回滚位置、下一步给谁。
组合两个各自验收过的补丁 ≠ 组合已验收：要检查共享写入、共用调用路径与状态交互。

## 常见误区（含本工作区实测教训）

| 误区 | 应采取的做法 |
|---|---|
| 参考版本地址/逻辑相同就直接复制 | 在目标上重新核对函数、调用、表、状态与 ABI（6.5 与 6.6 结论**不得互相套用**） |
| 找到一个"看起来合适"的辅助函数就当必经入口 | 分别证明：函数职责 / 原生流程何时调用它 / 新逻辑能否安全复用它 |
| 断点命中或寄存器符合预期就认为功能完成 | 继续追到**消费点**，并完成启动与游戏内验收 |
| 连续零字节或 NOP 就是空闲代码洞 | 查边界外、数据、交叉引用、运行时用途与最终生成长度 |
| 补丁文本手改正确就不必回归生成器 | 从唯一生成源重建并验证字节一致 |
| 崩溃地址就是根因 | 先保存现场（EIP/寄存器/调用栈/异常码），再结合改动范围定位 |
| 一个构建的样本结论可推广到所有版本 | 说明样本范围，每个目标构建上复核关键前像与语义 |
| 改大缓冲区/改表项数量就算完成数据迁移 | 同时追踪初始化/生产端、容量与尺寸描述、索引表与最终读取范围 |
| 一个陌生数字就是引擎自定义协议 | 先查平台标准常量（`WM_*`/`STN_*` 等），再从处理分支确认用途 |
| `WM_COMMAND(IDOK)` 就能完成业务动作 | 实测**只关框不办事**（结束回合无效）⇒ 用权威实现里的**物理点击**（`_42结束回合.py:click_yes`） |
| 自绘界面用 `PostMessage`/`SendMessage` 模拟鼠标 | 自绘窗口不认消息 ⇒ **先悬停 ≥0.5s 再物理点击**，且点前显式置前（游戏只在前台收鼠标） |
