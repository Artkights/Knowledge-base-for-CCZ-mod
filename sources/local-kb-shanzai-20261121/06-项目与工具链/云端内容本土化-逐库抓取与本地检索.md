# 云端内容本土化-逐库抓取与本地检索

## 结论速览

1. **两件事分开做**（用户口径 2026-10-15）：「**逐库抓下载选取使用**」+「**门禁不变**」+
   「**先把云端的变成本地在检索吧**」⇒ 抓取与判类归 `_普罗逐库抓取.py`，
   检索归 `_知识检索.py` 的**第四个来源 `cloud`**，**门禁（`_开工门禁.py`）一行没动**。
2. **普罗 29 库已逐库处理**：**7 个 CCZ 相关库**抓成快照落地（`_外部源码\普罗\`，242 文件），
   **其余 21 个无关库"流式判类后立即中止，不落盘"** ⇒ 不占 1.3 GB 磁盘
   （`Evil` 717 MB、`WarLords` 316 MB 因此一个字节都没下）。
3. **检索索引 1199 → 1457 条**（知识库 425 + 工具 778 + **云端 254**）；
   云端命中**永远单独成节**并带外部样本护栏，不与本地 6.6 结论混排。
4. **★ 一条硬教训（我踩的）**：**不要把 `/lua54/`、`/plugins/` 当垃圾跳过** ——
   `ccz-LuaSkill` 自己捆绑的 Lua 5.4 源码就在 `LuaSkillEngine/lua54/`，
   那 62 个文件（含 `lua_api.cpp`，伤害公式的权威实现）**正是要归档的内容**。
   我一度沿用旧脚本的跳过名单，靠"备份 vs 本轮逐文件比对"才发现漏了。
5. **API 额度是稀缺资源**：未认证 `api.github.com` 只有 **60 次/小时**，本会话多次 `403 rate limit exceeded`
   ⇒ 仓库列表一律**读本地缓存** `_普罗仓库清单.json`；抓整包走 **codeload tarball，不占额度**。

### 二、抓取器为什么不能用 `git clone`

| 目标 | 结果（2026-10-15 实测） |
|---|---|
| `api.github.com` | 通，但**未认证 60 次/小时**，本会话多次 `403 rate limit exceeded` |
| `codeload.github.com`（zip / tar.gz） | **通，且不占 API 额度** ⇒ 抓取主通道 |
| `api.github.com/repos/<o>/<r>/tarball/<br>` | **通**（重定向到 codeload），同样不占额度 |
| `git ls-remote` / `git clone` | ❌ git 配了 `127.0.0.1` 代理，`Failed to connect to github.com:443 over proxy` |

### 三、本土化的检索接法（**门禁不变**）

- `_知识检索.py` 的 `SKIP_DIR_PARTS` 里**本来就有 `_外部源码`**（避免同一 docstring 命中两次），
  ⇒ 云端内容**另开一路 `src="cloud"`**，不混进「知识库 md / 工具 docstring」两节。
- 只索引 `CLOUD_EXT` 的文本文件，**排除 `index.json`（656 KB）等巨型数据文件**与 `_快照.json` 元数据。
- 云端命中**打印前先打护栏**：
  「⚠ **外部样本**（Artkights 6.5/6.5pl/6.6 分区、caocao 6.5pl、普罗 6.2~6.4）：
  地址一律只作线索，必须在本样本 `Ekd5.exe` 重核（AGENTS.md §3/§12）；
  `candidate` 状态条目**不得**作为自动写回依据。」

| 用途 | 命令 |
|---|---|

| 只搜云端 | `… --only cloud` |
| 重建索引（含云端） | `… --rebuild` |

## 风险与边界

1. **只读远端 + 只写 `_外部源码\`**；`_普罗逐库抓取.py` **没有任何写 `Ekd5.exe` 的能力**。
2. **外部地址一律只作线索**，必须在本样本重核（§3 版本护栏 / §12）。
3. **门禁不变**：`_开工门禁.py` **未改一行**，云端内容只在 `_知识检索.py` 的 `cloud` 节出现。
4. **API 额度**：`--fetch-list` 会耗额度且可能失败（已做降级）；抓取本身不耗额度。
5. **跳过名单是危险参数**：见结论速览第 4 条 —— 下次改 `SKIP_PATH` 前，
   先确认目标项目有没有把上游源码（`lua54` 之类）放在该目录里。
6. 判类判据与 `_拉普罗全仓库.py` **同一套**（含两个实测误判坑：二进制巧合、通用三国术语）；
   `--fetch-all` 对巨型无关库是"流式读一部分就中止"，**不保证读完**，判类结论以命中信号为准。
