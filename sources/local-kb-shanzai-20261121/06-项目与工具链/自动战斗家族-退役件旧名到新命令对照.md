# 自动战斗家族：退役件「旧名 → 新命令」对照表（2026-10-26）

> **本页存在的唯一理由**：库里、日志里、别的会话留下的命令里，还写着 **60 个已退役的文件名**。
> 本页把它们逐条翻译成现行写法，**避免"照抄一条旧命令 ⇒ 报找不到文件 ⇒ 再手写一个新脚本"的循环**。
> 退役动作本身与原因见 `大鲸鱼产生专用\._废弃实验\自动战斗历史件-20261026\README-为什么退役.md`。

## 结论速览

1. **唯一入口** = `大鲸鱼产生专用\大鲸鱼自动战斗.py`。自动战斗 / 主动战斗 / 推进回合 / 读档进战场 / 托管 / 保命 / 断点命中观测 / 收尾清断点 **全在这一个文件里**（2026-10-26 三入口合一 + 二批退役）。
2. **旧名一律不要再执行**。`_42主动战斗批次.py`、`_自动战斗一次到底.py` 这两个"转发壳"也已经在退役名单里（用户口径「**壳也杀掉吧，只要大鲸鱼自动战斗**」）⇒ 命令行**不再兼容**，会报 `No such file`。
3. **历史证据不改写**：`更新记录.md`、`待验证清单.md`、`三链执行级证据*.md`、`地址语义与Hook契约.md` 里写着的旧命令是**当时用什么跑出这个结论的**记录，照抄保留；要复现就用本页翻译后的命令。
4. **为什么必须退役**：这 60 个件每个都自带一套 `mouse_event/SetCursorPos` + `ReadProcessMemory/WriteProcessMemory`，各自实现自己的闸门 ⇒ 用它们做测试会**绕开 `4018=1` 前提、R3.5 单次 ≤5 回合、托管 `+0x0E` 回滚、收尾删断点**。真实事故：`_42主动战斗批次.py --batch 1 --rounds 1` 托管未回滚 ⇒ 游戏后台自己打到约 30 回合并结束本局，**该批动态证据整批作废**（`00-总览与规范\自动测试强制规则.md` R3.5 强化节）。
5. **查旧脚本干过什么**：`python 大鲸鱼产生专用\_知识检索.py "<词>"` **仍然会命中退役件**（故意的：`_废弃实验` 不在检索剔除名单里）⇒ 读思路可以，运行不行。
