# ChatGPT 账号 MFA 与本地验证码生成器

## 结论速览

- **ChatGPT 账号已于 2026-10-21 开启双因素验证（TOTP）**。开启后**不能跳过**，
  每次新设备/新会话登录都要 6 位验证码。
- **触发原因**：安装 **GitHub 连接器**（`chatgpt.com/plugins/plugin_connector_1p_*`）时
  OpenAI **强制要求账号已有 MFA**，否则该连接器装不上；点「取消」只是退出本次安装，重装必再弹。
- **本地验证码生成器**：`[本地盘]\Users\Administrator\.dsh\hidden-launchers\_TOTP.cmd`（双击即出码，按任意键刷新）。
- **⚠️ 密钥是明文存放在** `_totp.py` 的 `SECRET` 常量里，**该目录不在 git 仓库**（在 `~/.dsh/` 下），
  但备份整个用户目录时需留意。
- **⚠️ 本轮密钥曾出现在对话记录中** ⇒ 建议在 ChatGPT 设置里「关闭 → 重新开启」双重验证以轮换密钥，
  轮换后只需改 `_totp.py` 里 `SECRET = "..."` 那一行。

## 适用版本

- 与 `Ekd5.exe` 样本无关，属账号与工具链配置。
- 适用 ChatGPT 网页版（2026-10 界面）；连接器安装流程可能随版本变化。

## 已确认事实

### 1. 为什么必须开 MFA

安装 GitHub 连接器时弹出：

```
连接你的身份验证器应用
使用身份验证器应用扫描二维码，然后输入应用中显示的 6 位代码
```

**点「取消」后重试安装仍会弹** —— 这是 OpenAI 对「可访问第三方数据的连接器」的硬性门槛，
不是可选提示。

### 2. 国内用户可用的验证器

| 平台 | 推荐 | 说明 |
|---|---|---|
| **安卓** | **微软 Authenticator** | 华为/小米/OPPO/vivo 应用商店可直接下载，**纯离线** |
| **安卓（备选）** | Aegis / 2FAS | 开源，APK 直装，不依赖 Google 服务 |
| **iPhone** | **系统「密码」App** | 设置 → 密码 → 密码选项 → 验证码，**无需安装** |
| ❌ 不可用 | Google Authenticator | 需 Play 商店 |

**验证器本身完全离线，不需要梯子**；只有 ChatGPT 网页需要梯子。

### 3. 本地生成器（无手机时的替代方案）

`_TOTP.cmd` 双击 → 调 `_totp.py` → 打印当前 6 位码与剩余秒数 → 按任意键刷新。

算法：RFC 6238 TOTP，**HMAC-SHA1 / 30 秒步长 / 6 位**，Base32 密钥。

```python
h = hmac.new(key, struct.pack(">Q", int(time.time() // 30)), hashlib.sha1).digest()
off = h[-1] & 0x0F
code = str((struct.unpack(">I", h[off:off+4])[0] & 0x7FFFFFFF) % 1000000).zfill(6)
```

### 4. 编码坑（本轮又踩一次）

`.cmd` 里**写了中文文件名** `_TOTP验证码.py` ⇒ 存成纯 ASCII 后变成 `???` ⇒
python 报 `can't open file '..._TOTP???.py'`。

**修正**：`.py` 与 `.cmd` **文件名都用纯 ASCII**（现为 `_totp.py` / `_TOTP.cmd`）。
即：**`.cmd` 的"纯 ASCII"要求包含它引用的文件名，不只是文件内容。**

## 实现/使用方法

### 日常登录

```
1. 输入密码
2. 要求验证码 → 双击 [本地盘]\Users\Administrator\.dsh\hidden-launchers\_TOTP.cmd
3. 抄 6 位数（不用打空格）→ 30 秒内填入并确认
4. 提示错误 = 超时，按任意键刷新出新码再试
```

### 换密钥后

编辑 `_totp.py`：

```python
SECRET = "新的Base32密钥"
```

（密钥在 ChatGPT 首次开启/重置双重验证时显示，点「无法扫描？请手动输入代码」可得。）

### 装到手机（可选）

在验证器里「手动添加账户」→ 粘贴同一串 Base32 密钥 → 以后手机直接出码，不必开电脑。

## 风险与边界

1. **密钥等于第二把钥匙**：任何人拿到就能生成你的验证码，绕开 2FA。
   不要截图外发、不要存进会被同步/提交的地方。
2. **本次密钥曾出现在对话记录**（DSH 会话存盘）⇒ **建议轮换**。
3. **换手机/重装系统前**必须确认密钥已离线保存，否则会**锁死账号**。
4. **恢复代码（backup codes）要单独存** —— 验证器全丢时靠它登录。
5. 本地生成器依赖本机 Python 与系统时间；**系统时间偏差 >30 秒会导致验证码全部失效**，
   若突然全错，先检查系统时间是否同步。
