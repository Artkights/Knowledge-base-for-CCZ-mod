### 二、帖中第四部分「主动连击」实例的可用性

帖中给出的补丁（慕容雪芸 2006）位置与原理：
- 抢占连击率函数 `0x405CE6` 内的 **`0x405D15`（5 字节）**，`JMP` 到代码洞 `0x485DD3`；
- 洞内：写回被占指令 → `PUSH 3A`（特效号）→ 取 `[4927F0+8]`（攻方 DATA 指针）→ `CALL 0x407A09`
  → `TEST/JE` 分流 → 有特效则 `MOV AL,64`（100%）直接跳回函数尾 `0x405D65`。

**对 6.6 的可用性判定**：
- `0x405CE6` **不是** 6.6 连击率函数入口（现读非序言）⇒ **抢占点必须重定位**；
  库内 6.6 的连击率函数是 **`0x4E40E0`**（见 `03-机制详解/连击.md`）。
- `CALL 0x407A09` ⇒ 6.6 应改为 **`0x4079DA`**（或按需重定位后自验证）。
- 代码洞 `0x485DD3` 现读**是 `55 8B EC`** ⇒ **已被占用/不是空洞**，绝不可照抄。
- ⇒ **帖中这套改法只能当"设计参考"，地址必须全部按 6.6 重新定位**。

## 实现·使用方法

### 老资料地址怎么快速判活（本轮用的三步）

1. **数据表**：搜 `add reg, IMM`（`81 C1/C2/C0 IMM32`）与 `imul reg,reg,imm8`（`6B C9 imm8`）
   两条形态，看**立即数基址**是否命中。
2. **函数**：读该址 3 字节，**是否 `55 8B EC`**（函数序言）；
   不是就用 **`funcstart <addr>`** 推定入口（库内 `_dsh反汇编工作台.py` 现成）。
3. **代码洞/补丁点**：**必须现读该处字节**（`exe_bytes`），
   命中 `55 8B EC` 说明已被别的函数占用、命中 `90` 才可能是洞。

工具（本轮全部复用现成）：
```bash
python 大鲸鱼产生专用\_指纹定位.py --hex "<字节串>"        # 跨现样本+全部备份定位
python 大鲸鱼产生专用\_dsh反汇编工作台.py funcstart 0x407A09
python 大鲸鱼产生专用\_dsh反汇编工作台.py func 0x4079DA
```
> ⚠ 工作台**必须用 DSH 运行时那份 Python**（`keystone` 只装在那里），否则所有子命令
> `ModuleNotFoundError: keystone`。

> ★ **十进制/十六进制**：本页同时给出两种写法（`0x19`=25、`0x24`=36、`0x30`=48、
> `0x3C`=60、`0x28`=40、`0x1B`=27、`0x46`=70、`0x48`=72）；
> 检索时两种写法都试（本库数据偏向 `0x`）。

## 风险与边界

1. **本页所有判定都是静态**（字节搜索 + 序言 + funcstart 推定），**未做实机验证**；
   `funcstart` 是启发式（"最近一个 `55` 且 8 字节内有 `8B EC`"），**可能落在函数内**。
2. **"序言命中" ≠ "语义相同"**：同址且是序言，只证明**那里有个函数**，
   不证明参数/返回值/语义与帖中一致（如 `0x406610` 是否仍读 `+0x2B` 需再读指令体）。
3. **基址 0 命中 ≠ 该表不存在**：可能是编译器换了寻址形态（如用 `lea`/寄存器基址），
   需另找；本页只报"立即数形态未命中"。
4. **不得照抄帖中任何代码地址去打补丁** —— 本轮已实测多处错位（含 `0x43B470` 落在 NOP 填充）。
