# 实机验证器：只读监控（不挂调试器）

## 结论速览

- `大鲸鱼产生专用/_实机验证v5.py` 是**只读**验证器：用 `ReadProcessMemory` 轮询
  单位表与战斗上下文，**不写游戏内存、不挂调试器**，用户正常玩即可。
- 2026-10-14 实测：能正确打开 Ekd5.exe 并读取（标题页时 ctx 全 0、单位表 250 项 HP 全 0）。
- 设计要点：**HP 差分 + 上下文历史回查**配对伤害与暴击标志 ——
  因为暴击标志/伤害槽是"预演"写入，HP 扣减要等动画播完（知识库实测差 11 秒）。

## 适用版本

- 主机：Windows + 管理员权限（需与游戏同权限才能 OpenProcess）。
- 目标：`Ekd5.exe`（任意版本均可，只读）。

## 已确认事实

- 关键地址（均来自知识库既有结论）：
  - `0x4927F0` = 战斗上下文**常量基址**（**不要** `rd32` 解引用）
  - `+0x00` 攻击者 slot、`+0x01` 目标 slot、`+0x84` 物理伤害[0]、
    `+0x254` 策略伤害[0]、`+0x604` 暴击、`+0x608` 连击、`+0x614` 反击
  - 单位表 `0x4A7B20 + slot*0x30`，HP 在 `+0x10`
- 带防御暴击 `0x24` 的目标默认聚合 Data `330` / `510`（可用脚本内 `DEF24_DATA` 改）。

## 实现·使用方法

```bat
:: 先启动游戏并进战场，再跑（会在标题页读不到有效数据）
大鲸鱼产生专用\_pyrun.cmd 大鲸鱼产生专用\_实机验证v5.py --secs 1800

:: 已知特效值时直接校验比值
大鲸鱼产生专用\_pyrun.cmd 大鲸鱼产生专用\_实机验证v5.py --v 75
```

输出：每次 HP 下降打印一行（时间/slot/data/HP 变化/伤害/攻击者/暴击/连击），
结束时按 Data 号聚合「暴击 vs 非暴击」平均伤害与比值，并给出判定。
日志追加到 `_实机验证v5日志.txt`。

## 风险与边界

- **只读**：任何情况下不会修改游戏内存，可放心在正常游玩时挂着。
- 若 `OpenProcess` 失败 ⇒ 监控脚本与游戏权限不一致（都用管理员启动）。
- 未进战场时上下文全 0 属正常，不是脚本故障。
- 单位表字段偏移若在某版本变动，需要先核对 `02-数据结构/单位结构体.md`。
