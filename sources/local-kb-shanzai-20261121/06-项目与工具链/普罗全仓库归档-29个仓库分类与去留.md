## 五、普罗源码对"伤害预览"的可用性（本次重点结论）

**结论：没有现成实现，但有 3 个可复用零件。**

| 零件 | 地址 | 用途 | 出处 |
|---|---|---|---|
| **数值→文本** | `0x428372` | `void(char* buf, DWORD value, DWORD kind)`，**`__cdecl`**，调用方要 `sub esp,0xC`；`kind` 决定格式（`-%d` / `+%d%%`） | `CCZ-ExtendData/ExtendData/constants.h`、`teji.cpp` |
| 结算后飘字 | `0x450986` → `0x450033` | 画"浮动数字 + 血条"，**纯动画、不改 HP/MP** | `ccz-LuaSkill/game_structs.cpp`、`lua_api.cpp` |
| 数值消息框 | `0x42F699` | `void(DWORD a, DWORD b)`，实调用一律 `a=2`、`b=`GBK 指针 | `CCZ-ExtendData/dllmain.cpp` |

- **普罗全线没有"把预估伤害/命中/暴击显示到预览面板"的代码**（`预览`/`preview` 0 命中）；
  最接近的 `ai.estimate_physical_damage`（`lua_api.cpp:1259`）**纯计算、不上屏**，
  且是**独立简化实现**（不含威力系数/地形/克制/特技/暴击）。
- 我们自己找到的**预览真身**是引擎内的 `0x44049E` 簇 —— 见
  `03-机制详解/预览模块总图-伤害暴击命中连击集气范围.md` 与
  `03-机制详解/伤害预览数值来源-预览函数0x44049E.md`。

## 风险与边界

- 分类为**启发式**，不是权威判定；新增仓库时请重跑 `--classify` 并**人工读 README 复核**。
- GitHub API 匿名限流 60 次/小时；29 个仓库的树查询会消耗配额，批量前先确认余量。
- `--purge-unrelated` **会真删文件**；默认不删，只报告。
- 归档是**上游原样 zip 解压**，含二进制资源；不要用"源码只有几百 KB"来质疑完整性。
