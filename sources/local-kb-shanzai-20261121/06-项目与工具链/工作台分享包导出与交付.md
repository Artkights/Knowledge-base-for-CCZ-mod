# 工作台分享包导出与交付

## 结论速览

- 「把工作台的数据库分享给别人」在本工作区的正确落地 = 交付 **01 知识库（`小暗的本地知识库` 全量）+ 02 逆向证据与补丁源码 + 03 DSH 会话记录**，
  归档为 `大鲸鱼产生专用\分享包\复刻版6.6山贼-工作台分享包.zip`；本工作区**不存在** `.db/.sqlite` 数据库文件，所谓“数据库”即 `ai使用库` 下的这套文档库。
- 本次导出基准（2026-10-13）：**728 项 / 72.75 MB 原始 → 53.04 MB（Deflate 9）**，
  包 SHA256 = `971B9229D7DFEC258ED342B2C7287058ED060027B002C1584C34ABC8D3BDD114`。
- **硬护栏（必须遵守）**：`~/.dsh/.credentials.yaml` 含真实凭据（`client-connection/browser-session` 的 secret、
  `deepseek-account-platform/device` 的 id、`deepseek-account-platform/default` 的 token），**任何外发包一律排除**，且不得写进日志、示例或截图。
- 素材与二进制（`ai使用库.zip` 937 MB、`英杰传 6.6x` 895 MB、`复刻版6.6` 300 MB、mp3/jpg/avi/`.e5`）
  不进入外发包：它们对“让对方读懂结论”零贡献，只把包体从 73 MB 抬到 GB 级。
- 交付包里所有脚本、文档仍带**源机器绝对路径**；收包人必须在自己的 `AGENTS.md` 与脚本常量里改写路径后才能跑。

- 绑定项目：`复刻版6.6山贼`（工作区 `[本地盘]\ccz\曹操传6.6-V7.30 解压密码：66\复刻版6.6山贼`）。

### 3. 敏感面扫描结果（本次实测）

## 实现/使用方法

1. **下次再要外发**：直接复用黑名单与白名单两张表，先跑 `_dsh_pkg_build.py`，再跑后三个脚本；不要手工拷目录，避免漏掉 `__pycache__`/备份/凭据。
2. **收包人上手（写进包内 `00-入口必读.md`）**：
   - 解压到短路径 → 把 `01-知识库(放进你的工作区)` 内容放到自己工作区的 `ai使用库\小暗的本地知识库\`；
   - 自建 `AGENTS.md`（UTF-8 带 BOM）绑定「先查库、落盘、写前复读」三条；
   - 首句自检：让 AI 读 `README.md` + `00-总览与规范/当前进度与交接.md` 并复述进度。
3. **换机后必改**：`_*.py` 里的 EXE/游戏根目录常量、`_*.bat` 的 `cd /d`、`03-DSH会话记录/storages/workspace.json` 的 `path`、
   以及 `AGENTS.md` 的项目专属约定（如 `大鲸鱼产生专用`、`_归档检查.py`）。
4. **版本自检**：收包人先算自己 `Ekd5.exe` 的 SHA256，与 `6929FE0D…`/`98E30F86…` 对比；不一致则一切地址结论**先复读再采信**。

## 风险与边界

- 包内是**原样导出**：暴露源机器绝对路径（含 `[本地盘]\ccz\曹操传6.6-V7.30 解压密码：66`）、文件时间戳、调试日志；仅适合可信对象间传递。
- 知识库正文默认口径写的是“6.5 未加密基底”（历史遗留），但本工作区实际是 **6.6 山贼**；
  收包人若照 README 首段选版本会误判，**以本页与 `09-版本与外部资料/复刻版6.6山贼基底身份与静态分析总览.md` 为准**。
- 排除 `CCZModStudio_Reports` 后，知识库正文中指向 `CCZModStudio_Reports/...` 的报告路径在包内**不存在**，属预期缺失，不是数据损坏。
- 素材类需求（E5/R 形象/音频）无法从本包满足；需要时应回到源工程取相对路径对应文件，不要凭包内文字重建二进制。
- 会话 `.zstd` 未逐条脱敏，其中可能含第三方论坛抽取稿；外发前若涉及版权或隐私，先人工抽查。
