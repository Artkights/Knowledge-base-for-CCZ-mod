# `.api` 节与"槽区"——外部 API 指针（附 `.text1` 第二片槽区）

> 适用样本：`Ekd5.exe` **SHA256 `2AC91CB8…E3A7D45`**｜归并自 `可搬回清单-初版对照.md` **§90–§93 / §107–§110 / §131–§132**

## 1. 结论速览

1. **`.api` 节 = `0x4BE000–0x4CE000`**（VSize `0x10000` / Raw `0xF600`）：**前段是"外部 API 指针槽"，中后段是"壳函数"** ✓
2. **本样本有"两片槽区"**：`.api`（`0x4BE0xx`，USER32/KERNEL32/GDI32/**GDIPLUS**/**`Jpg.dll`**）＋ **`.text1` 的 `0x486xxx`**（USER32/WINMM）✓
3. **槽内容在文件里是空的/占位，运行时才由 loader/引擎填入**（§93 结论，§107 运行时证实）✓
4. **运行时解析结果（9 个槽）**：USER32 ×3、KERNEL32 ×2、GDI32 ×2、**`Jpg.dll!PngRead`**、**`GDIPLUS.dll!GdipDrawImageRectRectI`** ✓
5. **MOD 经 `.api` 调引擎**：MOD 就地改写段 `0x46D113` 内 `0x46D161` = `call 0x4C0600`（`.api` 壳）✓

## 3. 实现·使用方法

- **解析槽（推荐工具）**：`python 大鲸鱼产生专用\_槽归属解析.py [槽地址…]` ⇒ 输出「槽 → 模块!导出函数」✓
  - ⚠ **两个坑（已固化进工具）**：① 目标 32 位而本机 Python 64 位 ⇒ **必须 `EnumProcessModulesEx(..., LIST_MODULES_32BIT)`**（否则"全不属于任何模块"）；② psapi 三函数**必须声明 `argtypes`**（句柄 >2^31 会 `OverflowError`）✓
- **判"某槽是什么"**：先看运行时值落在哪个模块区间，再查该模块导出表；**精确命中**即得函数名 ✓

## 4. 风险与边界

- **7 个槽未命中导出**（USER32/KERNEL32/GDI32 内的 RVA）⇒ 它们**不是导出函数入口** ⇒ 疑"模块内部函数 / API 转发目标"；"最近导出 + 偏移"**只是线索**（`+0x7610` 这类不得写成"就是 `GetClassLongA`"）⇒ 定案需 **x32dbg 在调用点断点读 `EIP`** ✓
- 槽值**随加载基址变化**（ASLR）⇒ **不可硬编码**，必须现读 ✓
- `.api` 之外还有 `.text1` 槽区 ⇒ 只查 `.api` 会漏 ✓
