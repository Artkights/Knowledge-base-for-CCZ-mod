# 桩函数

## 结论速览

- 适用：页内“完整参数地址”指向 `6.5特效注入索引`，带 `*` 的特效号为补丁中的当前配置值；复刻版6.6山贼使用前须复读目标 EXE 核对。
- 标准桩固定在 `421080-42115A`，每桩占 17 字节，格式为 `push 效果值标志 / push 叠加标志 / push 装备特效号 / push 个人特效号 / call <调度函数>`。
- 参数取值：参数1 `1`=不需要效果值（纯开关型）、`0`=需要效果值（有强度等级）；参数2 `1`=不可叠加（只取一个渠道）、`0`=可叠加（两渠道累加）；参数3/参数4 为 0000-FFFF 的特效号。
- 三个已知标准桩的原样参数：`4210D0` 引导攻击 `01/01/36/18` → `call 006002C6`；`421106` MP恢复 `00/00/1B/01` → `call 0060002A`；`421175` 二次行动 `01/01/5A/38` → `call 00600819`。
- 模组新增特技用内联桩：`mov ecx,<单位指针>` → push 4 个参数 → `call 4101D9` → `test eax,eax` + `jz <skip_label>`，跳过 `600XXX` 调度与 `9BBFE4` 查表；已知实例地址 `472C41`、`4259AF`、`472D5F`、`4528FF`、`41A5BC`、`445F6D`、`446170`、`41AB03`、`441D1F`、`43D307`、`4529B5`、`4D3500`、`43D0E2`、`43D3AE`、`43D3F9`、`4072CA`，带 `*` 的特效号可直接改补丁文件中的 `#宝物号` / `#个人号` 偏移。
- 例外：`41AA98` 护卫（大段目标改写逻辑，内部调用包装/范围判断，个人号 `D1(209)`）与 `41AA4F` 强化攻击穿透（调用 `42518F` 包装判定，个人号 `DD(221)`）**不是**标准内联桩，改动时必须按各自代码上下文处理。

## 详细记录

#### 概述

桩函数是特技判定系统的入口点，每个特技对应一个固定格式的桩函数。它们位于内存的 `421080-42115A` 区域，每个占 17 字节。

#### 函数格式

##### 汇编结构

```asm
; 每个特技桩函数的固定格式
push <效果值标志>      ; 参数1
push <叠加标志>        ; 参数2
push <装备特效号>      ; 参数3
push <个人特效号>      ; 参数4
call <调度函数>        ; 调度函数地址
```

##### 参数说明

| 参数 | 名称 | 取值范围 | 说明 |
|------|------|----------|------|
| 参数1 | 效果值标志 | `0` 或 `1` | 控制是否需要读取效果值 |
| 参数2 | 叠加标志 | `0` 或 `1` | 控制效果值能否叠加 |
| 参数3 | 装备特效号 | 0000-FFFF | 装备提供的特技编号 |
| 参数4 | 个人特效号 | 0000-FFFF | 角色自身的特技编号 |

#### 参数详解

##### 效果值标志

控制是否需要读取效果值（用于控制特技强度的数值）：

| 值 | 含义 | 典型用途 |
|----|------|----------|
| `1` | 不需要效果值 | 纯开关型特技（如引导攻击、二次行动） |
| `0` | 需要效果值 | 有强度等级的特技（如MP恢复、伤害加成） |

##### 叠加标志

控制个人和装备两个渠道的效果值能否叠加：

| 值 | 含义 | 说明 |
|----|------|------|
| `1` | 不可叠加 | 只取其中一个渠道的效果值 |
| `0` | 可叠加 | 两个渠道的效果值累加 |

##### 特效号

特技编号是 16 位数值，用于在游戏数据中定位具体的特技配置。

#### 代码示例

##### 引导攻击 (4210D0)

```asm
; 引导攻击桩函数
; 效果值标志=1（不需要效果值）
; 叠加标志=1（不可叠加）
; 装备特效号=36(54)
; 个人特效号=18(24)
004210D0: push 01    ; 不需要效果值
004210D2: push 01    ; 不可叠加
004210D4: push 36    ; 装备特效号 = 54
004210D6: push 18    ; 个人特效号 = 24
004210D8: call 006002C6
```

##### 二次行动 (421175)

```asm
; 二次行动桩函数
; 效果值标志=1（不需要效果值）
; 叠加标志=1（不可叠加）
; 装备特效号=5A(90)
; 个人特效号=38(56)
00421175: push ebp
00421176: mov ebp, esp
00421178: push 01        ; 效果值标志 = 1
0042117A: push 01        ; 叠加标志 = 1
0042117C: push 5A        ; 装备特效号 = 90
0042117E: push 38        ; 个人特效号 = 56
00421180: call 00600819  ; 调度函数
00421185: pop ebp
00421186: ret
```

##### MP恢复 (421106)

```asm
; MP恢复桩函数
; 效果值标志=0（需要效果值）
; 叠加标志=0（可叠加）
; 装备特效号=1B(27)
; 个人特效号=01(1)
00421106: push ebp
00421107: mov ebp, esp
00421109: push 00        ; 效果值标志 = 0（需要效果值！）
0042110B: push 00        ; 叠加标志 = 0（可叠加）
0042110D: push 1B        ; 装备特效号 = 27
0042110F: push 01        ; 个人特效号 = 1
00421111: call 0060002A  ; 调度函数
00421116: pop ebp
00421117: ret
```

#### 内联桩函数

##### 概述

并非所有特技都必须使用 `421080-421180` 区域的标准桩函数。在实际模组开发中，**内联桩**是更常用且更灵活的模式：

**内联桩**：在游戏逻辑的任意合适位置直接内联桩函数的核心逻辑，即 `push 4个参数 → call 4101D9`，跳过调度函数和查表环节。

##### 内联桩模板

```asm
; 内联桩函数标准模板
; 使用场景：任意游戏逻辑函数内部
mov ecx, <单位指针>           ; 设置 ECX = 单位指针
push <效果值标志>             ; 00=需要效果值, 01=不需要
push <叠加标志>               ; 00=可叠加, 01=不可叠加
push <装备特效号>             ; 用户可编辑
push <个人特效号>             ; 用户可编辑
call 4101D9                 ; → 直接调用核心引擎
test eax, eax                 ; 检测结果
jz  <skip_label>              ; 无特技 → 跳过
; [特技效果代码]
skip_label:
```

##### 内联桩对比标准桩

| 特性 | 标准桩 (421XXX) | 内联桩 |
|------|-------------------|--------|
| 位置 | 固定区域 | 任意位置 |
| 调度函数 | 必须经过 600XXX | 跳过（直接调核心引擎） |
| 查表 (9BBFE4) | 必须 | 跳过 |
| 创建难度 | 需在 421XXX 找空位 | 只需在目标函数附近找5字节空间 |
| 代码洞需求 | 通常需要 | 通常需要 |
| 适用场景 | 引擎原生特技 | **模组新增特技（推荐）** |
