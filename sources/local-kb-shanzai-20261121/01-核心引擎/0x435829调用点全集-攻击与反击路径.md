# 0x435829 调用点全集 —— 攻击本体与反击路径（实机探针定案）

## 1. 结论速览

1. **`0x435829` = 单次攻击执行器，`cdecl` 调用**：`0x435829(攻击方slot, 目标slot)`，末尾**普通 `ret`**（不带立即数），**调用方用 `add esp,8` 清参**。
   ⇒ 注入桩里必须先 `call 0x435829`（压返回地址）再跳回 `站点+5`，**禁止尾跳**（尾跳会把上层返回地址当自己的弹掉 → 闪退，实机教训）。
2. **攻击本体调用点 = `0x43DB4D`**（实机 16 点全探命中）：属函数 `0x43DB23`（攻击分发），
   现场：`ecx = 攻方单位指针`，`push eax`（目标 slot，al 来自 `[ebp+0x10]`）、`push [ecx+4]`（攻方 slot）→ `call 0x435829`；
   入口 `[esp]=攻方slot`、`[esp+4]=目标slot`；回跳 `0x43DB52`（`add esp,8`）。
3. **攻击第二段 = `0x4526E7`**：先把 `ctx+1 = ctx+0x10`（把“反击方”写进防方位），
   再 `0x403B96`/`0x44270C`，然后**内部两次** `call 0x435829`：
   - `0x45271E`：`push [ctx]`、`push [ctx+1]` ⇒ `0x435829(ctx+1, ctx+0)`（实机：**反击发生时命中**）
   - `0x452746`：`push 0xFF`、`push [ctx+1]` ⇒ `0x435829(ctx+1, 0xFF)`（实机：普通攻击时也命中）
   - 它被两条链调：`0x404BAB`（攻击分发 `0x404B46` 的末尾）与 `0x45292B`（斩杀流 `0x452907`）。
4. **“敌方攻击我方”的触发挂点 = `0x43DB4D`**（不是 `0x45271E`）。历史踩坑：
   - v6 挂 `0x436452`：**从不执行**（实机标记恒 90）；
   - v7/v8 挂 `0x45271E`：只在**反击**时执行 ⇒ “不反击不触发、反击闪退”；
   - 移星易宿 v9 已改挂 `0x43DB4D`。

## 3. 探测方法（可复用）

- 多点命中探针：每个站点挂一个 17 字节桩 `C6 05 <标记> 00 01` + `call 0x435829` + `jmp <站点+5>`；
  标记放 `.code` 空区（如 `0x4311E0+i`）；一次攻击后读标记字节（初值 90，命中=01）。
- 相关补丁：`_探针-16点全探.txt`（16 点）、`_精简-06-移星易宿v9探针-钩43DB4D.txt`。

## 6. 返回地址探针实测（2026-10-19 00:34，一次攻击的完整顺序）

在 `0x435829` 入口挂返回地址探针（钩 `0x435829` 前 5 字节 `55 8B EC 6A 00` → 洞 `0x430900`，
环缓冲 `0x4311C0..CF`、计数 `0x4311D0`；样本 SHA `1B493A8A05B3FF47213E68D8CB04F191BCC6DA0B6C7706B3E1798C2612C1FC4E`），
一次攻击命中 **恰好 3 次**，顺序：

```
1. 返回 0x43DB52 → 调用点 0x43DB4D   （攻击本体：0x43DB23 内）
2. 返回 0x452723 → 调用点 0x45271E   （0x4526E7 第二段第 1 处）
3. 返回 0x45274B → 调用点 0x452746   （0x4526E7 第二段第 2 处）
```

⇒ **一次物理攻击 = 0x43DB4D → 0x45271E → 0x452746 三次 0x435829**；
`0x43DB4D` 是第一处（攻击本体），挂它即可拦截每次攻击。
（该次测试为玩家侧攻击；敌方攻击路径是否同样经 `0x43DB4D` 待实机确认。）
