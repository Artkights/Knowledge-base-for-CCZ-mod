# 公式设定页：读写与语义验证（2026-10-30）

## 1. 页面结构

- 顶级页签：`Tag="__formulas"`，显示名“公式设定”。
- 左侧：全局 `_entityList`，24 项 `分类 · 公式名`。
- 右侧 `EngineBattleFormulaPanel`：
  - 标题与三基底摘要；
  - 公式计算过程（步骤 / 计算式 / 说明，只读）；
  - 公式常量（常量 / 作用 / 6.4 / 6.5 / 6.6 / 新值 / 范围 / 状态）；
  - 证据区（地址、签名、诊断）。
- “新值”是唯一可编辑列；共享常量按 ID 去重，写入后所有同 ID 行刷新。

## 3. 语义校验

`EngineBattleFormulaService.ValidateEdits` 返回 Error / Warning：

### 3.1 通用

- Error：ID 不存在、不是公式常量、同一批出现多个不同值、当前基底不可写、超出范围。

### 3.2 命中曲线族

Error：

- 低段基础 > 中段基础；
- 中段基础 > 高段基础；
- 高段基础 > 上限；
- 低段除数不在 1..10；
- 6.6 下限 > 低段基础。

Warning：

- 高段最高 > 上限（实际会被截断）；
- 中段最高 > 上限；
- 低段最高 > 上限。

只改上限（例如 100 → 90）只产生截断提示，不拦截。

### 3.3 发动率曲线族

Error：

- 低段基础 > 高段基础；
- 高段基础 > 上限；
- 满率倍率不在 2..10。

Warning：高段/低段最高超过上限。

### 3.4 二次判定

- Error：次数不在 1..8；阈值/扣减不在 0..100。
- Warning：扣减 > 阈值（补判命中率会变成 0 或负数）。

### 3.5 暴击/连击

- Error：上限不在 0..100；池号不在 0..255。
- Warning：池号不是当前基底默认值（6.4 0/0/0；6.5/6.6 2/18/0）。

### 3.6 经验族

- Error：经验常量超出各自范围（基础值 0..100/0..20，击杀加成 0..200，分子 1..200，除数偏移 1..50，倍率基础 0..200，无伤害扣减 0..10；角色最大等级 1..99、每级经验 1..250、6.5 分段 1..100、6.5 增量 1..250；装备阈值 1..250、装备上限 1..99）。
- Warning：
  - 经验倍率基础值 < 100（所有经验按低于 100% 结算）；
  - 击杀经验分子 < 除数偏移 + 1（普通击杀额外经验最多 1 点）；
  - 个人/武器/防具经验基础值为 0（对应经验会变成 0）；
  - 宝物等级上限低于普通上限（宝物会更早封顶）；
  - 宝物经验阈值低于普通阈值（宝物升级反而更快）。
- 只读结构值：个人经验的等级差钳位 −1/47、武器暴击 +1、防具等级 −1、策略经验各档位系数与上下限、功勋表结构、升级字段与满级 255 标记、战场变量装载表 `0x004123BE` 与 7 项写入/标志地址、每回合经验的 selector 表 `0x0043CFCD` 与 8 项结算地址、本场战功表 `0x508000 + ID×10` 与 9 项累加/结算地址，均不在“新值”列开放。

## 4. 写入流程

1. 用户编辑“新值”，`CellValidating` 做整数、范围、公式族校验。
2. “写入修改”显示变更列表与 Warning，确认后调用 `TryCommit`。
3. `TryCommit` 再校验一次，转成 `EngineConstantEdit` 调 `EngineConstantService.Commit`。
4. 事务做整文件备份、等长补丁、写后复读、失败回滚。
5. 成功后清空 pending、重新读取当前公式、刷新所有行。
6. 失败保留 pending，状态栏/弹窗显示原因。

## 5. 离开提示

- 切换顶级页签、切换公式、切换 Profile、打开项目、迁移、重新扫描、关闭窗口前：
  - Yes：先写入；
  - No：放弃；
  - Cancel：留在原页。
- `HasPendingChanges` 包含公式 pending；`RefreshDirtyState` 显示“● 有未写入的公式修改”。

## 6. 测试命令

```text
--battle-formulas <基底>
--battle-formula-write <基底>
--engine-constant-audit <基底>
--engine-effect-ui <基底> <截图目录>
--engine-assignment-ui <基底> <截图目录>
```

截图命名：`公式设定-{version}-{宽}x{高}.png`；经验页另存 `公式设定-经验-{version}-1280x720.png`，装备经验页另存 `公式设定-装备经验-{version}-1280x720.png`。

## 7. 边界

- 公式页只写“新值”列对应的真实立即数；`shl/shr/sar/inc/xor` 编码的倍率、除数、保底保持只读。
- 武力/统帅/智力/敏捷/士气是公式输入，不是单点常量。
- 静态写入验证不等于战场实机验收；曲线类改动建议在测试副本战斗场景复核。
