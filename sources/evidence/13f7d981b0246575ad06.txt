# 6.4 洗隋兼容适配

兼容修正日期：2026-10-22；最终程序版本见发布包及程序“关于”。

## 使用范围

新增 `ccz-6.4 / 64-xisui-v1`，以 `基底/洗隋` 为基准，支持该作品及相同文件布局、消费者结构的 6.4 引擎。识别顺序仍为四核心 SHA、EXE SHA、PE 固定版本和既有后续证据。PE 的 `FilePrivatePart=4` 优先于旧物品索引锚点，避免将 6.4 的 `0x4A1140` 错认成 6.6 兼容布局；目录名不参与识别。

保留人物、兵种系、兵种、宝物、策略、商店、拓展数据和形象设定的现有操作。CSV、XLSX、保存事务、统一历史和迁移继续使用现有格式。不同版本的交换文件仍不能直接混用，跨版本数据使用一键迁移按 TableKey、ID、字段和目标 Codec 映射。

## 6.4 证据和能力

- 旧 `老版游戏制作工具/CczRSX 6.5/ConfigTable/HexTable - 副本.xml` 保留 41 项 6.4 定义，共享主表沿用核对一致的几何；新清单在现有 6.5 基础结构上显式覆盖 6.4 差异，不修改 6.5/6.6 或两组冻结历史清单。
- 人物 R 表为文件 `+0xE1000`、S 为 `+0xD2800`，各 `1024×UInt16`。已知样本指纹、项目历史及完整人物 ID 换算/R/S 消费者沿用既有证据检查；同布局修改的 EXE 可凭当前消费者通过。INI 冲突、越界或消费者缺失时不读取猜测地址。
- 策略施展地形由当前 PE 读取函数和独立调用方探测；洗隋映射至文件 `+0x1FECC`，30 个低四位掩码。没有证据时不可用。
- 共享人物/兵种特效名称通过两处唯一消费者映射 `VA 0x4FF560 → 文件 +0xD0D60`，仅读取 `180×16` 字节，严格 GBK 和槽内 NUL。保持只读，不套用 6.5 的 `+0x9E800/255`；探测失败时共享引用回退数字 ID。
- 人物记录 `+27` 级别、`+28` 经验、`+29..31` 默认武器/防具/辅助已由洗隋完整人物构造器、1024 行加载和 32 字节索引步长验证，开放正常编辑。级别原始值为 0 时，游戏加载为 1。默认装备使用原生类型分类筛选，并保留 255 无装备。
- 详细兵种成长记录 `+9..34` 的 26 类装备许可已由洗隋 80 行/35 字节加载器、原生兵种索引、装备选择循环和许可读取链验证，开放“宝物可装备部队”和相关业务页。引擎读取 `row+9+类型`，类型码 0～19 为武器、20～25 为防具，非零许可即允许。
- 洗隋撤退台词实际位于 `Imsg.e5 +130000，49×200`，已开放。完整调用链使用消息索引 `650+人物ID`、200 字节读取和缓冲区尾 NUL，人物 ID 范围 0～48；人物记录 `+15` 的“撤退台词”字段不参与这条调用链。旧说明沿用了 6.5 的 `+440200` 并误判缺失，本轮已更正。
- 策略扩展标记仍无洗隋独立消费者证据，保持不可用；不能以 6.5 旧偏移 `+0xA2CE0` 或文件长度证明其语义。
- 缺失的 Effect、Effectmsg、MeffStudy、Forge 文件按对应拓展分类显示缺失。迁移现有物理文件读写能力不等于 6.4 游戏实现了扩展消费者，程序不通过复制 DLL 或注入代码补足这些能力。
- 特殊暴击映射额外核对洗隋完整读取链：21 项上限、UInt32 人物 ID、文件 `+0x89C30` 的 PE 映射及后续 200 字节台词读取。装备类型名称/显示及辅助分组继续经过现有项目 PE 引用、结构和边界检查。文本容量保留现有保守限制与证据提示，未确认消费者的文本不声明为已验证运行时容量。
- 6.4 新开放字段均由当前 EXE 完整消费函数、调用关系和唯一性独立校验。修改数值、名称或台词不改变消费链；对应读取/加载/边界代码损坏时，只关闭相关能力，普通人物字段继续可用。

本轮冻结上一版 6.4 完整清单（独立于当前 6.5 父清单），仅接受能由该清单及当前实际几何严格复现的上一版修订。旧版已开放人物字段仍在相同文件、记录和字节位置，已验证普通字段 CSV 和保存历史撤回/重做；旧版导出中已删除的保留原始列不能自动变成新的装备字段，需重新导出或按现有字段整理导入。不会借用 6.5/6.6 的 CSV 或历史身份。

## 验证

所有写回验证在系统临时目录的独立副本进行，原件只读。

```powershell
dotnet build data管理器/DataManager.sln -c Release --no-restore
dotnet run --project data管理器/src/DataManager.Tests -c Release --no-build -- --ccz64-compatibility "基底/洗隋" "基底/加强版6.5未加密版" "基底/曹操传6.6-V7.16 解压密码：66"
dotnet run --project data管理器/src/DataManager.Tests -c Release --no-build -- --ccz64-configuration "基底/洗隋"
dotnet run --project data管理器/src/DataManager.Tests -c Release --no-build -- --ccz64-field-writeback "基底/洗隋"
dotnet run --project data管理器/src/DataManager.Tests -c Release --no-build -- --core-regression "基底/加强版6.5未加密版"
```

6.4 专项覆盖精确/兼容识别、180 项名称、损坏消费者关闭、40 张加载表 CSV 和有数据业务页 XLSX 原样往返、损坏配置消费者关闭、七业务页绑定、跨表首末记录写回与逐字节撤回/重做，以及 6.4↔6.5、6.4↔6.6 四方向迁移。迁移同时验证人物数值、16 位 R 指定、辅助物品效果/类别的 Codec 转换、目标其他字节保留、跨 Profile 直接导入拒绝和源目录不变。

配置专项另覆盖撤退首末文本、全部 26 类许可首末写回、人物级别经验与三类默认装备、原生人物 ID 撤退映射、十处损坏消费者、重复消费者拒绝和上一版 6.4 严格历史兼容。逐字段矩阵另通过 720 项首末记录边界，18 项明确未测/不适用，失败 0；矩阵不代表全部中间记录或全部取值的穷举。已通过现有 6.5/6.6 核心回归。图片格式与图像底层的专项结果由形象管理器本轮报告记录。程序回归不替代每个衍生 MOD 的游戏内运行验证。
