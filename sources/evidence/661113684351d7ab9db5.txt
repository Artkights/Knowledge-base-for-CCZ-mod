# 业务工作簿交换

版本：1.2026.1022.5。顶部“导入”“导出”在业务详情中默认使用 XLSX；选择“兼容旧 CSV 目录”可继续使用原有 CSV。普通物理表仍使用 CSV。程序无需本机安装 Excel。

## 使用方式

1. 打开游戏项目并选择人物、兵种系、兵种、宝物、商店、策略或拓展数据。
2. 点击“导出”，选择 Excel 工作簿。整个大页表导出为一个文件，其中每个原生或物理数据集各占一张工作表。当前项目不存在的数据集不生成。
3. 编辑数据区。浅灰列为只读，白色列可编辑；第 2 行为可读表头，冻结表头和编号列。编号用于定位现有记录，不要新增、重复或修改编号。
4. 点击“导入”选择工作簿。程序先完整校验，再显示“工作表、单元格、编号、字段、当前值、导入值”的变更预览。
5. 点击“确认加入草稿”。整次导入形成一条撤回记录，可整体撤回或重做。顶部“保存”才写回游戏文件。

工作表可以重命名和重新排序，不能删除已登记工作表、隐藏的基线或元数据。缺少个别数据行表示不更新该记录，不会删除游戏记录。工作簿中的公式必须先粘贴为值；导入器拒绝使用公式的计算缓存。

## 数据范围

| 大页表 | 工作表内容 |
|---|---|
| 人物 | 基础、列传、普通/特殊台词、特殊台词关联、R/S 指定等当前可用数据集 |
| 兵种系 | 名称、克制、地形发挥、移动消耗、八项属性、原生辅助装备分组 |
| 兵种 | 基础、介绍、成长与装备许可、穿透范围；策略表只含名称参考和学习等级 |
| 宝物 | 当前各段宝物及说明、装备特效名称、可装备部队、装备类型名称与显示 |
| 策略、商店、拓展数据 | 该页负责的当前可用数据集 |

宝物“可装备部队”仅含 26 个装备许可字段，不包含兵种成长。兵种“策略学习”中的策略名称仅供参考，不能通过此页修改策略基础属性。导入时从程序重新生成字段白名单，文件内的隐藏信息不能扩大可编辑范围。

装备类型显示导出为 0/1：0 表示隐藏，1 表示显示；写回时转换为当前类型的原生编码。辅助和道具没有原生显示开关，不伪造可写开关。

辅助装备分组以逗号分隔的兵种系 ID 表示成员，只更新已有组；新增/删除组在原生分组编辑页操作。

## 冲突与校验

文件保存导出时的每格基线。导入只处理相对基线发生变化的单元格。若同一格在当前草稿和工作簿中被改为不同值，程序报告冲突并拒绝整本导入；当前值已经与导入值相同则不产生重复修改。

重复或新增 ID、未知字段、只读字段修改、缺失工作表、元数据损坏、跨 Profile/Variant 或不兼容布局，以及超范围/超 GBK 容量的内容，都会拒绝整本导入。错误说明文件、工作表、单元格、ID、字段及实际值。跨基底使用“一键迁移”。

预览确认后再次核对项目身份和所有拟修改单元格，防止等待确认期间的草稿变化。物理表与辅助分组草稿统一校验并组成一个命令组。保存仍执行来源 SHA、原字节、候选复读、磁盘复读及失败回滚。

CSV 兼容修复仅允许元数据原六列之后追加空列，适配 Excel 另存时的补齐行为。缺失字段、非空多余元数据和布局冲突仍然报错；正文中间的空字段仍保留原列位置。

## 实现与回归入口

- `src/DataManager.Core/Workbooks/PageDatasetRegistry.cs`：当前业务页的数据集及权限白名单。
- `src/DataManager.Core/Workbooks/WorkbookPackage.cs`：流式 Open XML 写入/逐行读取、隐藏基线和元数据。
- `src/DataManager.Core/Workbooks/PageWorkbookService.cs`：整本预检、三方冲突、原子草稿应用。
- `src/DataManager.App/MainForm.Workbooks.cs`：格式选择、后台文件 IO、变更预览。
- `DataManager.Tests --page-workbook <基底路径>`：各大页零变更往返、白名单、错误拒绝、联合原生草稿撤回/重做/保存/历史。
