# 验证与烟测

## 结论速览

自动测试覆盖 Profile 解析、codec、扫描、工作区、CSV、历史和真实样本读取。所有写入测试只使用临时副本。

## 适用版本

6.5 默认基底与七套本地 6.6 样本。

## 已确认事实

- Profile 已覆盖旧 HexTable.xml 的 6.5 表、四个拓展文件与运行时增强表；字段不越过行宽。6.6 地形/R/S 只由 PE32 节映射和实际消费者证据动态开放，缺证时不读取继承地址。
- 七套 6.6 样本均精确识别；厚黑选择兼容布局，其余选择标准布局。
- 标准 6.6 名称只写前 15 字节，普通装备特效写 `+0x12`，辅助/道具特效写 `+0x11`。
- 6.5 名称只写前 17 字节，资源原始字节保持不变。
- 人物级别/经验、策略资源字节和物品保留字节在相关保存测试中保持不变。
- 历史 schema 2.0 支持同布局整体撤回/重做，并拒绝跨布局重放。
- `BusinessTableWriteTests` 在一次跨表事务中验证兵种系矩阵、成长/装备许可/策略学习、宝物、策略附表和商店；检查草稿整体撤回/重做、跨 Data/EXE/Imsg 保存、写后复读、目标字段之外字节不变和已保存历史恢复。只读标签列不参与可编辑草稿快照。
- `ItemMigrationTests` 验证 6.5↔6.6 辅助/道具低段与高段、自定义 AssID、类别 2→3、普通装备保持同名映射，以及未知类别转换整行拒绝；同时检查目标原始 +0x11/+0x12 字节与 Codec 复读。
- `AccessoryGroupCsvTests` 验证辅助分组专用 CSV 的四种编码、版本/组号/范围/安全区拒绝、导入无磁盘副作用、专用保存复读与历史恢复，并防止占位定义被当成 EXE 首字节物理表导出。
- `IntegratedResourcePanelTests` 验证动画播放入口、已验证 R/S 引用对空闲筛选的实际作用，以及 6.6 缺证时隐藏筛选。原形象底层 8 项资源写入测试另外使用当前 Release Core 在临时副本中通过，日志见 `../验证/资源写入验证.log`。
- `AssignmentEvidenceTests` 在真实 6.6 V7.16 临时副本中写入并复读 R、S 和策略施展地形；同一测试还验证截断 PE、INI 冲突和破坏消费者签名会封锁写入。
- `MigrationIsolationTests` 验证根目录/E5 同名资源不可自动覆盖、单字段迁移不改写其它物理文件、配置快照变化拒绝提交，以及 `../` 路径穿越不会写出项目目录。

## 实现与使用方法

在 `data管理器` 目录运行：

```powershell
dotnet build DataManager.sln --configuration Release
dotnet run --project src\DataManager.Tests\DataManager.Tests.csproj --configuration Release
```

界面烟测应打开两个 Profile，切换布局，编辑单元格，执行多选批量修改、CSV 导入导出、草稿撤回/重做、已保存历史撤回/前进，并验证脏状态退出提示。

## 风险与边界

自动测试不操作默认基底原件。人物台词验证 6.6 +491600 以及旧区不变；CSV 覆盖四种布局和三种编码；迁移验证源不变、SHA、存储位置和中途失败回滚。WinForms 烟测遍历业务页、编辑五维、撤回和批量 CSV，并在 1280×720/1920×1080 检查固定窗格。

## 证据来源

`DataManager.Tests` 中的 Profile、record codec、七样本扫描矩阵、Profile 写入和既有工作区测试。
