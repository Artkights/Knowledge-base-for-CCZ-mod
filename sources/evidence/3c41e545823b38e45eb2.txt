# 模块精简与历史隔离

版本：1.2026.1022.5（2026-10-22）。

## 模块范围

顶部“人物/套装特效”模块已移除，包括原有特效分配、人物专属与套装、剧本分配子页，以及其专用数据集、工作簿交换、剧本扫描写回和迁移逻辑。

人物、兵种系、兵种、宝物、商店、策略、拓展数据、形象设定保持各自原有功能。拓展数据中的人物特效、特效成长属于独立数据功能，继续保留。其他业务使用的特效名称保留为共享只读引用；宝物装备特效名称继续由宝物功能处理。

旧版布局清单仅用于精确识别历史和 CSV 的旧布局标识，不提供被删除模块的编辑入口。历史恢复继续检查 Profile、Variant、布局、原文件 SHA 与补丁范围。

## 历史目录

默认使用 `AppContext.BaseDirectory`，即实际运行的 `data管理器.exe` 所在目录。与启动时工作目录无关。

```text
data管理器.exe
项目名称_历史记录/
  完整项目路径的身份标识/
    数据/
    形象/
    迁移备份/
```

项目名称来自程序实际打开的游戏项目文件夹名称。打开单层外包装目录后，名称取最终识别的游戏项目目录。内部身份由规范化完整路径计算：Windows 路径大小写和末尾目录分隔符不产生新身份，同名但位于不同路径的项目分别存放。

历史列表仍统一展示数据与形象记录，并按原有来源分发撤回和重做。切换项目和重开项目时使用该项目自己的身份。项目移动到其他绝对路径后视为新的项目身份，原位置历史保留在原身份目录。

## 旧历史

项目内部原 `.data管理器历史/manifest.jsonl` 在新目录尚无记录时可继续读取，首次保存或历史状态更新时接续到新目录。已有新记录后，以新记录为准。

原 `.data管理器形象历史` 的本项目记录和快照迁入新位置，快照路径同步更新，普通资源目标仍须属于当前项目；原有外部素材批量改名按记录中的明确素材根目录校验，继续支持撤回。原历史不删除。损坏或无法证明归属的记录不得绕过现有冲突检查写回文件。

迁移临时项目的历史使用独立临时位置；最终目标项目的历史与迁移备份使用目标项目自己的身份，迁移失败仍执行文件及历史回滚。

## 源码与构建

源码仓库：[Artkights/CCZ-DataManager](https://github.com/Artkights/CCZ-DataManager)（私有）。修改前基线标签：`baseline-before-simplification-20261022`，提交 `cb651cbc335cbef635bffb17f2825deecb111e61`。

仓库保留 `data管理器` 与同级 `形象管理器` 构建依赖，克隆后可直接运行：

```powershell
dotnet build data管理器/DataManager.sln -c Release
dotnet run --project data管理器/src/DataManager.Tests -c Release --no-build -- --core-regression <测试基底目录>
dotnet publish data管理器/src/DataManager.App -c Release -p:PublishProfile=SingleFileWinX64 -o publish
```

本版发布入口：`发布-模块精简与历史隔离版-20261022/data管理器.exe`。运行需要 .NET 8 Windows Desktop Runtime x64。
