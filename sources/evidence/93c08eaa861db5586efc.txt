# 疾风攻击公式与常量/特效值区分

日期：2026-10-29（2026-10-31 复核修正 6.6 公式）。适用基底：6.4 洗隋、6.5 加强版、6.6 复刻版山贼。
证据来自 `--engine-disasm`、`--engine-disasm-fn` 与三基底 `Ekd5.exe` 的静态分配表读取；不运行游戏、不修改样本。

## 1. 结论

- 6.6 疾风攻击的 `+12` 是代码里的固定补正（`add eax,0Ch`），**不是特效值**。
- 6.6 当前特效值为 5（特效 117 行，兵种 76）；6.5 的特效值恰好是 12，但 12 与特效值在 6.6 中同时出现且不相等，证明两者是两路数据。
- 6.4/6.5 的固定 `×5` 也是代码项，不是特效值；特效值 N 只作为触发门槛。
- 6.6 的特效值 N 只作为每点增伤比例，不再作门槛；公式是 `(12 - 目标能力) × N / 100`（字节 `F7 D8 neg`、`83 C0 0C add 12`、`0F AF C2 imul edx`，没有 `sub edx`）。
- 6.6 没有“每点增伤”的代码立即数，所以常量页把这一行映射到静态分配表行 117 的兵种 76 槽 N（文件 `+0xE2F5D`，当前 5），让同一行在三基底都能改；其他特效值仍在宝物/兵种特效页修改。

## 2. 6.4 / 6.5 公式

伤害函数 `0x0043BC62` 的特效 117 分支：

```asm
0043BD6B  call 00413260h        ; 查询特效 117
0043BD70  test eax,eax
0043BD72  je   short 0043BD95h
0043BD74  push eax              ; N = 特效值
0043BD78  call 0043F74Fh        ; A = 目标能力值
0043BD7D  pop edx               ; edx = N
0043BD7E  sub eax,edx           ; A - N
0043BD80  cmp al,0
0043BD82  jge short 0043BD95h    ; A ≥ N：不追加
0043BD84  neg eax               ; N - A
0043BD86  imul eax,5            ; ← 代码固定每点 +5%（6.4/6.5 立即数 0x0043BD88）
0043BD89  push dword ptr [ebp-4]
0043BD8C  push eax
0043BD8D  call 00425AD9h        ; 伤害 × (N-A)×5/100
0043BD92  add [ebp-4],eax
```

- N：特效值，只决定“目标能力低于 N 才触发”。
- 5：代码固定每点增伤，可编辑常量。
- 追加伤害 = 原伤害 × (N - A) × 5 / 100。

## 3. 6.6 公式

```asm
0043BD74  push eax              ; N = 特效值
0043BD78  call 0043F74Fh        ; A = 目标能力值
0043BD7D  pop edx               ; edx = N
0043BD7E  F7 D8  neg eax        ; -A
0043BD80  83 C0 0C add eax,0Ch  ; ← 12 - A（代码固定 12）
0043BD86  0F AF C2 imul eax,edx ; × N
0043BD8D  call 00425AD9h        ; 伤害 × 结果 / 100
```

- 12：代码固定补正，可编辑常量；不是特效值。
- N：特效值，只作为每点增伤比例。
- 追加伤害 = 原伤害 × (12 - A) × N / 100。
- 静态未见该分支对负值钳制；A ≥ 12 时结果会减少原伤害，需实机复核。

## 4. 三基底特效 117 实际分配

静态分配表（Ekd5.exe）：

| 基底 | 表文件偏移 | 行宽/行数 | 人物槽 | 兵种槽 | 特效值 N |
|---|---|---|---:|---:|---:|
| 6.4 | `+0xDA198` | 180×8 | 人物 4 | 空（255） | 10 |
| 6.5 | `+0xD9000` | 255×8 | 人物 85、45 | 兵种 45 | 12 |
| 6.6 | `+0xE2800` | 255×16 | 全空 | 兵种 76 | 5 |

6.6 行 117 的兵种 76 槽 N 在文件 `+0xE2F5D`（VA `0x0051175D`），前一字节 `4Ch`、后两字节 `FF 00` 作为槽位边界校验；该行人物槽全空。常量页在 6.6 读取/写入的就是这个槽。

读取命令（只读）：

```powershell
dotnet DataManager.Tests.dll --engine-effect-assignments 基底\洗隋
dotnet DataManager.Tests.dll --engine-effect-assignments 基底\加强版6.5未加密版
dotnet DataManager.Tests.dll --engine-effect-assignments 基底\复刻版6.6山贼
```

## 5. 常量与特效值边界

| 项目 | 常量页 | 特效值 |
|---|---|---|
| 存放位置 | Ekd5.exe 代码立即数/固定文本槽；6.6 疾风每点增伤映射到兵种槽 N | 宝物 selector 字段、兵种槽 N、Effect.e5 槽 N |
| 修改入口 | 引擎扫描 → 常量 | 宝物特效 / 兵种特效（特效值）/ 拓展数据（Effect.e5） |
| 典型例子 | 疾风的 5 与 12、各上限 100、方向数 4/8；6.6 疾风兵种 76 槽 N | 疾风 N=10/12/5，猛击/盾反读取的百分比 |
| 是否随装备/兵种变化 | 不随 | 随宝物/兵种/人物槽变化 |

## 7. 收录规则

新增常量必须同时满足：

1. 三基底或声明的适用基底有唯一、可校验的指令签名；
2. 立即数在代码里固定，不被特效值/表项/运行时开关覆盖；
3. 语义能用一句通俗话说明；
4. 有写入范围、成对地址（如需要）、写后复读与回滚；
5. 不把特效值、表项、方向表、枚举开关、难度开关收进常量页；唯一例外是 6.6 疾风攻击每点增伤——它没有代码立即数，行内映射到兵种 76 槽 N，且界面明确标为“特效值槽”；信奈/清儿的兵种 14 槽用可选后备布局映射，官方 6.6 仍走兵种 76 槽。

不满足就只记录“已排查、不收录”和原因，保持只读。
